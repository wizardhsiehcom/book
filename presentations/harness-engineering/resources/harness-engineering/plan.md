## 1. 對象與目的

| 項目 | 內容 |
| --- | --- |
| 聽眾 | 會讀簡單程式、沒設計過 agent 的學習者（沿用原書讀者設定） |

## 4. 特殊需求

- 分工判斷：未分派 subagent。宿主規定使用者未要求不派；內容多為同一案例的文字整理，用語一致比平行速度重要。交付前的邏輯審查由主 agent 自審，未做獨立審查。
- 特殊元件：無（只用 cards、sequence、table、predict）。
- 互動頁 4（edit-lab）：輸入＝檔案版本（0／1／2 處）、old 字串（短／加周邊）、套用 → 連動＝匹配數、寫入後檔案、工具回傳 JSON → 預期＝只有一處才寫入、拒絕時原檔不變。依 edit_demo 規則在瀏覽器即時計算，教學模擬，不執行程式。
- 互動頁 6（summary-lab）：輸入＝三份摘要 → 連動＝五欄保留／遺漏／與紀錄不符、能否交接 → 預期＝短摘要可能漏欄或竄改證據。照 context_demo 三個案例固定比對，非語意評分。
- 兩頁皆由講者操作，state 保留目前選擇，換頁返回保留；提供 previewArt 與清理函式；控制區高度固定。
- 品牌：沿用 `agentdeck/assets/theme/`；story.css 只用主題顏色變數。
