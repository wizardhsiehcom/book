# MIT 9.35 第 12 章：同一灰色，為何看起來不同

2026-09-28。主題目錄 `docs/mit9-35-perception/resources/same-gray/`；章節入口 `docs/mit9-35-perception/12-lightness-and-color.md`（第 3 行）。來源與假設見 [same-gray-sources.md](same-gray-sources.md)。

## 讀者能力

讀者已讀第 11 章（L = I × R、明度＝對反射率的知覺）。讀完能：

1. 分辨「像素值／進眼亮度相同」與「看起來一樣亮」是兩件事，並能用移除背景或接橋的方式自己核對。
2. 用 Hering 的中心-周圍比較，說出背景變暗為何讓「中心減周圍」變大。
3. 用 Helmholtz 的無意識推論（L = I × R），說出「暗背景被當成光照弱」如何推出較高的反射率。
4. 說出兩種解釋不互斥（章節引 Marr 的多層次分析）。
5. 用章節的「光照框架內最亮當白」規則，預測框架內多一塊更亮的東西時灰塊會怎麼變。

## 呈現決定

- 灰塊與橋一律用同一常數 `sgGray = '#808080'`（inline style 由同一常數產生）；`tools/check-same-gray-story.cjs` 斷言所有渲染狀態中的灰塊與橋都是此值，且常數在 `story.js` 只出現一次、`story.css` 不改灰塊的背景、透明度或濾鏡。
- 刺激色（`#202020`、`#e0e0e0`、`#ffffff`、`#808080`）是刺激本身，不是外殼配色，不用 token；其餘都用 reader.css `:root` token，朱紅只標重點（Hering 的訊號條、錨點「當作白」標記）。
- 不做閃爍、漸變或自動輪播；切換是即時狀態替換，主題 CSS 沒有 transition／animation。
- 數字只用 sRGB 像素值（0–255），明說它不是物理亮度；中心-周圍用「中心 − 周圍」差值示意，不是神經元放電模型。Helmholtz 頁的 L、I 是示意數字。

| 4 | inference | 背景被當成光照 I 的線索 → 相同 L 除以較小的 I → 推出較大的 R（看起來較白） | 分層：L、I、R 三列長條（示意數字） |
