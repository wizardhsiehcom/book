# EE274 算術編碼：A 紙本圖解改版

2026-09-28。只改 `docs/ee274-data-compression/resources/arithmetic-interval/story.js`、`story.css`。模型（acModel／acSplit／acTrace／acDecode）、頁 id、mount／cleanup／state、previewArt、題目、章節連結都沒改；保留 `[data-ac]`、`[data-ac-output]`、`.ac-controls`、`.ac-card` 及 `ac-` 前綴。

## 部件與各頁

所有位置都由模型推導：left =（左端 − 軸最小值）/ 軸範圍，width = 長度 / 軸範圍。半開區間的畫法固定為：實心點代表包含左端，空心點代表不含右端。A／B／C 用三種低彩暖色（沙、灰綠、陶土）並寫上字母。朱紅只用在目前選取的區間、目前前綴列與 z 線。

| 頁 | 部件 | 理由 |
|---|---|---|
| 01 契約 | 放大切分條＋刻度＋圖例 | 刻度 0／0.5／0.75／1 直接標出切點，恰好 0.5 屬於 B |
| 02 第一刀 | 共同座標（起點＋B）＋第一步切分 | 起點列讓「縮小」在同一比例上看得到 |
| 03 再切 | 上方 [0,1) 定位條 → 漏斗 → 放大切分 | 把「在目前區間內再切」畫成空間關係，不再是等寬條加文字 |
| 04 預測 | 同上，只標兩端刻度 | 不揭露 0.59375 |
| 05 互動 | 按鈕＋序列＋共同座標（起點＋各前綴），局部放大可展開 | 控制與主要結果放在一起 |
| 06 寬度 | 左右兩欄對照（1/32、1/8）＋共同座標 BAC 與 AAA | 用長度直接呈現 4 倍 |
| 07 前綴 | 放大座標 [18/32,21/32)，以虛線標出 BAC 兩端，1001 超出的部分畫斜線 | 一眼判斷前綴是否整段落在區間內 |
| 08 解碼 | 共同座標上畫一條貫穿各列的 z 線＋BA 放大切分與 z | z 在 C 的實心左端點上 |
| 09 CA | 定位＋漏斗＋C 的放大（只標兩端） | 答案只寫在回饋裡 |

## 重做結構，還是只換顏色

- 重做結構：原本的切分條用 flex 撐成等寬，只靠文字寫端點。現在改成絕對定位的比例條，加上刻度與「整條 → 目前」定位漏斗。共同座標增加起點列、格線、貫穿各列的單一 z 線、半開端點記號、目標虛線與超出部分的斜線。第 06 頁由兩張數字卡改成對照加共同座標。
- 只換顏色：深藍卡片改用 reader token。`.ac-card` 不再畫框（`.stage` 已經是卡片），卡片之間改用細線分隔。
- 窄螢幕：倒數第二個刻度會往下錯開一行，避免 0.59375 和 0.625 重疊。列標籤加上底色，蓋住穿過的格線與 z 線。
- `.mini-page` 另外寫了覆寫，讓縮圖維持桌面構圖（三欄圖例、雙欄對照、條高、刻度的「不含」字樣）。
