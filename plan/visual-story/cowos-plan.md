# 第三篇：GPU 到 HBM 經過哪些層？

日期：2026-09-28。依候選順序製作 CoWoS 第 03–07 章的結構解說。

## 讀者與終點

讀者知道 GPU 與記憶體，尚不能區分中介層、封裝基板與主機板。讀完能沿剖面指出 GPU–HBM 的橫向互連、CoWoS-S 的下行連接，以及 HBM 堆疊內的 TSV；再辨認 S／R／L 的中介層差異。

## 分鏡

| 頁 | 認知步驟 | 圖解 |
|---|---|---|
| 1 | GPU 和 HBM 在封裝內並排 | 簡化剖面，標示封裝與板端 |
| 2 | 三個結構層分工 | 晶片、CoWoS-S 中介板、封裝基板分層 |
| 3 | GPU 到 HBM 的橫向路徑 | 凸塊下接、沿中介板布線、再上接 HBM |
| 4 | 接往基板是另一條路 | S 的 TSV → C4 → 封裝基板 → BGA／板端 |
| 5 | HBM 自己還有一個垂直方向 | DRAM 堆疊與 TSV、底部 die；與中介板 TSV 分開 |
| 6 | 預測：讀 HBM 都先經主機板嗎？ | 題目；分開同封裝互連與對外連接 |
| 7 | 同一位置，換三種中介層 | 原生按鈕切換 S／R／L；相同晶片與基板，只有中介層改變 |
| 8 | L 的「局部」是什麼？ | RDL 中介層與局部矽互連的位置，避免畫成整片矽 |
| 9 | 用三個問題讀懂剖面 | 哪兩顆晶片、橫向走哪層、往外怎麼接；回 03／06／07 |

## 內容界線

- 原創 HTML/CSS 結構示意，不按比例，不表示實際晶片數量、線數、厚度或製程順序。
- 主要路徑以 CoWoS-S 為例；R/L 不套用整片矽中介板的 TSV 圖。
- S：矽中介板；R：RDL 中介層；L：RDL 中介層加局部矽互連 LSI。RDL 中介層仍須和下方封裝基板分開。
- 不採用原章未逐一查核的良率、成本排名、產品對應、面積上限及「HBM 非 CoWoS 不可」等絕對說法。
- HBM 是堆疊記憶體；CoWoS 是整合它與邏輯晶片的方案之一。圖省略電源／接地、散熱蓋與填充材料。
- 官方查核放 [cowos-sources.md](cowos-sources.md)。只用支持此圖的來源，不複製外部圖片。
