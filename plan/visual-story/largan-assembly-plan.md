# 大立光 06：每片合格，組起來為什麼失敗

2026-09-28。主題目錄 `docs/largan/resources/assembly-yield/`；章節入口 `docs/largan/06-assembly-yield-cost.md`。來源與假設見 [largan-assembly-sources.md](largan-assembly-sources.md)。

## 讀者能力

讀完能：

1. 分辨零件規格與系統規格。
2. 用幾何離焦說明「間距誤差 → 全場對稱變差」「像面傾斜 → 單側變差」。
3. 說出為何「單片良率的片數次方」不能當鏡頭良率，以及配對怎麼改變組出率。
4. 用兩站模型算合格單位成本 K，並指出良率改善是透過分母降低 K。

## 光學呈現的決定

不做模糊影像動畫，也不畫 MTF 曲線。只用**幾何離焦模糊圈**：物在無窮遠、小離焦時，模糊圈直徑 c = |Δz| / N。

- 圖上一律標示「只含幾何離焦；未含繞射、鏡頭本身像差；不是 MTF」。
- 輸入直接用像側量（整體焦點偏移、邊緣焦點差），不假裝從元件 Δd、θ 換算到像面。那個換算要靠設計敏感度，本篇沒有。
- 偏心的主要徵狀是非對稱彗差，不在這個模型裡，只畫幾何定義並說明畫不出的原因。
