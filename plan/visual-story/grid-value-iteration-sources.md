## 不宣稱

- 不說價值迭代比策略迭代快或慢；不給複雜度以外的效能數字。
- 不把格子世界說成 CS234 課堂上的例子；只說仿照 Mars Rover。
- 不宣稱就地更新一定比較快（只示範中間數字不同）。
