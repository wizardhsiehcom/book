## 讀者能力

讀者讀過第 2 章前半：知道 MDP 五元組、γ、V 與 Q。讀完能：

1. 對一個格子寫出一次最佳貝爾曼備份：列出每個動作、到哪些 s'、機率、R、γ，取 max。
2. 說清楚同步更新：第 k+1 輪全部讀第 k 輪的 V；就地更新的中間數字不同，固定點相同。
3. 解釋箭頭為何逐輪改變：V^k 是「只剩 k 步」的最佳回報，遠處的大獎勵要幾輪才傳到。
4. 分辨「策略穩定」與「價值收斂」是兩個不同輪次，並用 γ 壓縮說明差距逐輪縮小。
5. 用 γ^距離 × 目的地價值比較兩條路，預測改 γ、加滑動或改獎勵後某格的箭頭。

## 模型（全部由 story.js 執行，不手填）

- 4 × 3 格，s1…s12 由左上逐列編號。動作 上下左右。撞邊界留在原地（同章節 Mars Rover 的 try-left）。
- R(s,a) 只看 s：s4 = +10、s9 = +1、s8 = −10（泥沼：待在裡面的每一步都扣分，但走得出來），其他 0。沒有終止狀態。
- 滑動 p：以 1 − p 走向想去的方向，各以 p/2 滑向兩個垂直方向。基準 p = 0。
- γ 基準 0.9。V⁰ = 0。**同步更新**：V^{k+1}(s) = max_a [R(s,a) + γ Σ P(s'|s,a) V^k(s')]，每輪另開陣列。
- 第 k 輪的箭頭 = 算 V^k 時取到 max 的動作（全部平手就不畫箭頭，寫「四向平手」）；差距 < 1e−9 視為平手並全畫。
- 停止：Δ_k = max_s |V^k − V^{k−1}| < ε = 0.01。
