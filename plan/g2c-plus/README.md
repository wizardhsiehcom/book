盤點結果：未見三家公司的獨立 docs 或 plan。除 GPM 外，公司名稱搜尋命中 CoPoS 的志聖名單。既有簡介與名單不等同完整公司書，但其內容無須再抄一遍。

## 共用架構

產品需求 → 工件與材料 → 製程操作 → 缺陷及控制 → 設備指標 → 個別公司證據。

每本計畫包含章節問題、先備、視覺需求、來源入口、待查事項、分批交付與驗收條件。三本都保留已確認／推論／待查三欄。詳細來源與本次取用限制見各書計畫。
