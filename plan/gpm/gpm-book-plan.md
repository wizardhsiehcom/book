## 定位

讀者：沒有半導體製程背景，但要看得懂均豪（5443）與先進封裝設備相關的公司消息、法說會與客戶需求。
讀完能做到：對任一則先進封裝新聞，走完「產品需求 → 封裝結構 → 製程步驟 → 缺陷與量測 → 設備需求 → 供應關係證據」六段推理，並說得出每一段的證據等級。

主線：**先建立封裝的物理與流程心智模型，再把設備需求推導出來，最後才拿均豪的公開證據去對號**——順序不可倒過來。全書反覆演練的動作是「把設備類別能做什麼」與「均豪已被證實供應什麼」分開。

不做的事：不寫成名詞百科、不寫成新聞彙整、不做投資建議、不把「某設備類別可用於某製程」寫成「均豪已供應該製程」。

1. **主體分離**：均豪（5443，母公司，Wafer 級檢量磨拋）／均華（6640，子公司持股約 56.8%，Die 級 Sorter・Bonder）／志聖（2467，交叉持股，前段設備）／東捷（2026 加入 G2C+）。合併報表數字不等於均豪本身產品的成績。
2. **證據分級**：每個供應關係標為 `[公司自述]`／`[雙方公告]`／`[媒體報導]`／`[業界消息]`／`[推論]`／`[未證實]`。未具名客戶（如「晶圓代工大廠」）不得自行補成特定公司。
3. **流程分級**：教學簡化流程、跨來源整理流程、公開技術文件流程三者分開標示。不同世代／版本（CoWoS-S/R/L、HBM3/3E/4、I-Cube 各版）不混寫。

## 每章統一格式（寫作模板）

1. **開場問題** — 具體產品或工廠情境
2. **先看結構** — 材料、工件、相對位置，再給名詞
3. **逐步製程** — 每步寫明「輸入 / 操作 / 輸出 / 目的」
4. **失敗會長什麼樣子** — 缺陷如何形成、影響什麼
5. **如何檢查與控制** — 量測方法與設備能力邊界
6. **與均豪的連結** — 三欄分列：已確認事實／合理推論／尚待查證；沒有證據就明說「本章無均豪公開證據」
7. **理解檢查** — 3–5 題推理題（用 `??? question` 摺疊答案）
8. **來源與待查** — 來源代號、日期、支持的主張
