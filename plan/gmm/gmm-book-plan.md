# 從晶粒分選到精密接合看懂均華 — 成書計畫

建立日：2026-09-10｜slug：`gmm`｜正文：`docs/gmm/`｜狀態：八章正文與出版整合完成；公司證據缺口列附錄 C。

## 定位

核心問題：切好的晶粒如何被辨識、挑起、翻轉、放準，並穩定交給下一站？讀者讀完能分辨 Sorter、取放、Die Bonder 與特定接合製程的差異；不會從「做 Bonder」直接推成「供應 HBM／混合鍵合」。

## 已寫內容與去重邊界

[工件流](../../docs/gpm/04-workpiece-flow.md)、[HBM](../../docs/gpm/08-hbm.md)、[混合鍵合](../../docs/gpm/09-soic-hybrid-bonding.md)、[KGD](../../docs/cowos/13-test-and-kgd.md) 已有基礎；SMT／ACF 原理參照 [SMT 書](../../docs/smt-bonding/README.md)，但不可把板級貼裝精度條件搬成晶粒接合條件。

沿用 [GPM 成書計畫](../gpm/gpm-book-plan.md) 的六段推理與八段章節模板。每章依序寫：開場問題、結構、輸入／操作／輸出、缺陷、檢查與控制、公司連結（已確認／推論／待查）、理解檢查、來源與待查。先備只做短摘要與跨書連結，不重寫既有章節。

### 本次架構回修

- 讀者起點：知道晶圓與晶粒的差別，但不需已有機構或計量背景；輸出能力為辨識分選、取放、對位、接合及供應證據的不同責任。
- F1／F2 法說提供 HBM 示意與 Bonder 營收分類，不能再籠統寫「均華公開資料沒有提 HBM」或「Bonder 全部僅研發」。型號／接合法／客戶量產配對仍未明。
- 第 08 章採三種來源案例：官方產品功能、2026 年法說、公開專利，避免重複三個只有活動日期的消息；每例含事實、推論、未知及翻案條件。
- 8 月法說第 6 頁 2026 F 未標百分比；第 9 頁 41% 是 H1 YoY，不移用。頁碼以封面起算的 PDF 頁序核對。
- 公式用有單位的純文字／程式碼算式，無需新增 MathJax；跨書連結指向書庫內相對 HTML，避免獨立站台保留失效 Markdown 路徑。
- 跨書連結使用行內 HTML anchor，保留相對 URL；MkDocs 只認本書 docs_dir，因此另對輸出做實際檔案／錨點核對，不降低整體連結檢查等級。
- 瀏覽器發現 Material 自動載入與共用 Mermaid 初始化偶發重複渲染。僅本書改用 `gmm-mermaid` fence class 與 `javascripts/diagrams.js` 單一初始化，保留 Mermaid 10；白底圖框支援亮／暗閱讀，十二欄矩陣保留欄寬與表內橫捲。不改其他書及共用資產。
