## 共用問題與术語

每個案例回答：工件與用途是什麼 → 在哪一步發現異常 → 哪些證據支持根因 → 有哪些處置選項 → 處置後如何驗證 → 公司公開能力支持到哪裡。

| 用語 | 本書系中的區分 |
|---|---|
| 重測 retest | 重新取得量測證據；不等於改變或修復產品 |
| 重工 rework | 重新加工以滿足要求；必須寫明可回到哪一步與重新驗證條件 |
| 修理／修復 repair | 說清楚恢復的功能、使用目的與允收依據，不與所有重工畫等號 |
| 電路編修 circuit edit | 用於工程修改及驗證；不自動代表量產出貨修復方案 |
| 再生 reclaim | 恢復特定用途晶圓的可用條件；不等於恢復原晶片電路 |
| 重新投片／改版 | 改善下一批產品，與救回原工件分開 |
| 降級／改作他用 | 須有目標用途與允收證據；不能當成任意放寬標準 |
| 報廢／材料回收 | 終止原用途與材料去向分列，回收不等於再生合格 |

上表是編輯用工作定義；正式正文引用標準時需對照該標準版本、適用產業與原文。避免發明跨公司通用處置規則。

## 證據與來源規則

1. 公司事實、通用技術與教學案例分開。每章公司連結固定分為「已確認事實／合理推論／尚待查證」。
2. 來源記錄包含 URL、標題、法人、發布日、資料期間、查閱日、原文段落或頁碼、能支持的主張與限制。網頁未標日期就寫未標示。
3. 前一輪已初查的官方網頁是研究起點，不代表本次完成逐章來源精讀。研究批次須重新開啟、保存適用段落及定位。
4. 能力不等於客戶採用，採購不等於驗收，通過驗證不等於量產收入。自製設備、代理設備、服務與合併營收分列。
5. 不把光阻剝離、清洗、解鍵合等正常加工自動稱為重工；公司提供這種設備，也不能證明它已用於某客戶的失效補救。
6. 所有允收值、化學配方、重工次數與可靠度結論都須有適用條件。缺少資料時保留未知，不填入通用數字。
7. 失效分析可能只提供證據，並不負責修好樣品；再生服務的工件也未必原本失效。各書開篇明示此差別。

## 每章格式與圖表

開場問題 → 工件剖面與用途 → 輸入／操作／輸出 → 異常與候選原因 → 檢查與處置分支 → 處置後驗證 → 公司證據三欄 → 3–5 題推理題 → 來源與待查。

必要圖以加工前後剖面、量測能力表、處置決策圖為主。每張圖標「官方流程」「跨來源整理」或「教學假設」。真實照片要核對授權，不冒充公司現場；精確工程示意優先 SVG／Mermaid。遵守 CLAUDE.md 的 Mermaid 引號與換行規則。

## 分工與去重

- 閎康負責「症狀到根因」及電路編修；辛耘只簡述定位後需要哪些加工條件。
- 辛耘負責「選擇性移除與損傷邊界」；昇陽引用原理，聚焦再生履歷、用途與回用資格。
- 昇陽負責循環次數、厚度預算與再生經濟性；辛耘雖有再生業務，僅在公司矩陣交代，避免重寫一整套循環模型。
- GPM 提供設備、缺陷與供應關係的延伸閱讀，不作新書的技術或公司一手證據。
- 記憶體冗餘修復、完整晶圓廠內部重工規範與板卡維修不列主線。必要時短文定位，避免宣稱三本涵蓋所有半導體修復。
