# 《衣物照護：從材質、洗滌到去污與保養》書籍計畫

建立日期：2026-09-22。Slug：`clothing-care`。狀態：初版書稿與網站已完成；嚴格建置、35 頁靜態檢查通過。圖表尚未逐頁完成視覺驗收，詳見第 11 節。

## 1. 定位與讀者

一本給一般家庭讀者的實用知識書，以繁體中文、台灣常見衣物及潮濕生活情境寫作。不要求化學或紡織背景，從「這件衣服是什麼、能承受什麼處理」開始，建立能自行判斷的照護方法。

全書主線：**辨識衣物 → 讀取限制 → 判斷髒污與目的 → 選擇處理方式 → 檢查結果 → 日常保養與收納。**

讀完應能：

- 分辨纖維成分、布料結構、加工與整件衣物構造，知道它們各自影響哪些處理選擇。
- 結合洗標、衣物狀態與產品說明，決定機洗、手洗、局部處理或交給專業清潔。
- 按污漬來源與材質限制查找處理流程，遇到未知污漬也知道先蒐集哪些資訊。
- 安排洗滌、乾燥、整燙與換季收納，辨認哪些損傷不適合繼續自行處理。

暫定 18 章、4 組附錄，正文約 40,000～55,000 字。字數是深度估算，不能為達標重複內容。以「原理能懂、操作可查、限制清楚」為編輯標準。

## 2. 範圍與分工

涵蓋棉、麻、羊毛、羊絨、蠶絲、再生纖維素纖維、聚酯、尼龍、壓克力、彈性纖維與混紡；兼顧針織、梭織、印花、塗層、襯裡、黏合與裝飾對整件衣物的限制。

實作涵蓋日常洗衣、局部去污、異味處理、乾燥整燙、起毛球與外觀維護、換季收納；情境涵蓋牛仔、運動機能衣、防水外套、羽絨、內衣與有結構的外套。皮革、麂皮僅寫辨識、日常照護與送洗界線。

不延伸成品牌採購榜、工業洗衣教科書、鞋包家具清潔百科、皮革修復或專業溶劑操作手冊。家庭照護與醫療感染控制分開，後者不在本書操作範圍。

避免重複的分工：材質章說明「限制從哪裡來」；流程章說明「共同操作如何安排」；去污章說明「依污漬如何調整」；情境章把前面知識組合成整件衣物的判斷。

## 5. 正文寫法與查詢設計

材質章固定回答：它是什麼 → 怎樣辨認 → 哪些性質影響照護 → 哪些成衣因素會改變判斷 → 常見失誤 → 連到共用洗衣與去污流程。不能只列出「可洗／不可洗」二分表。

操作頁使用一致格式：

1. **適用情境**：材質、洗標、污漬及必要工具。
2. **不適用與停止條件**：哪些情況需另查原廠說明或交專業處理。
3. **步驟與理由**：每步交代做什麼、觀察什麼，必要數值附來源及條件。
4. **結果判斷**：改善、無變化或出現異常時，各自下一步是什麼。
5. **失敗與限制**：舊漬、既往處理、未知染料等如何限制成功率，不保證完全恢復。
6. **來源與相關頁**：可追溯來源、材質限制及後續乾燥保養連結。

首頁提供三種入口：「從材質找」「從污漬找」「從症狀找」。速查頁指向完整操作，不把有條件的步驟壓縮成失去限制的一句偏方。

編輯時專門查核常見網路偏方，但不預先寫定它們有效或無效。涉及清潔用品混合，不提供自創配方；所有操作需符合已核實的相容性與產品說明。

## 8. 寫作批次與階段驗收

### 階段一：補來源與驗證架構

先補 S1、S2、S3、S4，確認洗標、材質與去污共用框架；再補 S5–S7 的成衣、設備與收納限制。將每章來源代碼換成實際書目或文件定位。

通過條件：各章有明確作用、前置概念有位置、操作主張有合適來源。資料不足的案例刪減、暫緩或縮限，不靠常識填補。

### 階段二：試寫 C11，再回修

試寫「污漬判斷與處理前檢查」，搭配一則可水洗日常衣物案例與一則需停止自行處理的案例；必要的 C02、C07、C08 概念在試寫時簡述並標記後續連結。

通過條件：沒有背景的讀者能辨認適用範圍、完成判斷並知道何時停止；章節沒有跳過材質和洗標直接給配方。依試寫修訂術語、操作模板及案例篇幅。

### 階段三：分批完成正文

1. C01–C06：完成衣物辨識與材質限制。
2. C07–C10：完成洗劑、洗滌與乾燥流程，回修 C11 的先備連結。
3. C11–C15：完成去污與問題診斷，各案例逐一核對適用條件。
4. C16–C18：完成成衣情境、損傷與日常保養。
5. 附錄、首頁與必要圖表：從已驗證正文整理索引，不另發明簡化規則。

每批更新下表，核對術語首次定義、重複內容、交叉連結和資料缺口；章節變動時同步記錄受影響的前後章。

### 階段四：全書與出版驗收

- 抽查棉質上衣、羊毛針織、蠶絲、彈性運動衣及有膜材外套，能否從入口找到材質限制與完整流程。
- 抽查血漬、油漬、咖啡、染色轉移、異味和未知污漬，是否能找到適用條件、結果檢查與停止條件。
- 所有具體數值、化學相容性及效果宣稱可追溯，不把纖維通則當成所有成衣的保證。
- 不承諾縮水、褪色或脫膠能完全復原；不把清潔效果與消毒效果混寫。
- 圖片授權、符號版本、圖文一致性、章節依賴及相對連結完成核對。
- 出版時依 repository 規範同步 assets，完成 nav、入口卡片與回書庫頁尾；執行 `uv run mkdocs build --strict -f configs/clothing-care.yml` 並檢視生成頁面。
