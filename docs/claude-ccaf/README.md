# Claude 架構師認證：CCAF 備考學習指南

一本以**情境中的架構判斷**為主線的繁體中文學習書。從工具迴圈開始，理解任務編排、MCP、Claude Code、結構化輸出與可靠性，再用實作和原創題目檢驗理解。

本書對應 **Claude Certified Architect – Foundations**。使用者常以 CCAF 或 CCA-F 稱呼；本書查覈的官方 Exam Guide v1.0，於 **2026 年 7 月生效**，列出的正式考試代碼是 **CCAR-F**。查覈日為 **2026-09-07**。[官方考綱與來源紀錄](appendix-sources.md)

!!! warning "讀之前先確認你報得了名"
    考綱沒有記載一般大眾是否可報名，而第三方指南普遍稱 CCAR-F 限合作夥伴企業員工。報名與排程要跨 Partner Academy 與 Pearson VUE 兩個平臺。**先花十分鐘確認資格，再投入四週準備。**[報考流程與考試政策](00-exam-map.md#報考流程)

## 讀完要能做到什麼

- 說明模型選工具與應用程式執行工具的差別，正確判斷停止狀態。
- 選擇固定流程、動態委派或平行調查，保留來源與狀態。
- 設計不容易誤選的工具，分清失敗、空結果與業務拒絕。
- 把 Claude Code 規範與 skills 放在適合的作用域，接入團隊與 CI。
- 區分 JSON 格式、schema、語意與證據品質，設計重試及人工檢查。

你需要能閱讀基本 JSON、Python 和 Git 專案。不要求先會所有 SDK；不熟悉的術語可查[英中術語表](appendix-glossary.md)。官方面向具有實務經驗的候選人，因此讀書後應完成[實作工作坊](11-labs.md)，不能只記憶名詞。

## 閱讀路線

| 目前狀態 | 建議路線 | 完成的證據 |
|---|---|---|
| 用過 Claude，沒寫過 Agent | 00 → 01–05 → 06–10 → 11 → 12 → 13 | 能追蹤工具往返並跑離線實驗 |
| 已做過 Agent 專案 | 00 任務對照 → 弱項章節 → 11 → 12 → 13 | 能解釋失敗與替代方案 |
| 考前總複習 | 00 → 各章自測 → 12 → 錯題對應章 → 13 計時 | 不看答案也能排除干擾項，且在時限內完成 |

主線分為三段：先讓系統**做對動作**（01–05），再讓團隊**重複做出可驗證結果**（06–08），最後在長任務與大量資料下**保留可靠性**（09–10）。

## 如何使用這本書

各章標明考綱任務，接著解說觀念、原創例子、失敗模式與自測。程式或設定若只供說明會明確標示；隨書可直接執行的 [offline_lab.py](examples/offline_lab.py) 不呼叫 API。

**考場是閉卷的**：禁止筆記、書籍與任何裝置。所以各章末的自測請當成真的測驗，能不看書答出來才算讀完；讀完有印象但答不出來，就回該章重讀，不要用「查得到」安慰自己。

本書是獨立學習材料，非 Anthropic 官方教材。情境題全為原創，數量與難度未校準成官方模擬考。報考流程、費用、重考與續證政策整理在[考試範圍與讀書地圖](00-exam-map.md)，但一律以[官方認證入口](https://anthropic-partners.skilljar.com/page/partner-certifications)的最新版本為準。
