# 附錄 B　術語表

一句話只定義這個詞指什麼結構、哪家法人或哪一種測試。誰在量產、誰拿下訂單，不是定義，要回到各章的證據等級。

| 術語 | 一句話 | 第一次出現 |
|---|---|---|
| SPIL | 矽品精密工業股份有限公司；2018-04-30 起為日月光投控百分之百持有的子公司，同年台股與 NASDAQ 下市。 | [01](01-who-is-spil.md) |
| ASE Inc. | 日月光半導體，與矽品並列、同屬投控的另一家封測子公司，不是矽品的簡稱。 | [01](01-who-is-spil.md) |
| ASEH | 日月光投資控股，台灣證交所 3711、紐約證交所 ASX，是集團合併財報的主體。 | [01](01-who-is-spil.md) |
| OSAT | 接受客戶委託、代為封裝與測試晶片的廠商類型，不是某一家公司的名字。 | [01](01-who-is-spil.md) |
| WLCSP | 在晶圓階段做完大部分封裝、成品尺寸接近晶粒本身的晶圓級晶片尺寸封裝。 | [04](04-mainstream-packaging.md) |
| FCBGA | 晶粒翻面、以凸塊接到球柵陣列基板的覆晶封裝。 | [04](04-mainstream-packaging.md) |
| CP | 晶圓尚未切割時，用探針接觸接墊做的晶圓針測。 | [05](05-testing.md) |
| FT | 封裝完成之後，透過測試座接觸外接腳的成品測試。 | [05](05-testing.md) |
| SLT | 在接近真實系統的板級或模組環境下做的系統級測試。 | [05](05-testing.md) |
| CoWoS | 台積電的 Chip-on-Wafer-on-Substrate 平台名稱；別的文件提到它，只表示被提到，不表示該公司供應整套。 | [06](06-interposer-era.md) |
| SLIT | Silicon-Less Interconnect Technology，先做堆疊、再整片移除矽中介層的互連作法。 | [06](06-interposer-era.md) |
| NTI | Non-TSV Interposer，不靠矽穿孔導通的中介層流程。 | [06](06-interposer-era.md) |
| FOPLP | 在矩形面板而不是圓形晶圓上做扇出重佈線的封裝作法。 | [07](07-fanout-to-fomcm.md) |
| FO-MCM | Fan-Out Multi-Chip Module，用扇出重佈線連接多顆晶粒，再把模組接到基板。 | [07](07-fanout-to-fomcm.md) |
| FO-EB | Fan-Out Embedded Bridge，在扇出重佈線裡埋入一小塊矽橋，只在需要高密度的地方走細線。 | [08](08-fo-eb.md) |
| FO-EB-T | 矽橋本身帶矽穿孔的 FO-EB，訊號和電源可以穿過矽橋。 | [08](08-fo-eb.md) |
| CPO | Co-Packaged Optics，把光引擎與交換或運算晶片放進同一個封裝模組。 | [09](09-cpo.md) |
| CoW | Chip-on-Wafer，把晶粒接到晶圓或中介層上的前段工序。 | [10](10-beside-tsmc.md) |
| oS | on-Substrate，把已經接好的模組接到封裝基板上的後段工序。 | [10](10-beside-tsmc.md) |
| WoS | Wafer-on-Substrate，把晶圓或中介層接到基板上的後段工序；新聞裡常與 oS 混用，本書不互相代換。 | [10](10-beside-tsmc.md) |
| CoWoP | Chip-on-Wafer-on-Platform PCB，把晶片與中介層直接接到平台電路板、省掉傳統封裝基板的架構名稱。 | [10](10-beside-tsmc.md) |
| CoPoS | Chip-on-Panel-on-Substrate，用面板而不是圓形晶圓承載這類堆疊的架構名稱；集團文件列名不等於矽品的角色已經寫明。 | [10](10-beside-tsmc.md) |
| EFB | Elevated Fanout Bridge，AMD 新聞稿用來稱呼晶圓級 2.5D 橋接互連的名稱；縮寫本身不等於某一家已經量產。 | [13](13-customers-suppliers.md) |
