# 附錄 A　來源索引

查閱日一律為 **2026-10-12**。正文的來源代號都要回到本頁。等級只能往下標，不能因為敘事完整就往上調。

## 證據等級

| 等級 | 一句話 |
|---|---|
| 官方文件 | 向主管機關申報，或由主管機關發布的文件。 |
| 雙方公告 | 交易或合作的兩邊都各自公開講過同一件事。 |
| 論文 | 有作者單位與 DOI 的論文；摘要以外未核全文。 |
| 公司自述 | 公司官網、新聞稿、法說或高層公開談話。 |
| 媒體報導 | 媒體以自己的採訪或具名來源寫成的報導。 |
| 業界消息 | 引述沒有名字的「業界」「據了解」。 |
| 推論 | 把消息接起來的判斷，不是新的事實。 |

公司自述只證明「公司這樣說過」。論文寫通過認證，仍然只證明論文這樣寫。
