# 從封裝測試看懂矽品

矽品已經下市，也不再單獨公布財報。新聞裡的「矽品」到底指誰？它的技術和產能，又能被公開證據證實到哪一步？

這本書先把三個常被混稱的主體拆開，再沿著矽品自己公開過的技術往下走：現在還在接單的基本盤、2014 年前後的中介層、扇出多晶片、埋在扇出裡的矽橋，然後才是光進封裝。最後拿產能、客戶與購廠新聞來練習同一件事：論文或平台「做得到」，和公開資料已經證實的量產或供貨，是兩句不同的話。

## 這本書假設你已經知道什麼

你分得清晶圓和晶片，也會讀半導體新聞，但沒有封測背景。不必先讀完其他書。日月光的法人關係、CoWoS 怎麼分段、扇出的通則，本書只連過去，不重講。

## 讀完之後你能做什麼

對任一則矽品消息，依序回答四件事：

1. **主體是誰**：矽品、日月光半導體，還是日月光投控？
2. **談的是哪一層**：技術平台、製程段落，還是客戶量產？
3. **證據等級到哪裡**：誰說的，說到什麼程度？
4. **什麼觀察會推翻這個判斷**：下一份文件出現時，哪一句要改寫？

說得出「這則新聞證明不了什麼」，和說得出它證明了什麼，同樣算讀完。

## 三條紀律

**先分開三家公司。** 矽品精密是投控百分之百持有的子公司；日月光半導體是另一家子公司；日月光投控才是公布合併財報的那一家。投控文件寫「集團做得到」的技術或產能，不能直接算成矽品的能力。群創南科那座廠，賣方公告把買方寫清楚之前，本書不把它算進矽品的廠。

**先看這句話是誰說的。** 官方文件、雙方都公告過的合作、論文、公司自己的網頁和談話、媒體報導、沒有具名的業界消息、以及把消息接起來的推論，由硬到軟。等級只能往下修，不能因為數字寫得很具體就往上抬。論文寫「通過認證」，只代表那篇論文這樣說，不是客戶已經下單量產。

**先問是哪一代、哪一年。** 2014–2016 年的矽中介層、2019 年的扇出多晶片、2020 年埋進扇出的矽橋、2021 年起矽橋再加矽穿孔，是前後相接的不同做法，不能收成「矽品的先進封裝」一句話。時效性數字要帶期間、是哪一家的數字、單位，以及查到的日期。

互相衝突的日期和買方，[來源索引](appendix-sources.md)裡並列，不挑一個當成定論。還沒查到的項目在[待查事項](appendix-open-questions.md)，那是證據缺口，不是還沒寫的章。

**本書不預測股價、不給買賣建議、不建估值模型。**

## 和鄰近幾本書怎麼分

[日月光書的法人篇](../../ase/html/02-group-and-business.html)已經寫過投控、日月光半導體、矽品、環旭的關係，也寫過 2018 年下市，以及反壟斷要求兩家獨立運作到 2020 年。那些沿革這裡不重抄。本書補的是矽品自己的廠區和購廠。日月光書如何把服務證據停在集團層級、不自動分給某一家子公司，見[服務與廠區證據](../../ase/html/10-ase-service-evidence.html)。

CoWoS 怎麼分成前段與後段、台積電自己的產能怎麼讀，分別在[競爭技術](../../cowos/html/09-competing-technologies.html)和[產能與經濟](../../cowos/html/15-capacity-and-economics.html)。那本書裡「矽品約 6–8 萬片」和「矽品主導 CoWoP」兩句，寫作時沒有核到原始出處。本書不把這兩句當成已證實的矽品事實，只問公開資料把矽品放在哪一段。

[均華的產品證據](../../gmm/html/07-gmm-product-evidence.html)已記錄均華官網把矽品列為客戶，而且只到公司名稱，沒有對到機型。本書沿用這條界線，不補型號。

[均豪的產品地圖](../../gpm/html/15-gpm-product-map.html)寫到的「日月光高雄廠」是日月光的廠，不是矽品。均豪董事長 2024 年受訪提到矽品是該公司第一家半導體客戶，本書只把它當成當時的歷史關係，不能推成現在仍有出貨。

扇出與面板級封裝的通則在[扇出與面板級封裝](../../copos/html/04-fan-out-and-foplp.html)。本書不重講原理，只寫矽品論文裡出現過的版本，以及 2014 年之後產線狀態查不到這件事。
