# 附錄 B：術語與不可互換的概念

| 術語 | 本書用法 | 最容易混淆的邊界 | 首次主要說明 |
|---|---|---|---|
| Panel／面板 | 矩形加工工件的形態之一 | 面板尺寸相同不代表材料、翹曲與製程相同 | [01](01-capability-baseline.md) |
| Carrier／載具或載板 | 依情境提供承載、支撐或搬運的物件 | 應辨認它是加工標的還是支撐物 | [01](01-capability-baseline.md) |
| EFEM | Equipment Front End Module，設備前端搬運／整合模組 | 搬運精度不是下游加工精度，產品頁不證明支援所有通訊協議 | [01](01-capability-baseline.md) |
| TGV | Through-Glass Via，玻璃通孔 | 雷射改質不是已完成蝕刻、金屬化與電性合格的通孔 | [01](01-capability-baseline.md) |
| RDL | Redistribution Layer，重布線層 | 幾何量測、外觀檢查與電性驗證是不同任務 | [01](01-capability-baseline.md) |
| OM／AOI | 本書分別指光學顯微／量測相關設備用語與自動光學檢查 | 按產品原名閱讀，不因都有影像就視為同一台設備 | [01](01-capability-baseline.md) |
| Bump／Cu pillar | 凸塊／銅柱，為互連幾何結構 | 量測高度或共平面不自動證明接合後可靠度 | [05](05-contrel-product-evidence.md) |
| Chipping／崩邊 | 工件邊緣局部缺損 | 必須指定尺寸定義、測法、抽樣位置與材料 | [02](02-transfer-gap.md) |
| HAZ | Heat-Affected Zone，熱影響區 | 它與崩邊、裂紋及粗糙度不是同一指標 | [01](01-capability-baseline.md) |
| Ra | 算術平均粗糙度指標 | 一個平均值不等於整條邊緣都無缺陷 | [02](02-transfer-gap.md) |
| Accuracy／精度或準確度 | 依文件定義讀取，正文保留來源用詞 | 對位精度、加工結果、重現性不能互換 | [02](02-transfer-gap.md) |
| 3σ 重現性 | 原產品頁以三倍標準差形式標示的重現性 | 不代表絕對準確度；樣本與跨日／跨機條件仍待查 | [01](01-capability-baseline.md) |
| µm/pixel | 成像時每像素對應的物方尺度 | 不是無條件缺陷檢出下限 | [01](01-capability-baseline.md) |
| UPH | Units Per Hour，每小時產出單位數 | 須指定產品、步驟、等待及運轉條件；直線速度不能直接替代 | [02](02-transfer-gap.md) |
| VC-B | 型錄列出的場地振動條件代號 | 本書未引用其完整曲線或合格判準；不當成機台精度證書 | [02](02-transfer-gap.md) |
| ESD | Electrostatic Discharge，靜電放電 | 有除靜電裝置不等於工件已通過完整靜電風險驗證 | [01](01-capability-baseline.md) |
| ICD | Interface Control Document，接口控制文件 | 用來共同界定實體、狀態、資料與責任，不只是接頭圖 | [03](03-integration-acceptance.md) |
| Recipe／配方 | 設備執行加工或檢測的一組設定與版本 | 同名配方不一定相同版本，變更後要確認有效範圍 | [03](03-integration-acceptance.md) |
| Host／MES | 上位主機／製造執行系統 | 連線成功不等於工件與結果的語意一致 | [03](03-integration-acceptance.md) |
| SEMI E84 | 自動載具交接平行 I/O 接口標準 | 不等於所有機械手動作、host 通訊或整機製程驗收 | [03](03-integration-acceptance.md) |
| GEM／SEMI E30 | 設備通訊與控制的共通行為模型 | 相容性需版本、功能範圍與測試證據，不是良率認證 | [03](03-integration-acceptance.md) |
| FAT／SAT | 供應商端／客戶現場驗收的常見工程用語 | 測試、付款、接受及放行效果依合約，不由縮寫決定 | [03](03-integration-acceptance.md) |
| Qualification／資格確認 | 評估約定產品與條件下的製程或設備能力 | 資格確認的範圍須明列，不等於所有產品全面適用 | [03](03-integration-acceptance.md) |
| Release／量產放行 | 依授權及證據允許特定範圍的生產 | 功能驗收或資格測試完成後，仍需對應的放行決定 | [03](03-integration-acceptance.md) |
| GR&R | 量測系統的重複性與再現性研究 | 需要說明樣本、操作者或條件及變異定義，不由像素數推得 | [05](05-contrel-product-evidence.md) |
| MTBF | Mean Time Between Failures，平均故障間隔時間 | 需有故障定義與觀察資料；型錄運轉環境不能替代可靠度統計 | [02](02-transfer-gap.md) |
| RACI | 執行、負最終責任、諮詢與知會的分工方式 | 專案責任表不是本書已取得的聯盟合約 | [04](04-alliance-delivery.md) |
| SLA | Service Level Agreement，服務水準協議 | 一站式服務口號不會自動產生回應時間或保固承諾 | [04](04-alliance-delivery.md) |
| PO | Purchase Order，採購訂單 | 接單不是出貨、驗收、量產或收入的同義詞 | [04](04-alliance-delivery.md) |
| IP | Intellectual Property，智慧財產權 | 有產品頁不代表所有模組、背景技術與共同成果皆為同一方所有 | [01](01-capability-baseline.md) |

本表是閱讀輔助，不是標準定義全文。公司規格與協議範圍的原始出處見[來源索引](appendix-sources.md)。
