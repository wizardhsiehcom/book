# 05　哪些是東捷產品，哪些仍是合作主張？

## 開場問題：一張聯盟簡報，能不能直接變成東捷產品清單？

不能。簡報可能同時包含自家產品、夥伴產品、研發方向與產業流程。若省略每一格的主體與階段，讀者就會把「聯盟有方案」看成「東捷有全部機型」，再把「有機型」看成「已取得量產收入」。

本章只回答本書前四章尚未集中處理的問題：**每一項公開主張，究竟能歸到哪個法人、產品與交付階段？** 下列「東捷產品」指以東捷名義公開列示的設備；不代表已證明全部 IP、關鍵模組與製造權都歸東捷。表中沒有以未公開資料補上客戶名字。

## 先看結構：產品歸屬、交付與收入是三條不同的線

| 要判斷的事 | 本次資料能提供什麼 | 還需要什麼 |
|---|---|---|
| 產品歸屬 | 公司官網與型錄上的產品名稱／型號 | 若問全部自研自製，需 IP、設計與製造權資料 |
| 交付階段 | 法說的開發、推出或歷史接單主張 | 型號對應、訂單、出貨、安裝、驗收與量產紀錄 |
| 收入歸屬 | 本次未取得可逐機型核對的收入資料 | 契約供應範圍、履約義務及會計揭露；不能只看聯盟標誌 |

出貨、FAT／SAT 與會計收入可能依契約有不同關係。即使得到驗收消息，也不能單靠縮寫推定何日、由誰、以多少金額認列收入。這是查證邊界，不是在斷言東捷採取某種會計處理。

## 缺陷：最容易拼錯的不是數字，而是列與列的關係

P1 切割與 P2 改質都處理玻璃，但前者改變外形，後者為通孔製程的前段處理；**名字相近不等於同一機台能交付完整通孔**。P4 的三個產品同屬 RDL，更不能把 OM 的微觀像素、線路機的照明與 3D 的重現性合成不存在的機型。

同樣地，I1 是 2024 年簡報對更早里程碑的回顧。若在 2026 年看到這頁，不能把當年的「持續接單」改寫成最新年度訂單成長。I2 與目前產品頁的對應，也要保留版本缺口。

最終檢查方法是問：**若把同一列的來源抽掉，剩下哪些字是作者自己加上的？** 「量產」「已驗收」「某大廠」「全自製」若沒有對應證據，不能因合理或常見就填入。

## 理解檢查

??? question "如果明天公布 GLDR 某型號出貨，矩陣哪些欄可以更新？"
    可更新來源、日期與該型號的出貨階段。仍不能把另一尺寸型號、全部 TGV 後段流程或客戶量產驗收一併升級。

??? question "為什麼 I1 的持續接單不能填成 2026 年訂單成長？"
    因為發布日與里程碑日期都有時間邊界；原文沒有最新期間、比較基期、台數或金額，也未對應目前每一型號。

??? question "P4 的 3σ 重現性 1 µm 能否證明可可靠檢出所有 1 µm 缺陷？"
    不能。量測重現性與缺陷檢出是不同指標；還缺樣本、真值、缺陷種類、成像與判定條件。不可把單一數字跨任務使用。

??? question "聯盟客戶完成 SAT，是否就能把收入填到東捷一列？"
    不能。需先確認東捷是否為該交易的供應與簽約主體，以及契約和會計揭露如何界定履約；聯盟名稱不足以回答。
