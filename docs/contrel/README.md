# 從設備整合到量產交付看懂東捷

看到東捷的玻璃切割、TGV、面板檢測或 G2C+ 聯盟消息，應先問的不是「能帶來多少營收」，而是：**公司公開的哪項能力，在哪種工件與條件下，走到哪個交付階段？**

本書用六章走完這條推理：公開產品 → 能力遷移缺口 → 整合與驗收 → 聯盟責任 → 產品證據 → 新聞判讀。讀完應能拆開設備規格、合作定位與客戶接受結果，知道何時可以下結論、何時必須停在待查。

## 先給結論，但保留邊界

東捷官網已公開玻璃切割、TGV 雷射改質、雷射修整、RDL 檢量測與 EFEM 等產品；官方亦提出聯盟協作與樹谷廠擴產方向。[來源索引](appendix-sources.md)逐項列出主體、日期與支持範圍。

**本書核讀的資料尚不足以把特定聯盟機型、客戶驗收、量產與收入逐一連回東捷。** 這不等於沒有訂單，也不等於技術沒有價值；它表示公開產品與完整交付證據之間還有一段必須查清的距離。

## 適合誰讀、怎麼讀？

適合已聽過先進封裝，但想更精確閱讀設備公司消息的人。不需要先懂雷射光學或合約條文；工件與載具不熟悉時，先回讀[工件流](../../gpm/html/04-workpiece-flow.html)。

## 本書使用規則

公開資料查閱日為 **2026-09-11**，不是所有文件的發布日。公司型錄規格仍屬公司自述，未標測試條件時不自行補齊；未具名客戶維持未具名。歷史「接單」不改寫成最新訂單，設備「驗證」不改寫成已驗收，來源查不到不等於現實中不存在。

每章把已確認的公開主張、合理推論與待查分開。流程、控制矩陣和算例均為原創教學整理，不是東捷內部資料、實際產線設計或投資建議。全書不重講 OEE、人力編制或封裝平台史，改以跨書連結補先備。
