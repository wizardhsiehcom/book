## 對職務的訊號

### 記憶體與 HBM

WSTS 預測顯示 2026 成長高度集中在記憶體。HBM 又把 memory design、TSV／bonding、先進封裝、多階段測試、熱與系統驗證綁在一起，因此值得關注跨 die 的產品、測試與封裝能力。但景氣循環與供給擴張也會放大波動，不能把單年高成長當永久缺工。

### 先進邏輯與設計複雜度

GAA、背面供電、chiplet 與多晶粒整合提高 design-technology co-optimization、physical design、sign-off、DV、DFT 與 silicon bring-up 的協作密度。職缺是否增加仍應回到公司招募頁；技術複雜度本身不是招聘數量證明。

### 先進封裝、測試與可靠度

AI 系統的頻寬、功耗與散熱限制，使 CoWoS／SoIC、hybrid bonding、CPO、KGD/KGSD、ATE 與 system-level test 更重要。這些工作跨越封裝、測試、FA、可靠度與客戶系統，不宜只歸為單一「封裝工程師」。

### 智慧製造

SEMI 的智慧製造議題涵蓋資料互通、設備自動化、預測維護與資安。實務上需要 MES／CIM／AMHS、設備與製程 domain knowledge，以及資料工程共同交付；「會訓練模型」不等於能把系統部署到量產線。

## 求職時怎麼驗證趨勢

1. 用產業預測決定要追蹤的技術，不用它推算自己的 offer。
2. 用公司年報與技術論壇確認投資、產品節點與量產進度。
3. 用公司招募頁確認地點、職級、班別與實際交付物。
4. 用求職平台看同一時間點的職缺結構，保留搜尋日期與篩選條件。
5. 每季重查；「熱門」不代表免受庫存、資本支出與產品週期影響。
