# 入職門檻與學習規劃

學位不是職級，科系也不是唯一入口。真正要對齊的是職務交付物、最低學歷、基礎課程與可證明的能力。

## 先依職務型態分流

| 職務型態 | 市場常見要求 | 準備重點 |
|---|---|---|
| IC 設計、演算法、系統、軟體與多數研發 | 碩士常見；部分職缺接受學士或等同經驗 | 電路／CS 基礎、專題、程式與工具實作 |
| Analog layout、部分 digital implementation | 大專以上可見，仍依公司與產品而異 | 版圖作品、DRC/LVS/PEX、timing／P&R 基礎 |
| 製程、整合、元件與先進研發 | 電機、材料、化工、物理等；研究型職缺可能偏好博士 | 製程整合、元件物理、統計與實驗設計 |
| 設備、製造、技術與維修 | 學士／專科入口較多，部分職缺科系不拘 | 機電、故障排除、安全、輪班條件確認 |
| 封裝、測試、品質與可靠度 | 電機、機械、材料、化工；依角色偏設計或量產 | 統計、材料／熱機、測試、品質系統 |
| IE、CIM、AMHS、智慧製造 | 工工、資工、自動化、數學統計等多背景 | SQL／Python、最佳化、MES／資料流與現場理解 |

經濟部 2026–2028 IC 設計人才調查中，除佈局工程師最低學歷列為大專，其餘受調查職務多列碩士；這是特定產業調查，不代表所有公司與職缺。另一方面，104 的 2025 年 4 月平台資料顯示，科系不拘比例在操作／技術／維修類為 58%、生產製造／品管／環衛類為 38%、研發類為 23%，說明現場職務通常比研發職務有更大的科系彈性。

## 科系只是能力代理

| 目標 | 常見相關背景 | 面試前至少能說清楚 |
|---|---|---|
| 數位設計／DV／DFT | 電機、電子、資工 | RTL、時序、計算機組織、驗證或測試架構 |
| 類比／RF／SerDes | 電機、電子、物理 | 元件、回授、雜訊、PVT／Monte Carlo、量測 |
| Physical Design／EDA | 電機、資工 | synthesis、STA、P&R、演算法與 scripting |
| 製程／設備／整合 | 材料、化工、物理、電機、機械 | 製程流程、SPC、RCA、機電或真空／電漿基礎 |
| 封裝／可靠度／FA | 材料、機械、電機、化工 | 熱機應力、材料、失效機制、量測與證據鏈 |
| AI／compiler／智慧製造 | 資工、電機、統計、工工 | 資料品質、模型／compiler、效能指標與部署限制 |

## 學位怎麼選

- **學士／專科**：適合直接累積量產、設備、測試、版圖或軟體實作；是否能進研發取決於作品與職缺，不是制度上禁止。
- **碩士**：對需要專題深度與工具經驗的 IC 設計、演算法、製程研發最直接；研究題目最好能對應目標職務的交付物。
- **博士**：適合需要原創研究、元件／材料、演算法或先進製程深度的職缺；不保證直接取得資深職級或較快升遷。

## 用作品取代空泛證照

優先留下能被追問的證據：RTL＋驗證結果、layout＋DRC/LVS/PEX、製程 DOE／SPC 分析、故障排除紀錄、測試程式、良率分析、compiler pass、資料 pipeline 或可重現的模型效能。Cadence、Synopsys 等課程可協助學工具，但課程證明本身不等於量產能力。

## 轉職不是固定年限路線

設備轉製程、測試轉 DFT、製程轉整合、FAE 轉產品等都可能發生，但沒有可靠資料支持固定「3–5 年」或「5–7 年」。判斷可攜性時，比對兩邊共同的交付物、工具、domain knowledge 與責任範圍。

## 面試前確認

- 職務最低學歷與科系是硬門檻，還是 preferred qualification？
- 團隊收新鮮人後提供哪些訓練，何時開始獨立值班或 sign-off？
- 是否輪班、on-call、假日值班？交接與待命是否計入工時？
- 評等看專案、良率、機台、coverage、客戶還是營運 KPI？
- 這份工作兩年後可證明的成果是什麼？
