# 薪酬資料與 offer 比較方法

半導體薪酬常把底薪、固定月數、績效獎金、分紅、輪班津貼、加班費與股票混在一起。不同資料若母體不同，就不能排成同一張「職務薪資排行榜」。

## 三層資料口徑

| 層級 | 可回答 | 不能回答 |
|---|---|---|
| 政府產業統計 | 某產業分類的平均經常性薪資、非經常性薪資與全年總薪資 | 單一公司、職務、年資或 offer |
| 求職平台職務統計 | 該平台履歷／職缺樣本中的職務中位數與分布 | 全產業真實行情；樣本定義不明時也不能比較新鮮人 |
| 公司公開揭露 | 全公司平均薪資、獎金或人事成本 | 特定職級、部門與個人可拿到的總酬勞 |

匿名社群可用來發現分紅遞延、值班或工時等問題，但自選樣本、年份與職級常不完整，不宜拿來建立精確區間。

## 可驗證的市場基準

### 產業層：電子零組件製造業

主計總處薪情平台的「電子零組件製造業」涵蓋半導體以外業者。2025 年該分類平均全年總薪資為 **1,332,924 元**，2024 年為 **1,228,272 元**。這可觀察大分類變化，不能稱為「半導體工程師平均年薪」。

### 職務層：104 平台中位數

104 與工研院於 2025 年 5 月發布的人才報告，列出平台樣本的年薪中位數（P50）：

| 職務 | 年薪中位數 |
|---|---:|
| 類比 IC 設計工程師 | 1,782,178 元 |
| 數位 IC 設計工程師 | 1,565,458 元 |
| 韌體工程師 | 1,426,317 元 |
| 電信／通訊系統工程師 | 1,324,609 元 |
| 演算法工程師 | 1,291,886 元 |
| 半導體工程師 | 1,149,161 元 |
| 半導體製程工程師 | 1,065,736 元 |

這些是平台職務樣本，並非同公司、同學歷、同年資的新鮮人 offer，也不應外推到 Staff／主管。

### 公司層：平均值不是 offer

台積公司 2025 年個體財報揭露平均員工薪資與獎金約 **409.3 萬元**，平均勞動成本約 **442.5 萬元**。母體包含不同職務、年資、地區與獎酬，因此只能描述公司整體，不能當成工程師起薪或保證所得。

## 比 offer：先把欄位拆開

至少把以下項目放進同一張表，並註明保證或變動：

| 欄位 | 要確認的問題 |
|---|---|
| 固定現金 | 月薪、保證月數、固定津貼是否寫入契約？ |
| 變動現金 | 績效、分紅的公式、發放月份與到職比例？ |
| 股權 | RSU／股票的授予日、vesting、匯率與離職處理？ |
| 工時成本 | 班別、on-call、加班費、補休、交通與交接時間？ |
| 遞延風險 | 第二年才發的獎金，離職或留停是否失效？ |
| 非現金項目 | 退休提撥、保險、宿舍、餐食、搬遷與訓練綁約？ |

可用三個情境比較：

- **保守值**：只計合約保證現金與已確定 vest 的股權。
- **基準值**：加入公司書面說明、可追溯歷史或明確公式的變動薪酬。
- **樂觀值**：把高績效、股價與匯率上行情境另列，不能混進保證值。

若工作型態不同，再計算「可支配時薪」：年度可得現金除以實際工作、值班與通勤時間。它不是法定工資計算法，而是個人決策工具。

## 面試與核薪時要問

1. 報價的「年薪」包含哪些項目，哪部分有保證？
2. 獎金按曆年、會計年度還是到職週年計算？首年是否按比例？
3. 輪班、夜班、on-call 與加班如何計薪或補休？
4. 股票用授予價、目前市價還是預估價計算？vesting 幾年？
5. 職稱對應哪個內部職級與責任範圍？何時重新檢視薪酬？
