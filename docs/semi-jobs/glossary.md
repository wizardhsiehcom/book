# 半導體職務術語表

同一縮寫在不同公司可能有不同邊界；面試與協作時仍要確認實際交付物。

| 術語 | 意義 |
|---|---|
| AE / FAE | Application Engineer／Field Application Engineer，協助產品導入、除錯與客戶技術溝通 |
| AMHS | Automated Material Handling System，自動搬運晶圓盒與在製品的系統 |
| ATE | Automatic Test Equipment，晶圓或成品電性測試設備 |
| ATPG | Automatic Test Pattern Generation，自動產生結構測試向量 |
| BIST / MBIST | Built-In Self-Test／Memory BIST，晶片內建自我測試，後者針對記憶體 |
| CAD / EDA | Computer-Aided Design／Electronic Design Automation；半導體語境多指設計工具、流程與自動化 |
| CAPA | Corrective and Preventive Action，矯正與預防措施 |
| CDC / RDC | Clock／Reset Domain Crossing，跨時脈／重置域檢查 |
| CIM / MES / MCS | 製造電腦整合／製造執行／物料控制系統，邊界依工廠架構而異 |
| CoWoS / SoIC | 台積電先進封裝與 3D 整合技術家族；不能當成所有先進封裝的通稱 |
| CPO | Co-Packaged Optics，將光電元件與運算／交換晶片近距離整合 |
| Coverage | 驗證或測試覆蓋率；須說明 functional、code、fault 等種類與 sign-off 條件 |
| DFT | Design for Testability，在設計中加入 scan、BIST、test access 等可測試性結構 |
| DRC / LVS / PEX | 設計規則檢查／版圖與電路比對／寄生參數萃取 |
| DV | Design Verification，設計驗證；可能包含 simulation、formal、emulation 等 |
| EUV / DUV | 極紫外光／深紫外光微影 |
| FA | Failure Analysis，利用電性、物理與化學分析定位失效根因 |
| FDC / SPC / WAT | Fault Detection and Classification／統計製程控制／晶圓允收測試 |
| Fabless / Foundry / OSAT | 無晶圓廠設計公司／晶圓代工／委外封裝測試服務商 |
| HBM / DRAM / NAND | 高頻寬記憶體／動態隨機存取記憶體／NAND 型快閃記憶體 |
| KGD / KGSD | Known Good Die／Known Good Stacked Die，已通過既定測試的裸晶／堆疊裸晶 |
| NPI | New Product Introduction，新產品導入量產 |
| On-call | 非正常班別期間待命處理事件；待命與實際處理工時應向公司確認 |
| P&R / STA | Place and Route／Static Timing Analysis，實體實作與靜態時序分析 |
| PDK | Process Design Kit，把製程規則、模型與設計工具連接起來的設計套件 |
| PE / EE / PIE | Process／Equipment／Process Integration Engineer；公司內縮寫可能不同 |
| PVT | Process、Voltage、Temperature，設計驗證常用的製程、電壓與溫度條件 |
| RCA | Root Cause Analysis，根因分析 |
| RTL | Register-Transfer Level，以暫存器與資料傳輸描述數位硬體 |
| Sign-off | 依事先定義的標準確認可進入下一階段，不代表零風險 |
| Tape-out | 將完成簽核的設計資料交付製造 |
| Yield | 良率；須說明 wafer、die、assembly、test 或 final yield 的分母與階段 |

職務之間如何交換這些交付物，見[職務合作關係圖](20-collaboration.md)。
