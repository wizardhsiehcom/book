# 導讀：資料壓縮的理論與應用

這本書解釋兩個問題：**資料要完整還原時，平均能壓到多短？容許部分失真時，檔案大小和品質又該如何取捨？** 內容依史丹佛大學 2023 年 EE274《Data Compression: Theory and Applications》課程整理。

先想一個小問題：資料只有 A、B、C、D 四種符號，若每個符號都用兩個位元表示，很容易解碼。但如果 A 比其他符號常見，能否把 A 寫短一點，讓整份資料變小？又該如何避免短編碼和長編碼混在一起，讀不出原文？前幾章會用同一類問題帶出編碼、機率與熵。

本書適合想理解壓縮原理、能閱讀基本公式的讀者。會用到機率、加權平均與以 2 為底的對數；實作材料使用 Python。不熟悉某個演算法名稱時，先看它要解決的問題，再讀定義與推導。

## 全書架構

本書分為兩大部分：

1. **無失真壓縮（Lossless Compression）**（第 1 ~ 10 章）：
   - 先要求解碼後完整還原資料，再用熵（Entropy）理解指定資料模型下的平均碼長下界。
   - 學習 Huffman 編碼、算術編碼（Arithmetic Coding）與 ANS（Asymmetric Numeral Systems）如何表示資料。
   - 接著讀 LZ 系列演算法（如 Gzip 所用的方法）與大型語言模型（LLM）在文字壓縮中的用途。

2. **失真壓縮（Lossy Compression）**（第 11 ~ 18 章）：
   - 先定義容許的失真，再用率失真理論（Rate-Distortion Theory）研究所需的資料量。
   - 學習轉換編碼（Transform Coding），包含離散餘弦轉換（DCT）。
   - 比較 JPEG、BPG 與學習型影像壓縮（用資料訓練模型來編解碼）的方法。
   - 最後看人類視覺與視訊壓縮，理解影音串流中的大小與品質取捨。

這本書的內容源自 2023 年由 Kedar Tatwawadi, Shubham Chandak, Pulkit Tandon 與 Tsachy Weissman 等人教授的 EE274 課程。我們會保留課程中直觀的類比與生動的實驗，並把口語的講解轉化為易讀的書面知識。

## 先用三個問題檢查自己

| 讀完 | 試著回答 |
|---|---|
| [第 1 章](01-intro.md) | 已知各符號的機率與碼長，怎麼算平均要用多少位元？ |
| [第 2 章](02-prefix-free.md) | 碼字連在一起時，為何仍能知道每個符號在哪裡結束？ |
