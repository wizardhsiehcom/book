# 詞彙表

定義只服務這本書的用法。更細的條件在各頁。

| 詞 | 在本書的意思 |
|---|---|
| 程序 | 作業系統排程與資源記帳的一個執行個體，有自己的 PID 與虛擬位址空間 |
| PID | 程序的識別號碼。它指程序，不指程式檔名 |
| 退出狀態 | 程序終止時交給父程序的狀態。0 通常被約定為成功 |
| zombie | 已終止、狀態還沒被父程序取走的程序。父程序若丟棄子程序狀態，就不會留下 |
| 執行緒 | 共享所屬程序位址空間的一條控制流 |
| 並行 | 多條控制流的執行區間重疊 |
| 平行 | 這些控制流真的同時佔用多個執行單位 |
| 虛擬位址 | 程序指令裡使用的位址。有 MMU 時再譯成實體位址 |
| 借用 | 使用別人擁有的資料，不因此延長那份資料的壽命 |
| flush | 把語言或函式庫的使用者空間緩衝交給底層 |
| fsync | 對一個已開啟的檔案描述符，要求把資料送到關聯的儲存裝置 |
| 發布 | 本書的檔案實驗裡，指同目錄 `rename` 之後正式名稱指向完整內容 |
| 名稱解析 | 把主機名換成一組可用來建立 socket 的位址 |
| port | 傳輸層上區分服務的號碼。要搭配位址與是誰在 listen |
| 位元組流 | TCP 交給應用的依序位元組。沒有保留 send 的邊界 |
| 定界 | 應用自己規定怎樣才是一筆完整訊息 |
| 狀態碼 | HTTP 回應列上的三位數，描述這次請求的結果 |
| 事件迴圈 | 在一條控制流上輪流推進各個 Task 的排程器 |
| 邏輯競爭 | 每步看起來有同步，但組合起來的不變條件仍會破 |
| data race | C++ 裡潛在並行、衝突、又沒有 happens-before 的存取。行為未定義 |
| 背壓 | 接收端跟不上時，來源阻塞或被拒絕的政策 |
| 剩餘預算 | 從單調時鐘的截止點扣掉已經用掉的時間 |
| 未知 | 客戶端沒有獨立證據能把工作收成成功或失敗 |
| 就緒 | 可以接受新工作。與程序已啟動、連線可建立分開 |
| drain | 停止接收新工作，並把已接受的工作收成完成或明確未完成 |
| nearest-rank | 本書 L10 使用的分位算法：排序後取 `ceil(p×n)` 那個樣本 |
