# 術語表

本表是本書的編輯用工作定義，目的是讓跨章推理不會偷換概念。**遇到合約、標準或客戶規範使用不同定義時，以該文件的範圍為準，並記錄差異**；不要把本表當成業界一致的規格。

## 一、證據鏈的四個詞

這四個詞是全書骨架。混用它們，就會把「看到一個異常」說成「找到根因」。

| 術語 | 本書定義與提醒 | 首次完整解釋 |
|---|---|---|
| 症狀 symptom | 測得的異常行為本身（某腳位恆低、待機電流偏高、特定頻率下時好時壞）。症狀要先可重現，才值得動樣品 | [03](03-trust-the-symptom.md) |
| 定位 localization／fault isolation | 把異常縮小到一個空間位置或一組候選位置。**定位成功不等於知道原因** | [04](04-localization.md) |
| 根因 root cause | 能解釋症狀、經過對照與替代解釋檢驗後仍站得住的原因。需要多組獨立證據互相印證 | [06](06-physical-evidence.md) |
| 驗證 validation | 用改動後的結果檢驗某個假設。**驗證的是修法有效，不自動等於根因成立** | [07](07-circuit-edit.md) |

## 二、處置與修改

書系共用的處置用語，在本書中的對應意義：

| 術語 | 本書定義與提醒 | 首次完整解釋 |
|---|---|---|
| 失效分析 FA / failure analysis | 以科學方法找出產品失效原因的技術服務。**交付物是報告、定位結果與分析數據，不是修好的產品** | [01](01-failure-and-disposition.md) |
| 電路編修 circuit edit | 用 FIB 切斷既有連線或沉積新導體，以修改晶片實體佈局。用於工程驗證與原型除錯 | [07](07-circuit-edit.md) |
| 切線 cut | 銑掉一段既有金屬連線使其斷開 | [07](07-circuit-edit.md) |
| 接線 strap／deposit | 以氣體前驅物在離子束下分解，沉積白金、鎢或絕緣層形成新連接。**電阻遠高於原生製程金屬** | [07](07-circuit-edit.md) |
| 工程樣品 engineering sample | 用於驗證設計的少量樣品。編修過的樣品不是量產版本，時序與可靠度結論不能外推 | [07](07-circuit-edit.md) |
| 量產修復 | 對已生產的貨品做可出貨的修復。**FIB 編修不是量產修復方案**；公開資料所述規模是少數到幾十顆 | [09](09-validation-and-respin.md) |
| ECO / metal-only respin | 只改金屬層的工程變更。前提是設計時預留足量 spare cell | [09](09-validation-and-respin.md) |
| 重新投片 respin | 改光罩後重新製造。全層與 metal-only 的光罩數量與成本差一個級距 | [09](09-validation-and-respin.md) |
| spare cell | 佈局階段預先散佈的備用邏輯閘。不足時就無法只靠金屬層實現改動 | [09](09-validation-and-respin.md) |

## 三、接近與製備

| 術語 | 本書定義與提醒 | 首次完整解釋 |
|---|---|---|
| 打線封裝 wire bond | 以金屬線連接晶粒與導線架／基板。打線與 bond pad 可從正面接近 | [02](02-chip-access.md) |
| 覆晶封裝 flip chip | 晶粒正面朝下接到基板。**主動區與 BEOL 只能從矽基板背面接近** | [02](02-chip-access.md) |
| BEOL／FEOL | 後段金屬互連層／前段元件層。兩者的證據由不同方法取得 | [02](02-chip-access.md) |
| 正面／背面編修 | 從金屬層側或矽基板側接近目標。金屬層數與堆疊決定哪一側可行 | [07](07-circuit-edit.md)、[08](08-editing-limits.md) |
| 去封裝 decap | 移除封膠以露出晶粒。化學、電漿、雷射、機械四法各自破壞不同證據 | [05](05-sample-preparation.md) |
| 去層 delayering／deprocessing | 逐層移除互連與介電層以抵達目標層。濕蝕刻、乾蝕刻、機械研磨與化學輔助 FIB 各有終點控制難題 | [05](05-sample-preparation.md) |
| 剖面 cross-section | 切開以觀察截面形貌。機械研磨與 FIB 產生的假象性質不同 | [05](05-sample-preparation.md) |
| lamella | 供 TEM 觀察的超薄試片。製備本身是高度加工，樣品已不代表原始塊材狀態 | [05](05-sample-preparation.md)、[06](06-physical-evidence.md) |
| 假象 artifact | 製備過程造成、原本不存在的特徵，例如 curtaining、再沉積、非晶化、浮凸、塗抹 | [05](05-sample-preparation.md) |
| 非破壞先行 | 在改變樣品之前先做 X 光、超音波掃描等不破壞證據的檢查 | [05](05-sample-preparation.md) |

## 四、定位方法

本表只寫各方法回答什麼問題；適用條件與盲點見[第 04 章](04-localization.md)，不要只憑縮寫選方法。

| 術語 | 本書定義與提醒 |
|---|---|
| EMMI／PEM 光輻射顯微 | 偵測通電元件發出的光。**對不發光的純歐姆或金屬短路看不到** |
| OBIRCH | 以紅外雷射局部加溫引發電阻變化，定位異常導通或漏電。需光學可及 |
| TIVA／熱式雷射刺激 | 同屬雷射刺激類方法，量測的是電性參數隨局部加溫的變化 |
| LIT 鎖相熱影像 | 偵測週期性偏壓下的微小溫升分佈 |
| EBIRCH／EBAC／EBIC | 電子束式定位。**需先去層並以奈米探針接觸，屬破壞性前處理**；同一位置的訊號可能混雜多種物理機制 |
| LADA／SDL | 針對時序敏感、時好時壞的症狀。找到的是**時序敏感位置**，不必然是永久性物理缺陷所在 |
| PVC 被動電壓對比 | 以電子束成像時的對比差異判斷節點是否浮接或異常導通 |
| TDR 時域反射 | 封裝層級的阻抗不連續定位。對分支走線無法分辨個別分支貢獻 |
| SAM／C-SAM 超音波掃描 | 對分層、空洞與界面裂縫敏感；遇密封空腔聲波無法穿透 |
| X-ray／CT | 看密度與厚度差異。**對純電性、無結構改變的缺陷看不到**；與 SAM 互補而非互換 |
| SIL 固體浸液鏡頭 | 提高背面觀測數值孔徑的鏡頭，用來補償長波長帶來的解析度損失 |

## 五、分析與量測

| 術語 | 本書定義與提醒 |
|---|---|
| SEM | 電子束掃描表面成像，兼可做成分分析與電性缺陷偵測 |
| TEM／STEM | 電子束穿透超薄試片，可達奈米甚至原子尺度 |
| EDS／EDX | 元素成分分析。定量分析需極薄試片與低探針電流 |
| EBSD | 晶粒取向、差排與局部應變分析。**表層非晶化會使繞射圖案消失** |
| AFM／XPS／FTIR | 表面形貌／表面化學態／分子鍵結分析 |
| 良品對照 known-good | 用已知正常的樣品做同條件比對，用來分辨「這個結構異常」與「這片樣品不同」 |
| 可重現性 | 同一條件下能否再次觀察到同一症狀。不可重現時，先停在證據缺口而非繼續加工 |
| NTF／CND | no trouble found／cause not found。**本書未取得晶片層級的一手技術文獻全文，因此不引用任何相關比例或統計** |
