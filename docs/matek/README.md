# 從失效分析與電路修補看懂閎康

一顆晶片在測試站上 FAIL。接下來的問題通常不是「再測一次會不會過」，而是：這一顆工程樣品要不要深入分析、這一批貨能不能出、下一版光罩該不該改。閎康科技（Materials Analysis Technology，MA-tek；股票代號 3587）公開提供失效分析、材料分析、可靠度測試與 FIB 電路編修等服務。這些服務要放回「症狀如何變成有證據支持的根因」這條路線，才容易讀懂。

本書追問六件事：**FAIL 之後面對的是哪一個對象、故障藏在哪一層、症狀可不可信、定位方法看得到什麼、物理證據能不能證明因果，以及公開資料究竟證明到哪裡。**

## 你會建立的能力

- 分開工程樣品、已生產批次與下一版設計，不把三種決策當成同一份報告。
- 說出電性定位與物理分析各自提供什麼證據，以及各自天生看不到什麼。
- 在動樣品之前先問：接觸、條件與對照是否足以相信這個症狀。
- 區分電路編修的工程驗證、量產修復與重新投片；一次功能通過不能直接寫成根因確立。
- 用明示假設重算「再做一次分析值不值得」，不把期望成本當成放行資格。
- 面對新設備、據點調整或聯盟消息，找出從能力清單到案件與收入之間缺的證據。

## 如何閱讀證據

全書來源查閱日為 **2026-09-17**。公司網頁與新聞支持閎康自己的公開陳述；設備原廠、學會與產業技術文件用來解釋一般工程原理，不能替閎康證明任何案件。宜特（iST）等獨立同業的技術文章只作工程說明，與閎康的能力無關。來源發布日與查閱日分列於[來源索引](appendix-sources.md)。

算例全部是明示假設，不是閎康真實報價、成功率或營收預測。公司未揭露的事業別收入、機台稼動與客戶規格留在[待查問題](appendix-open-questions.md)。

失效分析交付的是報告與證據，不是修好的產品；電路編修交付的是可驗證的工程樣品，不是量產修復方案。本書與[從晶圓再生與薄化看懂昇陽](../../psi/html/index.html)同屬「晶圓失效與補救」書系：昇陽處理的是監控晶圓能否再被同一用途接收，本書處理的是功能異常的晶片如何被定位與驗證。兩本都可獨立閱讀。本書不建立股價估值或目標價。圖表是教學示意。實物照片以 Wikimedia Commons 線上連結顯示、不下載進儲存庫；它們不是閎康現場或客戶案件。出處見[圖表來源](99-image-credits.md)。
