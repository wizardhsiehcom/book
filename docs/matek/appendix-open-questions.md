# 待查問題：哪些資料會改變本書判斷？

本表列的是尚未被本次可得來源充分回答的問題，不等於公司沒有相關能力或沒有對客戶揭露。更新時保留日期、來源與適用範圍。

| ID | 尚缺的資料 | 現在如何處理 | 取得後能改變什麼 |
|---|---|---|---|
| Q01 | 官網寫「TWSE: 3587」、交易所資料集歸屬上櫃的原因 | 依 TPEx 資料集歸屬上櫃，把用字不一致當分欄案例 | 確認是筆誤、舊站殘留或另有上市安排 |
| Q02 | FA／MA／RA／FIB 的營收、毛利、件數拆分 | 年報僅「檢測服務收入」100%；月報只有總額 | 才能把成長歸因到某一項服務 |
| Q03 | 15 台 SB-FIB 的廠牌、型號、廠區、稼動與可達節點 | 只引用公司自述台數 | 判斷編修能力邊界是否涵蓋正文討論的堆疊 |
| Q04 | 上海子公司處分：MOPS 原件、交割是否完成、80%／15.2 億與 78.4658%／12.02 億的口徑 | 兩套數字並列，不調和；不宣稱已交割 | 更新控制權、合併範圍與中國據點狀態 |
| Q05 | 閎康 NTF／不可重現案件的結案標準與比例 | 第 03 章只用公開的非閎康 NTF 案例談條件 | 才能描述公司自己如何停在症狀缺口 |
| Q06 | 化學去封裝配方、三種去封膠子頁的量化風險比較 | 只寫方法名稱與一般工程風險 | 才能比較閎康各法對污染／打線證據的影響 |
| Q07 | FIB 沉積金屬的電阻率（μΩ·cm）與鎵污染量化 | 只用服務商量級與定性限制 | 才能把編修樣品的時序／漏電差寫成數字 |
| Q08 | 各節點編修成功率百分比 | 只保留「良率會下降」的定性描述 | 才能討論編修作為驗證手段的鑑別力 |
| Q09 | 晶圓廠 metal-only respin 官方價目與週期 | 完整 set 與 metal-only 的公開數字並列、不採單一標價 | 才能把第 09、10 章的教學成本換成特定節點估計 |
| Q10 | 良品對照應取幾顆、同批或跨批 | 方法論只寫「需要對照」，不填樣本數 | 才能把根因主張的統計強度升級 |
| Q11 | IEEE／ISTFA 晶片 FA 專論的 NTF、SDL 全文 | 標題可證實研究方向存在；數字不引用 | 補上元件級 NTF 在 IC 定位文獻中的定義與比例 |
| Q12 | 遠端上機是否涵蓋 FIB／TEM，以及與現場品質的對照 | 只採用已列機台名單 | 擴大或收窄「不必到現場」的主張 |

沒有這些資料時，仍然可以下的結論是：閎康公開提供失效分析與電路編修服務；FA 交付證據不是修好的產品；編修通過不能自動等於量產修復。保留未知不會抹去這些已支持的句子。
