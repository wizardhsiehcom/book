# 圖表來源與閱讀方式

本書以原創 Mermaid 教學圖與表格為主，另以 Wikimedia Commons 線上圖補充實物觀察。圖是教學示意，不是閎康現場、客戶案件或比例正確的製程剖面。非比例圖不能用來讀尺寸；流程圖中的順序也不等於任何實驗室 SOP。

圖檔**不下載進 repo**。正文以 Wikimedia `Special:FilePath` 遠端顯示；點圖連到 Commons 檔案頁（wiki `File:`）。授權與作者資訊以 Commons API／檔案頁逐一核對（2026-09-17）。

> **閱讀提醒**：這些圖是為了讓「晶圓、打線、覆晶、探針台、X 光、SEM、FIB、光罩」長什麼樣子可被看見。它們**不是閎康的產品或現場照片**，也不表示圖中的公司、機台或封裝是閎康的客戶。
