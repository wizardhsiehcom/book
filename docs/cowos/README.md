# 導讀：為什麼工程師需要懂 CoWoS

一顆 NVIDIA Blackwell GPU 裡有兩顆接近光罩極限的運算晶片，用 **10 TB/s** 的速度互相通訊——比它整包 HBM 記憶體的頻寬還高。這兩顆晶片沒有焊在同一片矽上，而是靠嵌在有機基板裡的幾片小矽橋連起來的。

這就是 CoWoS。

當 AI 算力需求持續翻倍，而單一晶片的面積被光罩極限（約 858 mm²）硬性封頂，**先進封裝成為繼製程節點之後最重要的效能槓桿**。理解 CoWoS，就是理解當代 AI 硬體最關鍵的一層。

## 這本筆記的目標

1. 建立 2.5D 封裝的完整心智模型：從 TSV、矽中介板，到 CoWoS 的三個變體。
2. 理解 CoWoS-S、CoWoS-R、CoWoS-L 的設計取捨，以及為什麼「局部矽」反而能做得比「全矽」更大。
3. 掌握 HBM 與 CoWoS 的協同設計邏輯，一路到 HBM4 的 2048-bit 介面。
4. 看清 CoWoS 在真實 AI 加速器（Blackwell、Rubin、MI400、TPU、Trainium）中的具體角色。
5. 補齊常被略過、但實務上最關鍵的三塊：**電氣（互連與供電）**、**熱**、**測試與良率**。
6. 理解封裝的經濟學——產能、成本與良率的算術，為什麼經常才是真正的瓶頸。

## 2026 年的狀況速覽

如果你只有兩分鐘，這是截至 **2026 年 9 月**最需要知道的五件事：

1. **CoWoS-L 是旗艦主力**，不是折衷方案。5.5 倍光罩尺寸量產中，良率超過 98%。Blackwell、Rubin、AMD MI400、AWS Trainium3 全部採用。
2. **CoWoS-S 沒有被淘汰**——它與 CoWoS-L 都全數訂滿，服務中等面積的廣大市場。
3. **路線圖比 2025 年的版本更長**：2027 年 9.5 倍光罩、2028 年 14 倍、2029 年 14 倍以上（24 顆 HBM5E）；而 SoW-X 從 2027 被推遲到 **2029**。
4. **HBM4 的頻寬躍升來自介面加寬（1024→2048-bit），不是速度提升**——這本質上是一次封裝互連密度的進步。
5. **瓶頸不再只有 CoWoS**：CoWoS、HBM、ABF 基板現在是並行的三重瓶頸。

當圓形晶圓的幾何極限浮現，接棒者是矩形面板——這條故事線見本書庫的《CoPoS 面板級先進封裝筆記》。
