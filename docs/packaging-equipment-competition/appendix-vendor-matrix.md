# 附錄 A：供應商、產品與關係總矩陣

查閱基準：**2026-09-11**。下列為產品索引，不是市占、性能或公司總分排名。每列與指定章節的能力、測試條件及來源紀錄合用；「未公開」限於本輪來源，不能解讀成不存在。

## 使用方式與共同缺值

先選工件與站點，再看比較對象。除明列者外，本輪來源未提供材料牌號、厚度、完整品質／節拍 recipe、同條件驗收和具名型號客戶；這些欄位一律視為**未公開／尚未取得**，不是零或相同。

「產品公開」只表示有產品頁或型錄，不證明展會展示、送樣、出貨或量產。產品頁位於某公司網站，也不代表所有模組均由該公司自研。
