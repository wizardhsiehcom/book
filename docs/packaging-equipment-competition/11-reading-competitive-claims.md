# 第 11 章：如何讀懂「取代外商」「打入大廠」「AI 升級」？

## 1. 開場問題

同一句「導入」，可能指軟體接上既有機台、工程線試用，也可能是客戶量產放行。讀消息不是選擇全信或全不信，而是找出原文到底跨過哪一道證據門。

先讀[關係分級](01-competition-unit.md)及[V5](09-v5-product-map.md)、[易發](10-efc-product-map.md)產品地圖。本章用六個可追溯案例，從主張回到產品與工件；不重寫公司沿革。

## 2. 工件與結構：把新聞拆成證據卡

| 卡片欄位 | 要保留的資訊 |
|---|---|
| 主體與原話範圍 | 哪家公司、產品還是公司層級？誰發布？ |
| 物理任務 | 工件、站點、缺陷／操作、前後段 |
| 商業階段 | 公開產品、展示、評估、驗證、訂單、出貨、量產各自有無證據 |
| 關係 | 候選、技術替代、商業替換、合作、互補或未知 |
| 缺口與翻案條件 | 什麼新增資料會升級、縮小或推翻目前說法？ |

**圖表 11-1｜自建主張分析卡。** 「有日期的公告」只能建立時間錨點；不會把單方宣稱自動變成客戶確認。

## 3. 操作流程：先讀原文，再找被省略的限定

第一步找原始發布者與日期；第二步定位產品、工件和動詞；第三步拆開已發生與預計；第四步確認客戶、對手及合作方有沒有具名；第五步才用本書的關係標籤摘要。

例如「完成評估、預計下一季出貨」至少包含兩種不同狀態。查閱日期已晚於預計日期，也不能自動把「預計出貨」更新為「已出貨」，仍須取得後續實際證據。

## 4. 缺陷：四種會放大消息的剪接

**補名字：** 未具名 HBM 製造商不等於讀者猜到的領導廠商。**補型號：** 新聞中的 AOI 不一定是官網第一台 AOI。**補階段：** 參展不是驗證，驗證不是量產。**補範圍：** 某一站取代既有機台，不是整間公司全面擊敗另一間公司。

還有一種時間錯置：用後來新增的產品規格回填較早新聞，卻未說明版本。正確做法是保留「當時公告」與「本次查閱到的產品能力」兩條紀錄。

## 5. 控制與驗收：六個真實主張案例

### 案例 A｜易發高階封裝 AOI「已導入」

**主張與來源：** 易發 2025-03-26 公司新聞自述已開發高階封裝 AOI，獲未具名國內半導體大廠導入。[E1，「以技術實力驅動產業升級」]

**可保留：** 有公司層級的導入自述。**不可補：** 客戶姓名、量產規模、封裝平台或 OM 型號。產品頁 E2 與新聞 E1 需要明示對應，不能靠時間或名稱相近就連在一起。

**翻案／升級條件：** 客戶共同公告、指定型號與站點的驗收資料可縮小範圍；若後續證明只是在工程線試用，應寫工程導入而非量產供應。

### 案例 B｜易發與 Pentamaster 的 SiC 合作

**主張與來源：** 同篇新聞指名 Pentamaster 合作與晶圓級老化測試；Trooper-V 產品頁也明示 Pentamaster AOI 主體。[E1「迎接第三代半導體浪潮」、E4「設備特性與優點」]

**可保留：** 易發公開宣稱的合作關係，以及網站展示的品牌角色。**不可補：** 易發全數自研、每台都是獨家代理，或 SiC 測試資格等於先進封裝 AOI 資格。

**翻案／升級條件：** 雙方合約或公告若界定代理、整合、服務地域與產品範圍，依該範圍重畫角色。合作可真實存在，仍不必然涵蓋官網全部產品。

### 案例 C｜V5 ADC「節省 70–90% 人力」

**主張與來源：** 倍利 2026-03-05 業績發表會簡報列此效益；另列整合多種 AOI 品牌的實績。[I6 p.20–21]

**可保留：** 公司對分類／複判工作的效益自述。**不可補：** 90% 辨識率、漏檢率降低 90%，或能移除前段光學設備。

**翻案／升級條件：** 補上同工作量、缺陷分布、原始與後續人數、剩餘複判、品質門檻及期間，才能估算人力價值。若減量來自少送影像或降低檢查覆蓋，不應解讀成同品質的效率提升。

### 案例 D｜Onto「取代既有 tool of record」

**主張與來源：** Onto 2026-03-16 Dragonfly G5 發表稿稱未具名 HBM 製造商完成現場競爭性評估，並有取代既有 tool of record 與訂單敘述。[I17，副標與正文]

**可保留：** `[公司自述]` 的特定採購範圍商業替換事件；強於只有產品適用性。**不可補：** 客戶名稱、被取代廠商與型號，更不能連成「Onto 已取代 V5／Camtek／均豪」。

**翻案／升級條件：** 客戶確認、原機與新機範圍及實際出貨能補強；若僅部分模式取代，結論需限定在該模式。即使商業替換存在，未公開的共同測試仍不足讓本書完成跨廠技術替代驗收。

### 案例 E｜均豪「取代科磊」

**主張與來源：** 鉅亨網 2026-04-27 報導標題及正文涉及 AOI 取代科磊；關鍵替換敘述屬報導中的業界消息。[I11，第 1–5 段]

**可保留：** `[媒體報導／業界消息]` 曾提出這個主張。**不可補：** 客戶或雙方已證實、KLA 型號、Carrier AOI／SWLI 各自替換範圍。文中其他具名廠區也不能自動綁定這項替換。

**翻案／升級條件：** 取得原始採購／替換資料和工件站點，才能把消息升級為可追溯商業關係；若只是新增站點而非替換，需改寫成新增設備導入。

### 案例 F｜兩台都叫 Bonder，可以互換嗎？

**主張與來源：** 易發 Flip Chip Bonder 頁是 COF ILB、reel-to-reel、共晶；均華 KB-9000 頁描述 die attach、flux／DAF 等流程。[E3 技術規格、G2 產品介紹]

**可保留：** 都處理晶粒接合，但工件、接收面與結果不同；這是「同名設備不可比」的原始產品反例。**不可補：** 兩者為 hybrid bonding 直接競品，或 ±2 μm 比 <3 μm 更好。

**翻案／升級條件：** 同一晶粒、接收面、材料與接合品質的配置資料若出現，才重做特定配置比較；品牌名下新增另一台設備，也不能回頭改寫這兩台的用途。

## 6. 方案比較及公司證據

**已確認：** 六組原始資料足以區分導入自述、合作角色、AI 效益自述、未具名商業替換、媒體消息及不同接合用途。它們的證據強度與指向不同，不能加總成公司總分。

**推論：** 案例 B 是合作而非所有產品皆競爭；案例 C 的 ADC 與成像是互補候選；案例 F 顯示同名不可比。案例 D 雖有競爭事件自述，仍無法補出兩個具名對手的邊。

**待查：** 本書仍沒有具名兩方案在相同工件與驗收條件下均過關的完整公開資料；不能宣稱「技術替代比較已完成」。這項缺口與已可閱讀的章節分開追蹤，詳見[待查表](appendix-open-questions.md)。

## 7. 理解檢查

1. 案例 D 為何比只有產品頁更接近商業競爭證據？
2. 案例 D 又為何不足以證明 Onto 對 Camtek 的特定替換？
3. 案例 C 若減少人力，但增加漏檢，應怎麼改寫？
4. 2025 年新聞與今天產品頁都有 AOI，何時才可合併？

??? note "參考答案"
    1. 來源明述現場競爭性評估及替換，而不只有適用性；但仍是單方自述。
    2. 對手未具名，最知名或最相似的供應商不是證據。
    3. 寫成不同品質門檻下的取捨，不再宣稱同品質效率提升。
    4. 取得型號、版本及站點的明示對應；否則分列公司消息與產品資料。
