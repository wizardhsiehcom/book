# 附錄 C：比較時新增的術語

封裝、AOI 與基本接合名詞請回[均豪術語](../../gpm/html/appendix-glossary.html)、[均華術語](../../gmm/html/appendix-glossary.html)。本頁只補跨廠比較需要的語言。

| 術語 | 本書用法 | 首次／主要解釋 |
|---|---|---|
| 任務卡 | 工件、站點、加工面、目標、驗收與責任的共同問題 | [01](01-competition-unit.md) |
| 功能重疊候選 | 有相近用途，但尚未取得共同驗收證據 | [01](01-competition-unit.md) |
| 技術替代 | 同需求、同驗收下存在至少兩個合格方案；不等於商業競標 | [01](01-competition-unit.md) |
| 物方像素尺寸 | 像素對應工件上的長度；不是量測準確度 | [02](02-comparable-specs.md) |
| 缺陷靈敏度 | 特定材料、對比與 recipe 下的檢出敘述；須追定義 | [02](02-comparable-specs.md) |
| 捕獲率／召回率 | 真實缺陷中被找到的比例；需指明樣本單位 | [02](02-comparable-specs.md) |
| 漏檢率 | 真實缺陷中被判正常的比例；公司口徑可能不同 | [02](02-comparable-specs.md) |
| 誤報率 | 本書以真實良品中被報缺陷的比例定義 | [02](02-comparable-specs.md) |
| Precision | 報缺陷者中真正有缺陷的比例；不要與機械「精度」混用 | [02](02-comparable-specs.md) |
| Recipe | 與工件相關的取像、加工、判定參數及版本 | [03](03-inspection-alternatives.md) |
| BF／DF | 明場／暗場；是成像通道，不是自帶共同測試條件 | [03](03-inspection-alternatives.md) |
| GR&R | 量測系統重複性與再現性分析；需定義人、機、日及樣本 | [04](04-metrology-boundaries.md) |
| CD／pitch | 臨界尺寸／節距；不等於高度量測的重複性 | [04](04-metrology-boundaries.md) |
| ADC | 自動缺陷分類；處理影像不代表提供成像硬體 | [05](05-inline-and-ai.md) |
| Unknown | 低信心或無法判定類；需要隔離或人工複判規則 | [05](05-inline-and-ai.md) |
| Brownfield 改造 | 在既有設備上升級；成本含原機限制與停機驗證 | [05](05-inline-and-ai.md) |
| Dry cycle | 不含完整實際加工的循環時間；不能直接當良品節拍 | [06](06-sorting-bonding.md) |
| 材料終點 | 製程後所需材料狀態，如固化程度、殘留或附著；不只是設定值 | [07](07-material-process.md) |
| 增量成本 | 比較當前選擇新增的成本；已不可回收的支出不重複列入 | [08](08-integration-switching.md) |
| Tool of record | 指定客戶／製程認可使用的設備；須保留站點與版本範圍 | [11](11-reading-competitive-claims.md) |
| 翻案條件 | 會使主張升級、縮小、降級或被推翻的新證據 | [11](11-reading-competitive-claims.md) |

各家若使用相同縮寫但不同定義，保留原文並列；本書詞彙不能覆蓋原廠實際規格契約。
