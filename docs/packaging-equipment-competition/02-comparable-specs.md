# 第 2 章：哪些規格能放在同一張表？

## 1. 開場問題

甲寫「0.18 μm」，乙寫「0.3 μm」，是否甲勝出？如果前者指帶灰階差條件的缺陷長寬，後者指暗場檢測靈敏度，先比較大小只會得到錯誤結論。

先讀[任務卡](01-competition-unit.md)；儀器原理可回到[缺陷、AOI 與量測](../../gpm/html/11-defect-aoi-metrology.html)。本章負責規格正規化，而非再介紹一次所有感測器。

## 2. 工件與結構：一個數字至少有六個附件

將規格寫成「**測量量／定義＋數值與單位＋工件＋方法＋統計口徑＋運作模式**」。沒有附件的數字是資料線索，不是比較結果。

| 指標 | 回答的問題 | 不能替代 |
|---|---|---|
| 物方像素尺寸 | 一個像素對應工件多長？ | 可辨識細節、檢出率或量測準確度 |
| 光學解析度 | 指定光學條件可分開多近的結構？ | 特定缺陷在量產影像是否可見 |
| 缺陷靈敏度／可檢尺寸 | 指定材料、對比及規則可找到什麼？ | 所有缺陷皆可檢出 |
| 準確度／偏差 | 測得值離可追溯參考值多遠？ | 重複量測散布 |
| 重複性 | 相同條件反覆量測有多集中？ | 跨機、跨日、跨人一致性 |
| WPH／UPH | 指定模式每小時完成多少晶圓／單位？ | 良品產能、全檢覆蓋率 |

「一個像素內」仍欠物方像素尺寸、樣本數、計算方法與工作距離。即使已知像素尺寸，可以換算那個偏移量，仍不能把偏移量改名為量測準確度。

## 3. 操作流程：先對齊定義，再換單位

先逐字保留來源與版本，再把單位換成共同尺度；其後標記是否量同一個東西，最後檢查覆蓋率、節拍與品質是否在同一 recipe 下取得。

| 原始紀錄 | 可做的轉換 | 仍不能做的結論 |
|---|---|---|
| 150 nm sensitivity | 換成 0.15 μm | 比 0.18×0.18 μm、灰階差≥30 一定好 |
| 100 WPH，8 吋、36 點抽檢 | 保留每片 36 個抽檢點 | 等於 100 WPH 全檢 |
| 30 WPH，8 吋、base on 30 μm 全檢 | 保留原文「30 μm」條件，定義待查 | 在 3 μm 缺陷設定也達同速度 |
| X/Y ±10 μm @3σ | 標為已給統計口徑 | 優於或劣於未標口徑的「<3 μm」 |

表中的節拍來自易發 OM，位置精度的對照來自 Besi 與均華；不能把不同機台的規格拼成一台理想設備。[E2、B1、G2]

## 4. 缺陷：有分母才看得懂漏檢與誤報

本書固定以經確認的「真實缺陷樣本」作漏檢率分母，以「真實良品樣本」作誤報率分母。這是本書教學口徑；廠商文件若另有定義，必須先換算或保持分列。

**假設的獨立盲測，樣本單位為檢查區域，不是晶圓：**

| 真實狀態 | 系統報缺陷 | 系統報正常 | 合計 |
|---|---:|---:|---:|
| 有缺陷 | 90 | 10 | 100 |
| 正常 | 99 | 9,801 | 9,900 |

- 召回率：90 ÷ 100＝90%；漏檢率：10 ÷ 100＝10%。
- 誤報率：99 ÷ 9,900＝1%；報缺陷的可信比例：90 ÷ 189≈47.6%。
- 整體正確率：(90＋9,801) ÷ 10,000＝98.91%。

**98.91% 正確率與 10% 漏檢率可同時成立。** 大量正常樣本會掩蓋少數但昂貴的漏檢。若只拿 AOI 已挑出的影像評估 ADC，連前段沒拍到或沒送出的缺陷都不在分母裡，不能據此宣稱整條產線漏檢率。

## 5. 控制與驗收：一張共同測試表

| 檢查項 | 驗收前要凍結的內容 | 未凍結的風險 |
|---|---|---|
| 工件 | 材料、厚度、圖形、翹曲、表面反射、批次 | 標準片成功，真實工件失敗 |
| 缺陷 | 類別、尺寸、對比、埋藏深度、確認方法 | 只挑容易找到的缺陷 |
| 取像 | 面積、正背面、邊緣排除、倍率、照明、焦點 | 抽檢和全檢混比 |
| 量測 | 參考標準、偏差、重複性、跨機／日變動 | 穩定地量錯 |
| 判定 | 各類漏檢、誤報、低信心處理與複判量 | 用總平均掩蓋關鍵失敗 |
| 產能 | 上下料、recipe、複掃、review、換批、停機 | dry cycle 冒充有效產出 |

若 N 個已確認缺陷均未漏檢，仍不能宣稱真實漏檢率為零。在獨立且有代表性的二項抽樣近似下，零事件的單側 95% 上界約為 3/N；例如 N＝100 時約 3%。這是由「零事件機率 (1−p) 的 N 次方約等於 0.05」得到的近似，不適用於高度相關或挑選過的樣本。

## 6. 方案比較及公司證據

**已確認：** V5 通用設備頁的像素穩定性、V5300 PRO 簡報的缺陷尺寸，與 Eagle G5 明／暗場靈敏度是不同表述；易發 OM 明列不同抽檢／全檢條件。[I1、I6、I12、E2]

**推論：** 共同測試應以任務結果為主，不要求不同物理方法使用相同內部參數；例如照明可不同，但必須拿到同一批盲測缺陷、相同產能與放行要求。

**待查：** 廠商規格中的 accuracy、sensitivity、resolution 各自定義，以及是否為最佳模式、選配或標準配置。

## 7. 理解檢查

1. 重複量測非常集中，為何仍可能每次都量錯？
2. 98.91% 正確率能否證明上例適合關鍵缺陷放行？
3. 看到零漏檢，為何還要知道樣本數及取樣方式？
4. 是否一定要把兩台設備倍率設成一樣才公平？

??? note "參考答案"
    1. 系統偏差可很大，重複性只描述散布。
    2. 不能；上例漏掉十分之一真實缺陷，是否可接受取決於風險門檻。
    3. 少量或偏斜樣本無法排除低頻事件；零次觀測不是零風險。
    4. 不一定。應固定工件、結果與成本／節拍條件，容許各方案使用合適成像方法。
