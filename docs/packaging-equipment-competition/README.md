# 先進封裝設備競爭地圖

## 從製程站點看供應商與替代方案

**先問工件要交出什麼結果，再問哪台設備能做，最後才問兩家公司是否競爭。**

本書面向已接觸先進封裝或均豪入門的讀者。它不是概念股名單，也不是公司總分排行榜；目標是讓你看出同站競爭、不同解法、相鄰互補，以及哪些關係其實尚未證實。

讀完能拆開 AOI 整機、嵌入式檢測與 AI 分類，辨認規格背後的工件與分母，並理解換供應商為何需要重新驗證。V5／倍利科技與易發精機各有一章；均豪、均華、志聖、東捷及選定國際方案按站點出現。

## 這一版已回答與尚未回答的事

資料查閱基準日：**2026-09-11**。本版共 11 章主線，含產品比較、規格反例、換機成本算例及六組真實主張案例。

**已有結論：** 部分產品有功能重疊；ADC 與成像可以形成互補候選；COF 接合、晶粒黏晶與 SiC 測試不能靠機器名稱混比。

**尚未證明：** 具名兩方案在相同工件、缺陷、覆蓋率及驗收條件下均合格的技術替代。本書不把缺漏欄位補成相同，也不把未具名競標對手補名字。[第 3 章](03-inspection-alternatives.md)完整示範如何得到「不能排名」的有用結論，以及要怎樣補證。

## 與既有書的分工

[均豪導讀](../../gpm/html/index.html)與[CoWoS](../../cowos/html/index.html)負責封裝背景；[均華](../../gmm/html/index.html)負責取放、對位與接合原理；[志聖](../../csun/html/index.html)負責光熱與材料狀態。本書以具體章節連回先備，不複製公司沿革與基礎原理，也不把既有書的舊快照自動當成當期事實。

每章依序有開場問題、工件、流程、缺陷、驗收、證據、理解檢查及來源。公司段固定拆成「已確認／推論／待查」；「已確認」指原始資料確有該敘述，不代表本書對產品作過獨立實測。
