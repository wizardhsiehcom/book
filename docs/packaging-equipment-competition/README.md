# 先進封裝設備競爭地圖

## 從製程站點看供應商與替代方案

**先問工件要交出什麼結果，再問哪台設備能做，最後才問兩家公司是否競爭。**

本書面向已接觸先進封裝或均豪入門的讀者。它不是概念股名單，也不是公司總分排行榜；目標是讓你看出同站競爭、不同解法、相鄰互補，以及哪些關係其實尚未證實。

例如，兩家公司都說能做 AOI（自動光學檢測），但一家提供拍照、判斷與上下料的整台設備，另一家只提供判讀既有影像的軟體。兩者可能接在一起使用，不能只憑「都有檢測功能」就說能互相取代。

讀完本書，你要能完成三件事：

1. 分清整台檢測設備、裝在其他設備內的檢測模組，以及影像分類軟體各負責什麼。
2. 讀到規格時，問清楚測的是哪種工件、使用什麼條件，以及百分比的分母是什麼。
3. 比較換供應商的方案時，列出需要重新驗證的項目。

V5／倍利科技與易發精機各有一章；均豪、均華、志聖、東捷及選定國際方案按站點出現。

## 這一版已回答與尚未回答的事

資料查閱基準日：**2026-09-11**。本版共 11 章主線，含產品比較、規格反例、換機成本算例及六組真實主張案例。

**已有結論：** 部分產品提供相近功能。ADC（自動缺陷分類）處理影像判讀，成像設備負責取得影像，兩者有互補的可能。COF（薄膜覆晶封裝）的接合、晶粒黏晶與 SiC（碳化矽）測試處理的任務不同，不能只看機器名稱就放在一起排名。

**尚未證明：** 本書還沒有足夠資料，證明指定的兩個方案能在相同工件、缺陷、檢查覆蓋率及驗收條件下都合格。因此，不能把功能相近直接寫成「技術上可替代」。缺漏條件要留白；來源未公布競標對手，也不能自行補名字。[第 3 章](03-inspection-alternatives.md)示範如何說明「目前不能排名」，並列出還缺哪些證據。

## 與既有書的分工

[均豪導讀](../../gpm/html/index.html)與[CoWoS](../../cowos/html/index.html)負責封裝背景；[均華](../../gmm/html/index.html)負責取放、對位與接合原理；[志聖](../../csun/html/index.html)負責光熱與材料狀態。本書以具體章節連回先備，不複製公司沿革與基礎原理，也不把既有書的舊快照自動當成當期事實。

每章依序有開場問題、工件、流程、缺陷、驗收、證據、理解檢查及來源。公司段固定拆成「已確認／推論／待查」；「已確認」指原始資料確有該敘述，不代表本書對產品作過獨立實測。
