# 第 3 章：同一個封裝表面檢測任務，有哪些候選？

## 1. 開場問題

採購端想檢查 RDL 表面缺陷，拿到三家簡報：V5 V5300 PRO、Camtek Eagle G5、Onto Dragonfly G5。如何從「都有 AOI」前進到有用的候選清單，而不跳成沒有證據的排名？

先讀[比較單位](01-competition-unit.md)與[規格定義](02-comparable-specs.md)。這一章完整示範公開資料所能做到的上限：**功能重疊候選已建立；同條件技術替代尚未證明。**

## 2. 工件與結構：先限定任務，缺的不要替廠商填

教學任務是「在 300 mm 晶圓的 RDL 蝕刻後，檢查正面導線區的開路、橋接及殘留」。這不是任何廠商的共同測試報告。

RDL 線寬、材料堆疊、金屬反射、表面粗糙度、邊緣排除及翹曲尚待需求方提供。候選產品頁可能只說表面缺陷、multi-RDL 或 after etch；**相近應用詞並不保證三者都已對這張任務卡驗證**。

| 目標 | 可研究方法 | 盲點／需補資料 |
|---|---|---|
| 導線開路、橋接 | 圖形比對、明／暗場或多角度成像 | 結構對比、正常變異與最小缺陷樣本 |
| 表面微粒、刮傷 | 多倍率與照明通道 | 材料散射不同，不能只用直徑描述 |
| 薄有機殘留 | 具相應對比機制的光學通道 | 肉眼可見與電性有害殘留未必相同 |
| 埋藏缺陷、接合空洞 | 另評估 IR、X-ray 等適用方法 | 光學表面合格不能證明內部合格 |

## 3. 操作流程：把來源拆成可稽核的三張卡

| 產品／主體 | 來源明述的能力 | 公開條件與缺口 |
|---|---|---|
| V5300 PRO／倍利科技 V5 | 公司簡報列 particle、scratch、residual、顯影異常與底材偏移 | 100X：0.275×0.275 μm；150X：0.18×0.18 μm，均附灰階差≥30。材料、全檢節拍、檢出率未公開 [I6 p.17–18] |
| Eagle G5／Camtek | 晶圓先進封裝、Multi-RDL、FOWLP；明／暗場、CAD 比對 | BF 0.5 μm、DF 0.3 μm；相對前代 2 倍 throughput，缺相同 recipe 的絕對 WPH [I12] |
| Dragonfly G5／Onto Innovation | RDL 顯影／蝕刻後、CMP、TSV reveal、hybrid bonding；多角度、IR、3Di | 150 nm sensitivity；缺共同缺陷、絕對 WPH 及高度重複性 [I16] |

V5 通用設備頁另列 200／300 mm、正背面與 2X–100X，但沒有型號；簡報的 V5300 PRO 列到 150X。兩份文件**分開記錄**，不把通用頁每一欄自動拼到具名型號，也不自行判定 150X 是標配。[I1、I6]

三張卡的用途是形成詢證清單。先確認 300 mm、蝕刻後 RDL 與全部目標缺陷，再要求樣本測試；不能直接進入價格與性能排名。

## 4. 缺陷：一個完整的不可比反例

有人把 0.18、0.3、0.15 μm 排成名次。單位雖已統一，量的東西仍不相同：

| 缺少的共同條件 | 為何會翻轉比較 |
|---|---|
| 缺陷形狀與材料 | 長寬門檻、散射訊號與線狀斷裂不等價 |
| 灰階差、照明與背景 | 同一大小在不同表面可能可見，也可能淹沒 |
| 捕獲率與誤報率 | 降低判定門檻可增加捕獲，也可能大量誤報 |
| 全檢面積與掃描模式 | 高倍率可增加掃描時間，不代表量產節拍相同 |
| 機型配置與文件版本 | 通用頁、選配與新機型不能混成同一版本 |

因此結論不是「三台一樣好」，而是「**公開數字不足以判定誰對任務更好**」。取得共同資料後，任何一台都可能通過、失敗或只適用部分缺陷。

易發 OM 提供另一個可重作的反例：8 吋、36 點抽檢的 ≥100 WPH，不能與 8 吋、base on 30 μm 全檢的 ≥30 WPH 比成「速度退步」，更不能用產品頁的 3 μm 瑕疵敘述替換全檢的 30 μm 條件。兩段數字對應不同工作量。[E2]

## 5. 控制與驗收：如何把候選推進成技術替代

先準備同批、可追溯且缺陷真值經獨立方法確認的工件；包含正常變異、難例及不同尺寸缺陷，不只放標準缺陷片。固定必檢區域、良品／缺陷分母與放行規則，允許廠商各自選合適光學 recipe，但須完整記錄。

接著把測試分成「調參組」及未看過的「驗收組」，避免拿已用來調模型的影像證明泛化能力。每台都交付逐缺陷結果、誤報數、無法判定數、掃描與複判時間、版本及原始定位資料。跨日與重新上片則檢查焦點、對位和量測穩定性。

| 驗收門 | 需交付證據 | 不通過時如何寫 |
|---|---|---|
| 任務適用 | 材料、厚度、尺寸、翹曲、站點與缺陷清單 | 不適用／僅部分適用 |
| 品質 | 每類捕獲、誤報、無法判定與信賴範圍 | 不滿足指定缺陷驗收 |
| 產能 | 同覆蓋率下含上下料、複掃及複判的時間 | 可檢測但未達產線節拍 |
| 整合 | map、座標、recipe 版本、異常復歸 | 單機可行，整線資格待補 |

這套試驗若證明兩方案在同一任務均過門檻，才能支持技術替代。實際換機仍需[第 8 章](08-integration-switching.md)的重新驗證與成本分析。

## 6. 方案比較及公司證據

**已確認：** 三家都公開了具名產品與封裝表面相關能力，支援建立功能候選。Camtek 公告 Eagle G5 訂單；Onto 公告 Dragonfly G5 經未具名 HBM 客戶評估並替換既有 tool of record，這是廠商對特定商業事件的自述，未揭露對手。[I13、I17]

**推論：** 在取得相同 RDL 任務資料前，三者只能列功能重疊候選；均豪公開半導體 AOI，但本輪具名型號及測試條件不足，不硬塞進數值表。[I8]

**待查：** V5300 PRO 的配置與 RDL 站點對應、三者共同材料窗口、漏檢／誤報和全檢節拍。Onto 公告不能拿來證明其曾對 V5、Camtek 或均豪競標。

## 7. 理解檢查

1. 本章是否已完成「兩個技術方案可互相替代」的證明？
2. 為何知道 150 nm＝0.15 μm 還不能排名？
3. 檢出能力過關但複判人力大增，應在哪一關被發現？
4. 「取代既有 tool of record」可以連線到哪一家對手？

??? note "參考答案"
    1. 沒有。完成的是候選盤點、不可比反例及共同測試設計。
    2. 換單位不會讓缺陷、對比、捕獲率、面積與節拍自動一致。
    3. 品質關要看誤報，產能與整合關要計入複判及放行延遲。
    4. 來源未具名時不能連到特定廠商，只能記錄未具名替換事件。
