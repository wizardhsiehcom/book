# C 中日英關鍵詞與官方入口

在日本機場、警察局或官方網站上，同一件事常以日文漢字或英文出現，字面和中文習慣不同，例如日本說「上陸許可」不說「入境許可」、說「遺失届」不說「報案」。本附錄把全書用到的關鍵詞依旅程順序排列，附上原文，方便你在官方網站搜尋或指給現場人員看。

!!! info "使用方式"
    **說明欄**只寫這個詞在本書的意思與對應章節，規定細節請回正文。**官方入口**是查詢時的第一站；日文原詞可直接貼進官方網站的搜尋框。標示「台灣用語」者是台灣的制度，日文欄留空。

## 入境資格與證件

| 中文 | 日文 | 英文 | 說明／官方入口 |
|---|---|---|---|
| 免簽證（短期停留） | 査証免除 | Visa exemption | 護照載有身分證字號的台灣護照可短期停留 90 日，不得從事有報酬活動（[02 章](02-passport-visa.md)）。入口：[日本外務省](https://www.mofa.go.jp/j_info/visit/visa/short/novisa.html) |
| 簽證 | 査証（ビザ） | Visa | 工作、長期留學等不適用免簽時要事先申請。入口：[日本台灣交流協會](https://www.koryu.or.jp/tw/visa/kaohsiung/tabid3098.html) |
| 上陸許可 | 上陸許可 | Landing permission | 入境審查官在入境時給予的許可；免簽只是不必事先辦簽證，是否准許入境仍在現場審查（[02 章](02-passport-visa.md)）。入口：[日本台灣交流協會 免簽入境須知](https://www.koryu.or.jp/visa/taipei/exemption/) |
| 短期停留 | 短期滞在 | Temporary Visitor | 觀光、探親等短期入境的在留資格；期間更新只限人道上不得已等特別情形（[12 章](12-emergencies.md)）。入口：[出入國在留管理廳](https://www.moj.go.jp/isa/applications/status/temporaryvisitor.html) |
| 入境審查 | 入国審査 | Immigration inspection | 下機後第一關，會採指紋與臉部照片（[07 章](07-vjw-arrival.md)）。入口：[日本海關 旅客通關程序](https://www.customs.go.jp/english/summary/passenger.htm) |
| 出入國在留管理廳 | 出入国在留管理庁 | Immigration Services Agency of Japan | 主管入境、停留期限的機關，設有多語諮詢窗口。入口：[外國人在留總合資訊中心](https://www.moj.go.jp/isa/consultation/center/index.html) |
| 護照 | 旅券（パスポート） | Passport | 短期停留外國人依入管法第 23 條須隨身攜帶（[09 章](09-local-rules.md)）。 |
| 在留卡 | 在留カード | Residence card | 官方說明發給「中長期在留者」；以免簽短期停留入境的觀光客不在此列。在日補發護照時，非定居日本者可免附在留卡影本。入口：[護照遺失申請補發](https://www.roc-taiwan.org/jp/post/375.html) |
| Visit Japan Web | Visit Japan Web | Visit Japan Web | 數位廳的免費入境手續服務，非強制；可登錄入境審查與海關申報並產生 QR code（[07 章](07-vjw-arrival.md)）。入口：[數位廳](https://www.digital.go.jp/policies/visit_japan_web) |

## 海關、檢疫與攜帶品

| 中文 | 日文 | 英文 | 說明／官方入口 |
|---|---|---|---|
| 海關 | 税関 | Customs | 入境時檢查攜帶品、課稅與申報的機關。入口：[日本海關](https://www.customs.go.jp/english/summary/passenger.htm) |
| 攜帶品與別送品申報書 | 携帯品・別送品申告書 | Customs Declaration | 入境旅客的海關申報；可用 VJW 或紙本（[07 章](07-vjw-arrival.md)）。 |
| 申報 | 申告 | Declaration | 對海關主動說明攜帶物品或現金；日本入境時支付工具合計超過等值 100 萬日圓須申報（[06 章](06-food-cash-goods.md)）。 |
| 免稅範圍（入境日本） | 免税範囲 | Duty-free allowance | 酒、菸、香水與其他物品的入境免稅數量（[06 章](06-food-cash-goods.md)）。入口：[日本海關 7105](https://www.customs.go.jp/tetsuzuki/c-answer/keitaibetsuso/7105_jr.htm) |
| 動物檢疫 | 動物検疫 | Animal quarantine | 肉品、含肉加工品入境日本須輸出國政府證明（[06 章](06-food-cash-goods.md)）。入口：[農林水產省動物檢疫所](https://www.maff.go.jp/aqs/english/product/import.html) |
| 植物防疫（植物檢疫） | 植物防疫 | Plant protection / Plant quarantine | 水果、種子、帶土植物等入境日本的檢查。入口：[農林水產省植物防疫所](https://www.maff.go.jp/pps/j/introduction/english.html) |
| 檢查證明書 | 検査証明書 | Inspection certificate | 輸出國政府機關發給的檢疫證明；旅客在商店買的伴手禮通常沒有。 |
| 輸入確認 | 輸入確認 | Import Confirmation | 攜帶超過免辦數量的藥品入境日本前，向厚生勞動省辦理（[05 章](05-medicines.md)）。入口：[厚生勞動省](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iyakuhin/kojinyunyu/topics/tp010401-1_00001.html) |
| 麻藥等攜帶許可 | 麻薬携帯輸入許可 | Permission to carry narcotics | 含麻藥等管制成分的藥，至少出發前 14 日申請（[05 章](05-medicines.md)）。入口：[厚生勞動省麻藥取締部](https://www.ncd.mhlw.go.jp/en/application2.html) |
| 紅線／綠線 | ―（台灣用語） | Red channel / Green channel | 返台時依有無應申報物品自選的通關檯（[13 章](13-return-customs.md)）。入口：[財政部關務署](https://web.customs.gov.tw/singlehtml/2597?cntId=cus1_114543_2597) |
| 指定菸品（加熱菸） | ―（台灣用語） | ―（無統一英譯） | 須經衛福部審查核定才能輸入台灣；國外購買未經核定者不得攜入（[13 章](13-return-customs.md)）。入口：[國民健康署](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4878&pid=19284) |

## 購物、免稅與稅費

| 中文 | 日文 | 英文 | 說明／官方入口 |
|---|---|---|---|
| 免稅（消費稅） | 免税 | Tax-free | 外國旅客購買後攜出日本，免除日本消費稅；與返台免稅是不同制度（[11 章](11-tax-free.md)）。入口：[國稅廳 6559](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6559.htm) |
| 免稅店 | 輸出物品販売場 | Tax-free shop | 經許可辦理免稅銷售的店家。 |
| 一般物品／消耗品 | 一般物品／消耗品 | General goods / Consumables | 2026-10-31 以前購買適用的分類；2026-11-01 起購買者取消此分類（[11 章](11-tax-free.md)）。 |
| 退款方式（退稅） | リファンド方式 | Refund method | 2026-11-01 起購買適用：先付含稅價，出境時海關確認後由店家退稅（[11 章](11-tax-free.md)）。入口：[國稅廳 改制專頁](https://www.nta.go.jp/publication/pamph/shohi/menzei/201805/format/002.htm) |
| 退款 | 返金 | Refund | 退款方式與手續費由各店決定。 |
| 國際觀光旅客稅（出國稅） | 国際観光旅客税 | International Tourist Tax | 自日本出境時由航空公司隨票代收（[11 章](11-tax-free.md)）。入口：[國稅廳 7195](https://www.nta.go.jp/taxes/shiraberu/taxanswer/inshi/7195.htm) |
| 駕照日文譯本 | 日本語による翻訳文 | Japanese translation of driver's license | 台灣駕照在日本駕駛時須搭配的指定譯本；台灣國際駕照不適用（[10 章](10-driving.md)）。入口：[日本台灣交流協會](https://www.koryu.or.jp/consul/drivers/detail3/) |
