# 台灣出發去日本：旅遊規定指南

在桃園機場安檢被收走一瓶 150ml 的乳液，到了成田又在海關前被問「有沒有帶肉製品」，回台灣時才發現在日本便利商店買的加熱菸屬於未經核定的產品，不能帶進來。這三件事分別歸不同的機關管：航空安檢、日本動物檢疫、台灣菸害防制。一趟日本旅行至少會經過五道規則：台灣出境、搭機、日本入境、在日停留、返台入境。每一道各有主管機關，彼此不互相保證。

本書不推薦景點，只回答一件事：**從台灣出發去日本玩，每一個階段要準備什麼、哪些東西要先查、查不到時該問誰。**

## 這本書寫給誰

- 持有效、**載有身分證字號**的中華民國普通護照，短期赴日觀光、探親的旅客。
- 第一次自由行也能照著核對；跟團旅客可直接讀證件、行李、檢疫、購物與返台章節。
- 役男、未成年、無戶籍國民、持外國護照或雙重國籍者，主線以外另有分流，見[第 02 章](02-passport-visa.md)與[第 03 章](03-special-travelers.md)。

工作、留學、長期居留、商業進出口不在本書範圍；遇到這些目的，書中只告訴你「已經超出觀光免簽」並指向主管機關。

## 三種標籤

全書用三種前綴區分規定的性質，不要把後兩種當成法律：

- **【法規】** 政府機關的規定，違反可能被拒絕入境、沒入或處罰。
- **【業者】** 航空公司、飯店、租車公司、商店的條款，只約束該業者的服務。
- **【建議】** 官方建議或本書建議，不做不會違法，但會增加風險。
