# D 來源索引與版本紀錄

## 如何讀其他國家的赴日指南

英國、澳洲、法國、德國的外交部都有日本旅遊建議，內容整理得很好。本書借用了它們的**編排方法**，但沒有搬用它們的**規則**。原因是這些頁面寫給自己的國民看：

| 參考 | 本書借用了什麼 | 不能直接套用的 |
|---|---|---|
| [英國 FCDO：Safety and security](https://www.gov.uk/foreign-travel-advice/japan/safety-and-security)、[Entry requirements](https://www.gov.uk/foreign-travel-advice/japan/entry-requirements)、[Health](https://www.gov.uk/foreign-travel-advice/japan/health) | 把入境、法律、健康、現場處理分開寫 | 英國護照的免簽待遇、英國醫療制度與用藥例子 |
| [澳洲 Smartraveller：Japan](https://www.smartraveller.gov.au/destinations/asia/japan) | 先給風險概覽，再列安全、健康、法律、聯絡方式 | 澳洲護照與駕照、澳洲使館服務 |
| [法國外交部：Entrée / séjour](https://www.diplomatie.gouv.fr/fr/information-par-pays/japon/conseils-aux-voyageurs-entree-sejour)、[Sécurité](https://www.diplomatie.gouv.fr/fr/information-par-pays/japon/conseils-aux-voyageurs-securite)、[Santé](https://www.diplomatie.gouv.fr/fr/information-par-pays/japon/conseils-aux-voyageurs-sante) | 行前與旅途中分段；自然風險依地區與活動呈現 | 法國的衛生證明、疫苗流程、領事登錄 |
| [德國外交部：Japan Reise- und Sicherheitshinweise](https://www.auswaertiges-amt.de/de/reiseundsicherheit/japansicherheit-213032) | 警示只限定在特定地理範圍，並標示更新日期 | 德國護照待遇、德國的警示等級與公民服務 |
| [日本觀光廳：Travel Etiquette](https://www.mlit.go.jp/kankocho/responsible-traveler/assets/pdf/etiquette_booklet_eng.pdf) | 把少數必要行動集中成容易查找的卡片 | 原圖不翻製 |

閱讀外國指南時，問自己三個問題：

1. 這條是**日本的規定**，還是**該國對自己國民的服務**？前者可能也適用於你，後者不適用。
2. 這條是否取決於**國籍**（免簽天數、駕照互認、領事協助）？如果是，回到日本或台灣主管機關查台灣護照的待遇。
3. 這條的**更新日期**是什麼時候？比台灣或日本官方頁舊的，以官方頁為準。

## 來源分類

全書依據分四類，各章末的「來源與查閱日」表列出該章實際使用的頁面。

| 類別 | 主要機關 | 權威範圍 |
|---|---|---|
| 台灣政府 | 外交部領事事務局、內政部移民署與役政署、交通部民用航空局與公路局、財政部關務署、農業部動植物防疫檢疫署、衛福部與食藥署 | 台灣出境、搭機底線、返台入境 |
| 日本政府 | 外務省、出入國在留管理廳、日本海關、農林水產省動物檢疫所與植物防疫所、厚生勞動省、國稅廳、警察廳、數位廳、觀光廳、JNTO、各自治體 | 日本入境、在日停留、日本離境 |
| 準官方窗口 | 日本台灣交流協會、台北駐日經濟文化代表處 | 台日之間的簽證、駕照、領事事務 |
| 業者 | 中華航空、長榮航空、JR 東海、JR 東日本、租車公司 | 只約束各自的服務與航班 |

搜尋引擎摘要、旅遊網站、部落格與新聞報導，只用來找到官方頁面；本書沒有把它們當成規定的唯一依據。書中凡寫「本書查閱時未能以主管機關原文核實」的地方，就是這類情況。

## 維護原則

- 每次改版前，重查入境、航空、藥品、檢疫、稅費與緊急聯絡六類來源；平時每季檢查一次。
- 已知的制度切換日，於生效前後各複核一次。下一個優先節點是 **2026-11-01**。
- 若某條規定找不到現行依據，標為「待更新」並保留主管機關入口，不沿用舊數字。
