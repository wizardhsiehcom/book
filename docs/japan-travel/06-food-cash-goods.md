# 06 食品、植物、現金與其他攜帶品

阿哲要去橫濱看阿姨，媽媽準備了三罐肉鬆、一包芒果乾和一盒新鮮芒果，要他順便帶過去；他自己則換了 30 萬日圓現金當旅費，還幫同事代買一條菸。這些東西在桃園都過得了安檢，但到了日本，肉鬆和芒果要先過**動植物檢疫**，菸要看**海關免稅額**，現金要看**申報門檻**。

!!! info "本章適用"
    - **何時會用到**：買伴手禮前、換匯前、打包前。
    - **適用誰**：從台灣出境、入境日本的旅客，帶食品、植物、現金、菸酒或高價物品者。
    - **不適用誰**：從日本**帶回台灣**的食品、菸酒、現金與免稅額，本章只簡述，完整內容見[第 13 章](13-return-customs.md)；藥品見[第 05 章](05-medicines.md)；液體能否手提見[第 04 章](04-baggage-batteries.md)；日本免稅購物見[第 11 章](11-tax-free.md)。

## 先分清四種處理方式

同樣是「海關」，處理方式分四種，彼此不能互相代替：

| 處理方式 | 意思 | 日本入境的例子 |
|---|---|---|
| 禁止 | 不論自用、少量都不能帶入 | 麻藥、槍砲、爆裂物、偽幣、侵害智慧財產權的仿冒品；土壤及附土植物 |
| 須證明或許可 | 要有輸出國政府證明或事前許可，並在入境時受檢 | 肉類與含肉加工品、植物；超量藥品（見[第 05 章](05-medicines.md)） |
| 須申報 | 可以帶，但要主動申報 | 所有入境旅客都要申報攜帶品；支付工具合計超過等值 100 萬日圓 |
| 免稅範圍 | 申報後在額度內不課稅 | 酒、菸、香水與其他物品的免稅額 |

**【法規】入境順序**：入境審查（指紋、臉部照片）→ 領行李 → **動植物檢疫**（在海關前）→ **海關**。動植物檢疫櫃台在海關檢查台之前，要帶著檢疫物品先去那裡，不是等海關問了才說。完整流程見[第 07 章](07-vjw-arrival.md)。

## 動物產品：肉類與含肉加工品

**【法規】**日本農林水產省動物檢疫所說明：

- 肉類與含肉加工品，**即使是伴手禮、個人自用、已煮熟或真空包裝**，沒有輸出國政府機關核發的檢查證明，就不能帶入日本。火腿、香腸、肉乾等都包括在內。
- 動物檢疫的對象還包括蛋（含蛋殼）、骨、脂肪、血液等動物來源部位，以及用這些原料做成的加工品。乳製品的處理方式依動物檢疫所頁面的分類為準。
- 要先確認產地與品項沒有被禁止或停止輸入，再取得證明並在入境時受檢；多數私人伴手禮難以符合這些條件。
- 檢疫物品要在空港、港口海關檢查區內的**動物檢疫櫃台**受檢，受檢前先拆封的，可能不能帶入。
- **罰則**：違法攜入可處 **300 萬日圓以下罰金或 3 年以下拘禁刑**（2020 年 7 月 1 日施行的家畜傳染病預防法修正）。

**判斷步驟：**

1. **看成分表**：成分列有肉類或其他動物來源原料（包括調味包裡的肉塊）→ 屬動物檢疫範圍。
2. **看產地**：台灣產畜產品的現行條件，以動物檢疫所公告為準；疫情會改變條件，不要沿用別人去年的經驗。
3. **沒有政府檢查證明** → **【建議】**不要帶。肉鬆、肉乾、含肉的調理包與泡麵，都先用這個標準檢查。
4. **不確定** → 帶去動物檢疫櫃台主動申報，或出發前詢問動物檢疫所。

本書不列「可以帶」的食品清單。成分、產地與疫情都會變，同一種點心換一個口味就可能不同。

## 植物與植物產品：水果、種子、生藥

**【法規】**日本農林水產省植物防疫所說明：

- 能否帶入依**產地**與**植物種類**判斷。部分產地的特定水果、蔬菜禁止輸入；非禁止品通常也須輸出國政府的**植物檢疫證明書**並接受入境檢查，與數量或用途無關。
- **土壤及附土植物禁止**帶入。
- 苗木、切花、水果、蔬菜、穀物、木材，以及香料、生藥材都屬須檢查的品項。
- 不會帶入病蟲害的部分加工品不需檢查；哪些算，以植物防疫所的說明與查詢資料庫為準。
- 入境時先到**植物檢疫櫃台**，取得檢查合格後再過海關。
- **罰則**：官方頁寫明，違反者可處 **3 年以下監禁或 300 萬日圓以下罰金**。

**判斷步驟：**

1. **新鮮的嗎？** 新鮮水果、蔬菜、切花、種子、球根 → 幾乎都須證明或屬禁止，先查植物防疫所的資料庫（依國家、品項查詢）。
2. **有土嗎？** 有土或附土 → 禁止。
3. **加工到什麼程度？** 乾燥、烘焙、醃漬等加工品，要看是否屬官方所列不需檢查的類別；查不到就到植物檢疫櫃台主動出示。
4. **中藥材、香料** → 屬須檢查品項，另依[第 05 章](05-medicines.md)查藥品規定。

## 現金與支付工具：台灣出境、日本入境各算一次

同一疊現金，會先後碰到台灣和日本兩個門檻。兩邊的計算方式不同，要分開核對。

| 關卡 | 項目 | 門檻 | 做法 |
|---|---|---|---|
| **【法規】台灣出境** | 新台幣 | 逾 10 萬元 | 須申報；超過限額部分不能攜出，未申報或申報不實者超額部分沒入 |
| | 外幣現金 | 總值逾等值 1 萬美元 | 須申報 |
| | 人民幣 | 逾 2 萬元 | 須申報，且出境時仍只能在限額內攜出 |
| | 黃金 | 逾等值 2 萬美元 | 須向經濟部國際貿易局申請輸出許可 |
| **【法規】日本入境** | 現金（含外幣）、支票、旅行支票、本票、有價證券等支付工具 | 合計超過等值 **100 萬日圓** | 須向日本海關申報 |
| | 金塊（純度 90% 以上） | 超過 1 公斤 | 須向日本海關申報 |

台灣出境時，填寫「旅客或隨交通工具服務之人員攜帶現鈔、有價證券、黃金、物品等入出境登記表」，在**安檢前**向海關服務檯申報；關務署也提供線上預先申報。新台幣超額時的處理方式，關務署頁面寫得較簡略，細節請以關務署頁面與服務檯說明為準。

**【建議】**幾點提醒：

- 日本的 100 萬日圓是**申報門檻**，不是攜帶上限，也不代表會課稅。
- 同行家人的現金要各自計算還是合併計算，本書查閱時未能以日本海關原文核實，請至日本海關網站查詢。
- 大額現金遺失或被竊時難以追回，旅費可分散成現金、信用卡與簽帳卡。
- 從日本出境與返台的現金規定，見[第 13 章](13-return-customs.md)。

## 菸、酒與其他物品：日本入境免稅額與禁止品

**【法規】日本入境免稅額**（旅客個人攜帶、自用範圍）：

| 項目 | 免稅範圍 |
|---|---|
| 酒類 | 3 瓶（每瓶以 760ml 計） |
| 菸品 | 紙菸 200 支，或加熱菸個裝 10 個，或雪茄 50 支，或其他菸草 250g |
| 香水 | 2 盎司（約 56ml） |
| 其他物品 | 海外市價合計 20 萬日圓；單項海外市價未滿 1 萬日圓的物品不計入合計 |
| 年齡 | **未滿 20 歲**不適用菸酒免稅 |

超過免稅範圍要申報並繳稅。阿哲幫同事代買的那一條菸是 10 包 200 支，剛好用完他自己的紙菸額度；他若再帶自己要抽的菸，就超過了。**【建議】**替別人代買、代帶的物品，一樣算在你自己的額度內。

**【法規】日本禁止帶入**的物品，日本海關列出：麻藥、槍砲、爆裂物、偽造貨幣、猥褻物品、兒童色情物品、侵害智慧財產權的物品（仿冒品）。在台灣夜市或網路買的仿冒名牌包，即使自用也屬禁止類別。

**須許可或另有限制**：瀕臨絕種動植物製品（華盛頓公約）、動物活體、刀劍等，本書查閱時未能以日本海關原文逐項核實，請至日本海關網站及相關主管機關查詢。刀具在日本的隨身規定見[第 09 章](09-local-rules.md)。

## 一件物品的四關表

| 物品 | 航空安檢 | 日本檢疫 | 日本海關 | 返台（見第 13 章） |
|---|---|---|---|---|
| 肉鬆、肉乾、含肉調理包、含肉泡麵 | 固體可手提；罐裝含汁者看液體規則 | **【法規】**須輸出國政府檢查證明；伴手禮難以符合 | 須申報攜帶品 | 肉類與肉製品原則須檢疫證明，罰則重 |
| 新鮮水果、蔬菜、切花 | 可攜帶 | **【法規】**依產地與種類禁止或須植物檢疫證明 | 須申報攜帶品 | 新鮮水果禁止或須檢疫 |
| 烘焙點心、糕餅 | 固體可手提；內餡為流質者看液體規則 | 看成分：含肉或其他動物成分時先查動物檢疫所 | 計入其他物品免稅額 | 看成分與產地 |
| 茶葉、乾貨、中藥材 | 固體可手提 | 部分加工品不需檢查；生藥材須檢查 | 計入其他物品免稅額 | 依防檢署與食藥署規定 |
| 醬料、蜂蜜、酒 | 超過 100ml 須託運 | 含動物成分時要查 | 酒類 3 瓶免稅；未滿 20 歲不適用 | 酒類有免稅額與年齡門檻 |
| 現金 | 不涉及 | 不涉及 | 支付工具合計超過等值 100 萬日圓須申報 | 新台幣、外幣、人民幣各有申報門檻 |
| 仿冒品 | 可能通過 | 不涉及 | **【法規】**禁止帶入 | 另依台灣規定 |

返台方向的限額、罰則與紅綠線，只在[第 13 章](13-return-customs.md)維護，這裡不重複列數字。

## 無法確定時找誰

| 問題 | 窗口 |
|---|---|
| 肉類、蛋、乳製品等動物產品 | 日本農林水產省動物檢疫所；入境時動物檢疫櫃台 |
| 水果、種子、植物、生藥 | 日本農林水產省植物防疫所；入境時植物檢疫櫃台 |
| 申報、免稅額、禁止品、日本端現金申報 | 日本海關（税関） |
| 台灣出境現金、黃金申報 | 財政部關務署；機場海關服務檯 |
| 從日本帶回台灣 | 財政部關務署、農業部動植物防疫檢疫署，見[第 13 章](13-return-customs.md) |

## 出發前勾選

- ☐ 伴手禮已看過成分表；含肉或動物成分、又沒有政府檢查證明的，不帶。
- ☐ 沒有新鮮水果、植物或帶土物品；不確定的加工品已查過植物防疫所。
- ☐ 現金已分別對照台灣出境與日本入境門檻，需要申報者已準備好。
- ☐ 菸、酒、香水與代買物品合計在日本免稅範圍內，同行者未滿 20 歲的不算菸酒額度。
- ☐ 行李裡沒有仿冒品。
