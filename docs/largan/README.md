# 從手機鏡頭看懂大立光

你手上的手機，相機不是一片鏡片加一顆感測器就能完成。多片透鏡要在有限空間內共同成像，組裝後還得檢查中心、邊緣與不同拍攝條件下的表現。大立光電（3008，Largan Precision）以精密光學塑膠鏡頭為核心產品；片數、材料與允收條件則隨設計而變，不能用一組規格概括所有手機鏡頭。[公司簡介與產品範圍](appendix-sources.md#c1)

本書追問一件事：**一顆手機鏡頭如何從光學設計變成能大量、穩定交付的產品，而這段能力又如何轉成公司的競爭力？**

你不需要修過光學。全書從一支手機的相機拆解開始，沿著「拍攝需求 → 鏡頭規格 → 設計與製程取捨 → 品質與合格成本 → 客戶採用與財務結果 → 公司證據」這條線走完。

## 你會建立的能力

- 分清鏡片、鏡頭組、致動器、感測器、相機模組與影像處理各自的責任，不把整條鏈的結果算在單一供應商頭上。
- 解釋為什麼鏡片數、畫素或變焦倍率單獨都不足以判斷一顆鏡頭的價值。
- 從一個影像缺陷倒推可能的設計、成形、組裝與量測因素。
- 用明示假設的算例，把良率、產品組合、固定成本與合格交付成本連起來。
- 把公司的技術、量產、客戶與收入主張分開查證，並說出**什麼證據會改變你的判斷**。

## 如何閱讀本書的證據

本書初始研究標記為 **2026-09-14**，續查與完稿日為 **2026-09-15**；新增核對紀錄見[來源索引](appendix-sources.md)。來源按類型區分，正文逐條標示：

| 證據類型 | 能證明什麼 | 不能證明什麼 |
|---|---|---|
| 法定揭露（年報、法說會簡報、重大訊息） | 公司依法揭露的數字與事實，範圍限於實際披露內容 | 不能從合併數字拆出未揭露的產品別毛利或良率 |
| 公司自述（官網、簡介、沿革） | 公司對自己能力與里程碑的公開陳述 | 自述不是獨立驗證；「開發完成」不等於量產 |
| 原始技術文獻（論文、標準、設備商技術文件） | 一般工程機理 | 不代表大立光的私有配方、參數或工序 |
| 媒體轉述 | 存在某則報導 | 不能當成公司書面揭露，尤其是法說會問答的轉述 |
| 作者推論 | 本書作者依前述證據所做的連結 | 不是事實 |

三條貫穿全書的紀律：

1. **階段用語不得升級。** 專利 ≠ 開發完成 ≠ 展示 ≠ 客戶驗證 ≠ 出貨 ≠ 收入。公司說「開發完成」，本書就寫「開發完成」。
2. **客戶未具名就維持未具名。** 公司年報依法僅以數字代號揭露主要客戶，本書不把代號補成任何品牌名稱。
3. **算例全部是明示假設**，不是大立光的真實價格、良率或成本。每個算例都寫出輸入、公式與簡化限制，讀者可以自己重算。

查不到的東西留在[待查問題](appendix-open-questions.md)，不寫成結論。來源的發布日與查閱日分列於[來源索引](appendix-sources.md)。

本書不寫股價、目標價或買賣建議，也不寫人物傳記。教學剖面圖一律標明「非特定公司產品、非按比例」，圖不能取代文字論證。
