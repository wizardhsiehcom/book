# 09 昇陽的哪些服務與成長主張已有證據？

## 開場問題：同一家公司，能把全部能力連成一張訂單嗎？

公司有再生、薄化與先進材料方向，也有新廠與設備投入。這些資訊能構成值得研究的業務輪廓，卻不能直接串成「某新材料已取得某客戶大量訂單」。本章逐列記錄交付物與證據，讓讀者知道每個結論的範圍。

全章法人主體為**昇陽國際半導體股份有限公司（PSI，8028）**，除非另有明記。資料查閱日 2026-09-14；未標日期的官網頁不視為當日新公告。

## 結構：先區分證據來源與成熟階段

本書用「原始公司／官方資料」「公告鏡錄」「作者推論」標示資料來源，另用「公開服務、研發方向、驗證、出貨、量產、財務」描述內容。兩者不能混成一條評分：官方簡報可以可靠地證明公司提出一個方向，卻未必包含該方向已量產的證據。

「未具名」指在本列所用來源中沒有將客戶名稱與交付物綁定，不表示公司沒有客戶。年報市場段出現的大型半導體公司名稱，也不能搬進客戶欄。

## 缺陷與失敗：矩陣如何防止過度連線

常見的錯誤是把「設備投入」「新材料方向」「公司營收增加」放在同一年，就認為三者已形成同一條因果鏈。替代解釋可能是既有服務出貨增加、價格或組合改變、成本改善；新材料甚至可能還在開發。

市場排名也要獨立處理。公司簡報的世界第一、市占與未來份額主張，須核對年度、尺寸、地區及按營收還是產能計算。缺原始方法時可以報告「公司如此主張」，不能把它升級成獨立研究的結論。

## 推理檢查

1. C2 列出某尺寸薄化，距離確認該尺寸對某客戶量產還缺什麼？
2. 為何 M2 的開發尺寸不能自動套到全部材料圖？
3. 均豪同時是股東且出現在設備交易鏡錄，能否證明所有擴產設備都向均豪買？
4. 2026 上半年 EPS 3.32，能否當成第二季單季 EPS？

??? note "參考推理"
    要有產品與客戶的驗證／放行、出貨和量產範圍。兩份文件可能描述不同工件或階段。單筆交易不能外推全部供應關係。季別 2 損益為上半年累計，單季需用相容的單季揭露，不直接改標期間。
