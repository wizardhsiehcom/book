# 從晶圓再生與薄化看懂昇陽

一片用來監控製程的晶圓，使用後不一定結束任務。它可能送去加工、重新驗收，再回到工廠；另一片正面已做出元件的晶圓，則可能要磨薄背面，帶著先前累積的價值交給下站。昇陽國際半導體（Phoenix Silicon International，PSI；股票代號 8028）的公司消息，要放回這些工件與交付路線才容易讀懂。

本書追問六件事：**處理什麼工件、要恢復或改變什麼性質、如何判定合格、每次合格使用花多少錢、產能如何變成收入，以及公開資料究竟證明到哪裡。**

## 你會建立的能力

- 分開晶圓的用途與再生歷史，不把測試晶圓和晶片電性測試混為一談。
- 畫出有拒收、重工與報廢出口的再生閉環。
- 用量測方法與條件閱讀「合格」，並重算含提前失敗的回用成本。
- 分辨再生、全新測試晶圓、元件薄化與材料拓展的交付物。
- 面對擴產、AI 或設備交易消息，找出從能力到出貨與收入之間缺的證據。

## 如何閱讀證據

本書於 **2026-09-14** 查核資料。公司網頁、正式簡報與年報支持公司自己的公開陳述；原廠技術文件用來解釋一般工程原理，不能替昇陽證明客戶訂單。來源發布日與查閱日分列於[來源索引](appendix-sources.md)，文件涵蓋期間也另外註明。

算例全部是明示假設，不是昇陽真實價格、良率或營收預測。公司未揭露的客戶規格、成本與分部資料留在[待查問題](appendix-open-questions.md)。先進材料章依公開證據收斂為拓展方向與驗證問題，不推定已對特定客戶量產。

本書聚焦製程服務與公司理解，不建立股價估值或目標價。圖表是教學示意；沒有以一般工廠照片冒充昇陽現場。
