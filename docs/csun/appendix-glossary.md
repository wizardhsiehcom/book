# 附錄 B：術語表

以下是本書用法，不替代材料或設備的專用定義。

| 術語 | 英文 | 本書定義與常見混淆 | 首次解釋 |
|---|---|---|---|
| 材料狀態 | Material state | 含水、溶劑、反應及介面等當下條件，不只是材料名稱 | [01](01-material-state.md) |
| 殘溶劑 | Residual solvent | 膜內尚未移出的溶劑；表面乾不代表深處已乾 | [01](01-material-state.md) |
| 固化／交聯 | Curing / cross-linking | 建立材料性質的反應；交聯是可能機制，不是所有乾燥的同義詞 | [01](01-material-state.md) |
| 預烘／軟烤 | Prebake / softbake | 光阻塗佈後調整殘溶劑等狀態的烘烤，不應任意當作最終固化 | [02](02-thermal-uniformity.md) |
| 熱歷程 | Thermal history / profile | 工件指定位置的溫度隨時間變化 | [02](02-thermal-uniformity.md) |
| 空間均勻性 | Spatial uniformity | 同一時段不同位置的分布；與單點時間穩定性不同 | [02](02-thermal-uniformity.md) |
| 製程窗口 | Process window | 同時滿足加工與不損傷等要求的條件範圍 | [02](02-thermal-uniformity.md) |
| 輻照度 | Irradiance | 單位面積的入射功率，需指明波段與位置 | [03](03-uv-process.md) |
| 劑量／輻射曝露量 | Dose / radiant exposure | 輻照度對時間的積分，不等於材料必然吸收的有效能量 | [03](03-uv-process.md) |
| 圖形曝光 | Pattern exposure | 建立空間選擇性的感光反應，後續以圖形等驗收 | [03](03-uv-process.md) |
| 曝光後烘烤 | Post-exposure bake / PEB | 部分光阻需要的後曝光反應步驟，不是所有光阻一律需要 | [03](03-uv-process.md) |
| 氧抑制 | Oxygen inhibition | 某些光固化系統的表面反應受氧影響，不可概括所有配方 | [03](03-uv-process.md) |
| 減黏／解黏 | Detacking / debonding | 改變黏性與解除暫時接合；照光減黏不等於雷射解黏 | [03](03-uv-process.md) |
| 壓膜／貼合 | Lamination | 使膜與基板接觸並達到所需覆蓋／介面；不是晶粒接合的同義詞 | [04](04-lamination-voids.md) |
| 空隙 | Void | 材料內或介面處未被預期材料填滿的區域，形成原因可能不同 | [04](04-lamination-voids.md) |
| 晶粒接合 | Die bonding | 晶粒放置與接合任務，還涉及位置及指定介面 | [04](04-lamination-voids.md) |
| 表面改質 | Surface modification | 改變表面化學等狀態，與移除污染有重疊但不完全相同 | [05](05-surface-treatment.md) |
| 接觸角 | Contact angle | 測試液在固體表面的幾何量，不是通用附著強度 | [05](05-surface-treatment.md) |
| 站間等待 | Queue time | 處理到下一站之間的時間；期間表面可能重新吸附或污染 | [05](05-surface-treatment.md) |
| 翹曲 | Warpage | 工件偏離平面的變形，會連動熱、光、搬運與接觸 | [06](06-scale-and-qualification.md) |
| 一次合格率 | First-pass yield | 不經重工即符合指定站點判準的比例，不等於整線最終良率 | [06](06-scale-and-qualification.md) |
| 製程資格 | Process qualification | 對指定條件的能力證明；不是產品頁存在或出貨的同義詞 | [06](06-scale-and-qualification.md) |
| 銦鎵鋅氧化物 | IGZO | 顯示電晶體等用途的氧化物半導體材料；其退火設備不因處理大面板就具備封裝資格 | [07](07-csun-product-evidence.md) |
| 導線架 | Lead Frame | 金屬支撐與引出互連結構；導線架電漿清洗不能直接等同晶圓表面處理 | [07](07-csun-product-evidence.md) |
| 高架搬運／無人搬運車／軌道導引車 | OHT / AGV / RGV | 廠內搬運與設備介接方式；自動化介接不等於材料處理能力升級 | [08](08-reading-news.md) |

公司新聞中的 CoWoS、SoIC、CoPoS 是需要各自核對的封裝平台／技術名稱，不因同屬先進封裝而可互換。未能直接對到平台的產品，一律保留未知。
