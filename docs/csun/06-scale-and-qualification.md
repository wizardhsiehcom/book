# 第 6 章：跨到晶圓或面板，要重新證明什麼？

## 開場問題

一家公司做過大尺寸 PCB 烘烤，另一項新設備也能容納更大的面板，能不能因此說它已經具備先進封裝量產能力？

「放得進去」只是幾何條件。**能在指定材料、全工件、連續批次與實際節拍下穩定做出合格結果**，才逐步接近製程資格。這一章把前四個技術章合成應用遷移的驗收問題，不重列供應鏈名單。

## 先看結構：尺寸、材料與資格分開

晶圓、顯示面板、封裝面板與 PCB 可能共享某些形狀或處理方式，但表面材料、薄度、翹曲、污染容許量、搬運接觸面與產品價值不同。即使都是矩形，也不是同一套製程。

因此要分開三件事：**硬體容納範圍、指定製程窗口、商業驗證階段**。產品頁可證明第一項的某些規格，少量試片可以探索第二項，但兩者都不自動證明第三項。

## 逐步製程：從可行性到穩定生產

| 階段 | 輸入／操作 | 輸出／仍不能宣稱什麼 |
|---|---|---|
| 問題定義 | 材料、工件、前後站與缺陷限制 | 形成需求；不是設計完成 |
| 工程試驗 | 代表試件，探索設備與材料參數 | 得到可行窗口；不是所有負載都合格 |
| 製程驗證 | 邊界條件、多批次、下游與可靠度 | 證明指定條件；不是任意平台通用 |
| 生產驗收 | 節拍、維護、良率、追溯及供料波動 | 證明約定範圍的運轉能力；出貨公告未必包含這些結果 |

以上為本書的概念分層，不是任何客戶統一採用的正式認證名稱。廠商說「驗證中」時，必須回到其原文確認在驗什麼。

## 失敗會長什麼樣子：局部合格，整批失敗

大面積帶來的不只是「多幾個測點」。熱、光、壓力和表面處理的分布可能在邊角與中心不同；翹曲也可能使熱板間隙、光源距離或貼合接觸隨位置改變。於是某一種變形可以同時影響數個站點。

| 變動 | 可能連鎖結果 | 應回讀的機制 |
|---|---|---|
| 基板／載具變厚 | 升溫較慢、有效停留不足 | [熱歷程](02-thermal-uniformity.md) |
| 工件翹曲或照射面變大 | 距離／遮蔽及空間劑量分布改變 | [UV 製程](03-uv-process.md) |
| 起伏、薄化或支撐改變 | 接觸不均、困氣或局部壓傷 | [壓膜](04-lamination-voids.md) |
| 前後站與等待方式改變 | 再吸濕、再污染或介面條件不同 | [表面處理](05-surface-treatment.md) |

這些都是需驗證的風險，不代表每次放大必然失敗，也不代表玻璃、晶圓或 PCB 之間完全不能轉移技術。

## 如何檢查與控制：應用遷移矩陣

| 驗收軸 | 從既有應用可以帶走什麼 | 新應用必須重證什麼 |
|---|---|---|
| 工件與搬運 | 機構、支撐與自動化經驗 | 尺寸、薄度、翹曲、接觸污染及破損率 |
| 熱歷程 | 熱源與回授控制方法 | 實際材料、載具、全負載的溫度分布與窗口 |
| 光製程 | 光源控制與量測方法 | 波段、工件面分布、遮蔽；若成像還有圖形／對位 |
| 貼合與排氣 | 壓力、真空及流程控制經驗 | 最差起伏、壓力分布、膜厚與空隙結果 |
| 表面與潔淨 | 供液、氣體及處理經驗 | 顆粒、離子／有機殘留、表面損傷與站間等待 |
| 品質與可靠度 | 追溯及缺陷分析方式 | 產品真正失效模式、量測盲點與允許範圍 |
| 節拍與維護 | 機台排程、保養與服務經驗 | 滿載週期、耗材壽命、換線、停機與長時間重現性 |
| 商業資格 | 已建立的合作關係 | 具體機型、站點、客戶驗收、出貨與量產狀態 |

### 自建算例：只看處理時間，會高估多少？

**全部數字是假設，不是志聖產能。** 假設一個批次處理 20 件，加熱／處理時間 30 分鐘，上下料、必要冷卻與其他不可重疊作業共 10 分鐘。

`理想批次產能 = 20 × 60 ÷ (30 + 10) = 30 件／小時`

只除以處理時間會得到 40 件／小時，已高估。若再假設可運轉時間比例為 0.8、這一站的一次合格率為 0.95，且兩者定義不重疊：

`估計合格產出 = 30 × 0.8 × 0.95 = 22.8 件／小時`

這仍未算下游瓶頸、重工排程與整線良率。若使用的 OEE 指標本來就含品質，再乘同一良率就是重複折減；若冷卻可與下一批重疊，也不能照上述全部相加。**先說清楚產能邊界，再做乘除。**

## 理解檢查

??? question "1. 新設備容得下某尺寸面板，還缺什麼才能談量產適用？"
    缺工件實際狀態、製程均勻性、潔淨與損傷控制、節拍、可靠度和客戶驗收。尺寸只是其中一軸。

??? question "2. 為什麼單片中央的好結果不能代表滿載合格？"
    負載會改變熱與流場，邊角及支撐也可能形成最差位置；還須看跨批次與維護週期。

??? question "3. 算例的 22.8 件／小時能直接當整線產能嗎？"
    不能。它是特定批次站、指定時間邊界與折減假設下的估計；整線瓶頸、重工及其他站良率未納入。

??? question "4. 『出貨』與『量產採用』應如何分開？"
    出貨只證明設備交付相關事件；可能是研發、試驗或驗證機。量產採用需要更直接且範圍明確的資料，不能自動升級。
