# 從光、熱與材料控制看懂志聖

**設備控制的不是「機器有沒有動」，而是材料能否以可重現的狀態交給下一站。**

這本書從含水、溶劑、固化、貼合與表面狀態出發，先建立光、熱、壓力和前處理如何影響缺陷的模型，再回頭核對志聖的公開產品及公司消息。目標不是記住設備名詞，而是對一句「切入先進封裝」提出有根據的問題。

## 讀完可以做什麼

你能區分設定溫度與工件熱歷程、曝光與 UV 固化、壓膜與晶粒接合、親水與附著；也能把公司主張拆成「產品用途、公開規格、驗證階段、客戶關係、特定平台」幾層，不再用前一層代替後一層。

## 本書的證據邊界

查閱基準日：**2026-09-10**。技術原理、公司自述、客戶公告與本書推論分開標記。未具名客戶不補名字，PCB 或顯示產品不直接映射半導體產線，產品上架、參展、得獎、出貨與量產不當作同義詞。

所有自建算例都明標假設，不是志聖規格或材料配方。產品性能若未交代負載、測點及方法，本書保留缺口；具體型錄、法說與平台對應仍以[來源索引](appendix-sources.md)及[待查表](appendix-open-questions.md)為準。本書不是投資建議，也不是設備操作手冊。
