# 第 3 章：曝光與 UV 固化能否混稱？

## 開場問題

兩台機器都會照紫外光，一台要做出細線圖形，另一台要把膠固化。能不能因為兩者都有 UV 光源，就說它們具備相同的微影能力？

不能。**波段相近，只代表能量可能落在相近範圍，不代表它們在製造同一種材料結果。** 本章新增的是光的用途、劑量與反應終點的拆分，而不是曝光設備名詞清單。

## 先看結構：同樣的光，材料任務不同

| 用途 | 材料與結構 | 光要做什麼 | 真正的驗收終點 |
|---|---|---|---|
| 圖形曝光 | 基板上的感光層；配合遮罩或直接成像 | 建立空間選擇性的化學變化 | 顯影後線寬、開口、側壁與對位 |
| UV／可見光固化 | 膠層、油墨或保護塗層；可能有透明覆蓋物 | 引發材料固化反應 | 深度及各處的材料性質、附著與可靠度 |
| UV 減黏／解黏用途 | 為照光改變黏性的材料系統 | 使黏著狀態適合後續移除 | 移除力、殘膠、破片與污染 |
| UV 表面清洗 | 表面有機污染及適用基板 | 以光化學作用移除污染 | 殘留、表面損傷及下一站適用性 |

前兩列原理來自 T2、T6；後兩列的公司用途例證分別見 P10 撕膜機與 P6 紫外線清洗機。**不表示任一 UV 固化機都能解黏，也不把 UV 曝光減黏等同雷射解黏設備。** 公司產品的實際名稱、波長用語與用途另見第 7 章。

對常見正型光阻，曝光會使曝光區在顯影時較易移除；交聯型負光阻的曝光區則較難移除。有些負光阻需要曝光後烘烤才完成所需反應。因此「照光就是把東西烤硬」連曝光原理都沒有說完整。[T2]

## 逐步製程：從光源走到終點

| 步驟 | 輸入／操作 | 輸出／目的 |
|---|---|---|
| 確認材料 | 查感光波段、膜厚與前處理 | 排除波段不合、前站狀態不合 |
| 確認光路 | 核對光源、光學件、距離、覆蓋物及遮蔽 | 知道能量能否到達要反應的位置 |
| 曝光或固化 | 控制工件面的照度分布、時間及必要氣氛 | 產生指定反應，不只讓燈亮過 |
| 後續驗收 | 曝光看顯影圖形；固化看材料性質 | 將設備輸出與製程終點連結 |

本章將常見說法「UV 強度」寫成**輻照度**，即每單位面積的入射功率，常用 mW/cm²；**劑量**是輻照度對時間的積分，常用 mJ/cm²。它們都需說明波段與量測位置。

在輻照度恆定的簡化條件下：

`劑量（mJ/cm²）= 輻照度（mW/cm²）× 時間（s）`

**自建算例：**工件面固定為 20 mW/cm²，照 10 秒，劑量為 200 mJ/cm²。若燈老化降到 16 mW/cm²，只就總入射能量而言，需要 12.5 秒才累積同樣劑量。這不代表兩次的固化程度或圖形必定相同：光譜、氧抑制、溫升、材料深度與反應動力學可能改變結果。[T2、T4、T6]

## 失敗會長什麼樣子

| 缺陷 | 可能機制 | 不能靠什麼直接修好 |
|---|---|---|
| 光阻小孔打不開 | 曝光／後烘／顯影未匹配；負光阻也可能過曝光 | 不分正負型就一律加大劑量 |
| 固化表面可接受、底部仍不足 | 材料吸收、覆蓋物阻光或厚度使深處能量不足 | 只量燈口強度 |
| 邊角或構件後方未固化 | 光路遮蔽 | 單純延長照射不能讓完全不透光的遮蔽物消失 |
| 表面發黏 | 某些自由基型材料受氧抑制，也可能是配方表面特性 | 只用手感推定整個膠層的反應終點 |
| 膠層／基板劣化 | 過度照射與熱吸收 | 假設「UV 冷光」就沒有熱負擔 |

T6 強調配方差異：表面發黏不一定表示整體未完成固化。對遮蔽區，也只有**本來具備第二固化機制且經驗證的材料**才可討論補固化，不應擅自套用加熱配方。

## 如何檢查與控制

| 問題 | 必須記錄 | 接到哪個結果 |
|---|---|---|
| 能量到哪裡？ | 工件面、覆蓋物前後、中心／邊緣、光源距離 | 最差位置的反應與圖形 |
| 測的是哪段光？ | 光譜、輻射計響應波段、校正與單位 | 避免不同儀器讀值被當成等效 |
| 光源是否漂移？ | 燈與光學件使用狀態、污染、維護前後讀值 | T4 所述的老化與不完全固化風險 |
| 材料是否完成任務？ | 曝光後顯影；固化後適當力學／化學與可靠度評估 | 不用總劑量替代產品性能 |

驗收應同時涵蓋最低有效輸出與最高允許暴露，並固定材料厚度、遮蔽與節拍。這比比較燈的總瓦數更接近真正的設備需求。

## 理解檢查

??? question "1. 劑量相同，為什麼不保證兩種燈都能固化同一材料？"
    光譜與材料吸收可能不同；量測儀器可能只量到部分波段。相同讀值不等於材料吸收了相同有效能量。

??? question "2. 固化機與曝光機最重要的驗收差異是什麼？"
    固化看材料性質與均勻性；圖形曝光還必須看空間選擇性、顯影輪廓與對位。UV 燈本身不提供這些圖形成像能力。

??? question "3. 自建算例改成 16 mW/cm²、12.5 秒，能直接取代舊配方嗎？"
    只能保持恆定輸出假設下的劑量數值。須重新確認節拍、溫升、反應與可靠度，不能只算乘法。

??? question "4. 透明材料是否一定讓 UV 通過？"
    不一定。對可見光透明不代表對材料所需的 UV 波段透明，要量相應波段的透射與實際固化結果。
