# 全書地圖：先理解材料，再核對公司

全書主線是 **材料狀態 → 製程作用 → 缺陷 → 量測與控制 → 設備資格 → 供應關係證據**。前半部問「應該具備什麼能力」，後半部問「公開資料實際證明到哪裡」；兩者不能倒過來。

```mermaid
flowchart TD
    A["01 材料狀態<br/>含水、溶劑、反應與介面"] --> B["02 熱歷程與均勻性"]
    A --> C["03 曝光與光固化"]
    A --> D["04 壓膜與空隙"]
    B --> D
    A --> E["05 清洗與表面處理"]
    B --> F["06 跨尺寸與量產資格"]
    C --> F
    D --> F
    E --> F
    F --> G["07 志聖產品證據"]
    G --> H["08 新聞的事實、推論與未知"]
```

*圖 00-1｜本書自繪的概念依賴圖。它是閱讀關係，不代表真實製程先後，也不表示志聖供應所有方塊。*
