# 衣物照護：從材質、洗滌到去污與保養

衣服沾到油、毛衣變形、白衣泛黃時，先辨認衣物與問題，再選處理方法。本書從材質、洗標到洗滌、去污、乾燥與收納，建立一套能自行判斷的日常流程。

**閱讀主線：辨識衣物 → 讀取限制 → 判斷髒污 → 選擇方法 → 檢查結果 → 長期保養。**

這是給一般家庭讀者的繁體中文實用入門書，共 18 章、12 則獨立案例與 4 組附錄。案例提供有條件的起始流程；實際衣標、產品與設備說明必須相容。全書沒有所有材質共用的浸泡時間或清潔劑配方。

## 本書怎麼使用證據

來源包括主管機關、大學推廣教材、纖維與衣物原廠、洗衣用品產業資料及設備說明。原廠資料只支持對應產品，本書另以日常例子與觀察表串接；不把品牌效果宣稱當成獨立比較試驗。2026-09-22 完成首版來源查核，詳見來源附錄。

本書不包含工業洗衣、醫療消毒、溶劑去污實作或皮革修復教學。家用方法不相容或資訊不足時，說清楚問題、停止並交接，就是本書流程的一部分。
