# 泥土：先移除顆粒，再處理殘痕

**適用情境：**一般戶外泥巴，衣物允許水洗。災後污水、工業污染、排泄物混合物或來源不明的泥，不適用本頁。

## 操作順序

ACI 的一般泥漬指引先讓泥乾，再刷去可移除的部分，後續以相容洗衣產品處理與洗滌。[ACI：Stain Removal Guide，Mud](https://www.cleaninginstitute.org/cleaning-tips/clothes/stain-removal-guide)

本書把這條路線限定在耐受輕柔清理的可水洗衣物。待普通泥巴乾後，輕取鬆散顆粒；不要用硬刷把細緻布面刷毛。再完成[局部測試](../11-stain-triage.md)，按相容產品標示處理殘痕，依衣標洗滌。

洗後檢查殘留顏色與布面。顆粒消失不等於色痕必然能去掉；如果原本是紅土或混有其他來源，需重新確認。沒有改善時不要一律改用漂白。

## 機能外套的例外

防水外套可能不允許一般去污劑。若泥巴沾在膜材外套，先轉[防水外套頁](../garments/waterproof.md)，用該產品的洗護方式處理，不把本頁的普通衣物路線直接套用。

## 預防下一次同樣問題

這類污漬通常位置可預測，例如褲腳與膝部。本書建議把大量戶外泥衣從日常輕污批次分開，在下次洗衣前先辨識污染來源。這樣能同時決定是否適合家庭處理與如何分批。
