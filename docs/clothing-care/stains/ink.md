# 墨水：先找筆，再找去污方法

**適用情境：**已知筆或墨水造成的小範圍痕跡。本頁提供辨識與產品選擇流程，不提供所有筆類共用的酒精或去光水配方。

## 為什麼不能統稱「筆漬」

原子筆、麥克筆、印台與墨汁的配方不同。UGA 按墨水種類分列，並指出丙酮對部分纖維有禁忌；其舊式複合溶劑路線不在本書家庭操作範圍。[UGA：Ink，Apparel/Fabrics](https://site.extension.uga.edu/textiles/care/stain-removal/remove-stains-from-ink-ballpoint-felt-tip-india-mimeo-stamp-pad/)

本書建議先拍下筆身型號與衣標。如果只知道是「藍色」，仍不足以選方法。不要為了找出是不是水性而在正面滴水、酒精或去光水比較。

## 可以自行進行的條件

只有找到明確適用該墨水與衣物材質的衣物去污產品，且衣物允許其後續洗滌，才按產品指示在隱蔽處測試。測試通過後，用相同條件處理污漬，注意是否連衣物染料也被帶出。

依產品要求移除殘留並完成清洗，再檢查結果。不要把清潔中的溶劑衣物直接送進烘衣機；相關限制見[乾燥章](../10-drying-and-pressing.md)。

## 何時送洗

來源不明、筆墨已大面積滲透、衣物只能乾洗，或沒有可核對的相容產品時，停止自行試藥。送洗時帶上筆的資料，說明是否洗過、烘過及用過何種產品。

成功不保證完全無痕。若墨色仍在但衣物原色開始改變，繼續處理可能損失更多。下一個合理問題是能否接受痕跡或修補，而不是再找一種更強溶劑。
