# 染色轉移：先分清多了顏色還是少了顏色

**適用情境：**衣物同洗或濕接觸後，出現外來色痕。若是原本黑色變白、圖案被藥劑改色，去除外來染料的流程不會自動補回原色。

## 立即分開與記錄

把可能的轉色來源和受影響衣物分開，拍下整批與局部，暫不烘燙。記錄洗標、程序和所用產品。本書建議連同是否為新衣、是否濕放也一起記下，供重新分類或送洗時使用。

## 白色與彩色衣物不是同一條路

UGA 的染色轉移段落對白布列有商用除色產品，並要求衣標與色牢度相容。這不是「除色劑只會除掉不想要的顏色」的保證。[UGA：Dye，Dye Transfer](https://site.extension.uga.edu/textiles/care/stain-removal/remove-stains-from-dye-hair-food-coloring-other/)

對確定可處理的白色衣物，仍須核對纖維、印花、縫線、鬆緊與產品用途，通過局部測試後才依標示操作。白底彩印也不是純白衣物。彩色、多色或有紀念價值的衣物，沒有精確相容資料時先交專業者，不自行整件浸除色劑。

## 結果怎麼判斷

外來色痕變淡而原本顏色穩定，是可以觀察的改善；整件一起變淡則需立即停止。洗回原來顏色不是保證。若無法恢復，可以評估改染或修改，但那是改變衣物外觀的新工作，不是本頁去污步驟的延長。
