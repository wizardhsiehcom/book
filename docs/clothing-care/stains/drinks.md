# 飲料：茶、咖啡、酒與果汁

**適用情境：**日常少量飲料沾污，衣物允許水洗且產品相容。蠶絲、羊毛、特殊膜材、易掉色或只可乾洗款式，先回材質與原廠指引。

## 先確認杯子裡有什麼

黑咖啡和拿鐵不是同一份污漬資訊。茶飲也可能含奶、糖漿或果汁。把已知成分記錄下來；不用為了精確分類耽誤讀洗標。

對可水洗衣物，UGA 的咖啡／茶及酒類衣物段落皆包含冷水處理與相容洗衣前處理路線。本書只採用這個起始方向，不採其自配酸、氨水或溶劑配方。[UGA：Coffee, Tea](https://site.extension.uga.edu/textiles/care/stain-removal/remove-stains-from-coffee-tea/)、[Alcoholic Beverages](https://site.extension.uga.edu/textiles/care/stain-removal/remove-stains-from-alcoholic-beverages-beer-wine/)

## 操作與檢查

1. 確認可水洗後，以冷水處理沾染處，避免把液體擴散到周圍。
2. 依[局部測試](../11-stain-triage.md)確認選定衣物產品相容，再按標示前處理。
3. 按洗標洗滌；含奶的飲料另參考[食物污漬](../12-food-and-body-stains.md)選產品，不能直接把一般酵素用在毛絲。
4. 洗後比較色圈與原本布色，未消失先不烘燙。出現色差、起毛或不再改善時停止。

果汁若已留下色料痕跡，能否進一步處理取決於衣標和產品。ACI 對果汁列有酵素及相容漂白的條件式路線；本書不把漂白設為必做步驟。[ACI：Fruit and Juices](https://www.cleaninginstitute.org/cleaning-tips/clothes/stain-removal-guide)

## 一個結果的兩種解讀

如果咖啡圈變淡，但旁邊的藍色布也變淡，不能算單純成功。記錄並停止，比繼續追求白一點更有意義。已放很久或烘燙過的飲料漬也不能保證恢復。
