# 鐵鏽：不要先拿含氯漂白劑

**適用情境：**可合理追溯到生鏽金屬或水質問題的斑痕。橘褐色本身不是確診，血漬和其他變色也可能相似。

UGA 的衣物鐵鏽頁明確排除含氯漂白，並列出依製造商指示使用商用除鏽產品的路線。本書只接受明示適用衣料的產品；五金、馬桶或磁磚除鏽品不因名稱相同就能使用。[UGA：Iron, Rust，Apparel/Fabrics](https://site.extension.uga.edu/textiles/care/stain-removal/remove-stains-from-iron-rust/)

## 先查來源

單點正好接觸金屬扣件，和整批衣物洗後同時變色，值得分開追查。前者看扣件與晾衣架；後者查水源、設備與同批物品。本書建議先停止重複洗同一批，避免把系統性問題當成每件衣服的獨立污漬。

## 可自行處理的範圍

確認衣物和產品都允許後，依產品標示測試、操作、漂洗及後續洗滌。不要自配酸液，不用煮沸或日曬取代產品說明。若先前已用過漂白劑，先停止，查明前次產品與處理紀錄，交給專業者評估。

處理後檢查斑痕是否減少、金屬附件與衣物本色有無變化。有任何異常就停止；找不到相容的衣料產品，也是一個明確的送洗理由。
