## 容易混淆的詞

| 詞彙 | 本書使用方式 |
|---|---|
| 針織／梭織 | 布料形成方式，不能代替纖維成分 |
| 緞面／刷毛／絨面 | 表面或組織線索，不能只靠觸感認定纖維 |
| 混紡／組合 | 多種纖維在紗線或布料層次結合 |
| 表布／裡布／填充 | 整件衣物不同部件，應分別查看 |
| 前處理 | 正式洗滌前，依相容產品標示處理局部髒污 |
| 色牢度 | 顏色在特定作用下的穩定程度；小範圍測試不是全面認證 |
| 平放乾燥 | 以平面支撐衣物乾燥，不等於濕衣摺成一疊 |
| 翻滾烘乾 | 烘衣機內伴隨翻動的乾燥，與自然晾乾不同 |
| DWR | 表面耐久撥水整理，與整件防水能力不可混為一談 |
| 專業濕洗／乾洗 | 專業維護路線，不是家用柔洗／完全無液體的意思 |

詞義用來讀懂問題；下一步仍是[整件衣物判斷](../02-labels-and-construction.md)。
