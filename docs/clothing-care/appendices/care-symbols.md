# A02 洗護符號：文字查閱與官方入口

本頁不重製完整符號圖。GINETEX 說明其圖示受商標使用規範保護；直接查官方頁可同時查看現行說明。本頁是文字導讀，不是標準原文或製作商品標籤的依據。[GINETEX：Care labelling，Basic principles](https://www.ginetex.net/userfiles/files/Table_of_textile_care_symbols_en.pdf)

## 先看五項，再讀附加文字

| 項目 | 要找的限制 | 常見誤讀 |
|---|---|---|
| 水洗 | 是否允許、溫度上限、機械作用、手洗 | 手洗可繞過禁止水洗 |
| 漂白 | 是否允許，以及允許哪類漂白 | 不含氯就一律可用 |
| 乾燥 | 翻滾烘乾或自然乾燥、支撐與陰乾要求 | 洗衣機能洗就能烘 |
| 熨燙及壓燙 | 是否允許、熱與蒸氣限制 | 隔布就可以超過限制 |
| 專業維護 | 交由專業者辨認的程序 | 專業濕洗等於家用柔洗 |

具體圖形、橫線、叉號與點數請以[GINETEX 現行符號頁](https://www.ginetex.net/GB/labelling/care-symbols.asp)核對。本頁不列可能跨版本混用的熨燙溫度換算表。

## 地區與版本

- **台灣服飾：**查[經濟部服飾標示基準](https://law.moea.gov.tw/LawContent.aspx?id=GL000482)，本版查得修正日期 2022-10-24、施行日期 2023-05-18。本文只概述消費者閱讀所需資訊，符號圖案仍應查主管機關公告。
- **GINETEX 體系：**採 2026-09-22 可讀的官方線上說明；未把無明確版次的下載檔宣稱成某版 ISO 全文。
- **進口或舊衣：**先找原銷售地、品牌與款式。美國的洗護規則另有體系，可參考[FTC 說明](https://www.ftc.gov/business-guidance/resources/clothes-captioning-complying-care-labeling-rule)，不直接視為台灣要求。

## 一個完整讀標結果

本書建議用句子記錄：「允許哪種洗法；是否漂白；怎麼乾；能否燙；哪些要交專業。」再加上「分開洗」「使用洗衣袋」「不可擰絞」等原標籤文字。

若符號與文字不清楚或互相矛盾，拍照詢問原廠，不自行選較強的操作。返回[第 02 章](../02-labels-and-construction.md)。
