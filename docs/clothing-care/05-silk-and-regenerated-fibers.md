# 05 蠶絲、嫘縈與萊賽爾：相似觸感，不同材料

一件有光澤、垂墜感強的襯衫，可能是蠶絲、嫘縈、萊賽爾，也可能是聚酯。這些名稱不是同義詞。先釐清材料，再思考濕洗、摩擦和局部去污。

## 把名字讀對

| 標示 | 這個名字告訴你的事 | 仍未回答的事 |
|---|---|---|
| Silk／蠶絲 | 動物來源蛋白質纖維 | 染色、加工及成衣能否水洗 |
| Viscose／嫘縈 | 常見再生纖維素纖維 | 是否做了改善尺寸穩定性的加工 |
| Modal／莫代爾 | 再生纖維素纖維類型 | 混紡、蕾絲、鬆緊等限制 |
| Lyocell／萊賽爾 | 另一種再生纖維素纖維類型 | 布面加工與洗標要求 |
| TENCEL™／天絲品牌名 | 品牌纖維，可涉及 Lyocell 或 Modal | 具體是哪一種纖維及成衣洗法 |

Lenzing 的資料將 TENCEL™ Lyocell 與 Modal 分別介紹，並說明其由木材纖維素再生成纖維的過程。因此「天絲等於某一種固定洗法」不是成立的推論。[TENCEL：Our Fibers](https://www.tencel.com/fibers)

## 蠶絲與嫘縈共同需要小心的地方

UGA 的纖維資料指出，蠶絲需留意水斑、日光與含氯漂白的影響；傳統嫘縈濕時強度降低，且可能縮或伸長。這些是材質層面的提示，不是對每一件成衣結果的預言。[UGA：Understand Your Fibers，Silk、Rayon](https://site.extension.uga.edu/textiles/textile-basics/understand-your-fibers/)

本書因此建議，不用「摸起來很柔軟」選洗衣機的柔洗程序。先找到水洗許可，再確認相容洗劑；濕時的搬動與乾燥支撐也要一起安排。洗標不允許水洗或資料不清楚時，先送評估。

## 可水洗款式的決策順序

先核對洗標指定手洗或機洗，再查產品是否適用該纖維。一般洗衣產品上的「適合彩色衣物」不等於「適用蠶絲」。遇到印花、深淺拼接或對比色滾邊，局部測試要考慮各區域，不能只測白色內縫。

如果原廠允許手洗，依[共用洗滌流程](09-washing-workflow.md)安排水量、動作與漂洗；不要擰成繩狀。若只是單點污漬，也先讀[去污入口](11-stain-triage.md)，不要假定局部搓揉一定比整件清洗溫和。

## 兩件相似襯衫的不同答案

假設一件蠶絲襯衫要求專業清潔，另一件萊賽爾襯衫允許機洗。外觀都很垂墜，不足以合併為同一批。第一件保留污漬資訊交給專業者；第二件按洗標選程序，同時確認扣子、印花與乾燥方式。

這個例子說明，材質知識幫你知道要問什麼，洗標與成衣狀態幫你決定這次可以做什麼。下一章將把同樣方法用在[合成纖維與混紡](06-synthetics-and-blends.md)。
