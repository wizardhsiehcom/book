# 08 洗衣產品：先讀用途，再看名稱

洗衣精、去污劑、漂白劑和柔軟精不應視為清潔強度逐級上升的同一套東西。它們的用途不同，適用衣物也不同。最有用的選擇方法，是拿著衣標與污漬問題讀產品背面。

## 先完成這張選擇表

| 產品類型 | 要確認什麼 | 不應自行推論什麼 |
|---|---|---|
| 日常洗劑 | 手洗或機洗、材質、濃縮程度、用量 | 泡沫越多越乾淨 |
| 含酵素產品 | 適用污漬、材質限制、操作條件 | 所有酵素配方都適用羊毛蠶絲 |
| 局部去污產品 | 能否直接前處理、是否需稀釋、停留限制 | 可以塗上放一整晚 |
| 漂白產品 | 含氯或含氧、衣標與產品是否都允許 | 「彩色適用」等於所有材質適用 |
| 柔軟或香味產品 | 是否需要該功能、衣物是否允許 | 可以代替洗劑去掉髒污 |

這張表是本書的閱讀順序；不是任何品牌的性能排名。

## 含氧不等於無條件安全

「不含氯」只能回答其中一個成分問題。OxiClean 的 Versatile Stain Remover 使用說明明列羊毛、毛混紡、蠶絲、絲混紡、皮革與只可乾洗衣物不適用。這是具體產品的例子，不能拿它的使用量套到另一種含氧產品。[OxiClean：Pre-treat laundry](https://www.oxiclean.com/en/stain-solutions/how-to-use-stain-remover-for-clothes-to-pre-treat-laundry)

同樣地，羊毛用產品與一般衣物產品不只差在香味。若衣標禁止漂白，看到頑漬也不能用「少放一點」繞過限制。若產品沒有列出你的材質，先找原廠答覆或選已有明確相容資訊的產品。

## 用量來自瓶身和機器，不來自瓶蓋大小

同樣一蓋，可能是不同容量、不同濃縮程度。按產品對衣量、水量與髒污程度的說明量取，再核對洗衣機的投入位置。Samsung 的支援文件提醒，其所述洗衣機須使用 HE 洗劑，且不可超過分配盒 MAX 線；用量過多會造成累積。這是設備相容性例子，不是所有洗衣機的規格。[Samsung：How to use detergent](https://www.samsung.com/us/support/answer/ANS10001018/)

若你的機器有自動投放，仍要確認填入產品的種類與濃度設定。自動只是替你投放，不會辨識這一批是否混入只能使用另一種洗劑的毛衣。

## 不把家用原料組成新的配方

本書不提供醋、小蘇打、漂白劑與其他清潔用品的混合配方。尤其家用漂白劑不可與其他清潔劑任意混合，可能產生危險氣體；通風與防護也依產品指示。[CDC：Bleach safety](https://www.cdc.gov/hygiene/about/cleaning-and-disinfecting-with-bleach.html)

這不妨礙使用明確標示可搭配的洗衣產品與設備程序；但「依標示分別投放」和「先倒在杯中混合」是不同動作，後者不能自行發明。

產品保留原容器與標籤，量取工具也不要混用為飲食器皿。下次換品牌或換新版配方，重新讀一次用法，而不是沿用上瓶的蓋數。準備完成後，進入[第 09 章](09-washing-workflow.md)。
