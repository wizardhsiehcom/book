# 14 飲料、墨水、泥土與染色轉移：按來源找案例

這一章是查詢入口，不是同一種化學污漬的大分類。咖啡和泥巴都可能是褐色，染色轉移和墨水都可能是藍色，但顏色不足以決定方法。

## 選擇案例

| 你知道的來源 | 案例頁 | 第一個分岔 |
|---|---|---|
| 茶、咖啡、酒、果汁 | [飲料](stains/drinks.md) | 是否加奶、含其他食物成分？ |
| 原子筆、印台、麥克筆 | [墨水](stains/ink.md) | 找得到筆或墨水產品資訊嗎？ |
| 一般戶外泥土 | [泥土](stains/mud.md) | 是普通泥巴，還是污水或化學污染？ |
| 生鏽金屬接觸痕跡 | [鐵鏽](stains/rust.md) | 是否確定來源、是否有整批變色？ |
| 與其他衣物同洗後染上顏色 | [染色轉移](stains/dye-transfer.md) | 是多了一種顏色，還是原色流失？ |

每一頁都以[第 11 章](11-stain-triage.md)的相容性與測試為前提。找不到來源時留在未知污漬流程，不用各頁的方法輪流試。

## 三個很像、卻不同的情境

白上衣上有藍痕：可能是筆劃過，也可能是深色衣物轉色。黑褲子出現淡斑：可能是附著物，也可能是原染料被改變。外套出現橘斑：可能與金屬接觸有關，也可能是其他來源。這些例子都是判斷練習，不是看照片就能診斷的規則。

真正能縮小範圍的是時間與位置：穿之前有沒有？洗之前有沒有？同批其他衣物有沒有？是否正好沿金屬扣件或筆袋位置出現？記錄這些比只描述「一塊很難洗的斑」更有用。

## 案例之間不互相加成

讀了飲料頁後又發現含奶，可以回到食物章重新選產品；這不代表先用飲料頁一套，再把食物頁所有處理加上。每次先完成相容性判斷，再只執行當下有根據的一條路線。
