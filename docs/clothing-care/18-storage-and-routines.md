# 18 日常與換季：讓照護做得下去

好的收納從衣物入櫃前開始。清潔、乾燥、檢查與修補各自完成，再決定放在哪裡。漂亮的盒子無法替衣服去除尚未乾透的水分。

## 三個時點的檢查表

| 時點 | 要做的事 | 檢查通過的條件 |
|---|---|---|
| 穿完 | 看污漬、濕氣、接縫與附件 | 決定待洗、待乾或可繼續使用 |
| 洗後 | 看原污漬、殘留、厚處與形狀 | 清潔及乾燥完成，沒有待處理問題 |
| 換季 | 重新檢查、必要清潔與修補、安排保存 | 可以說清楚每件衣物的狀態 |

表 18-1：原創生活檢查表。頻率依穿著與環境調整，沒有全書共用的「穿幾次一定洗」。

## 掛或摺，取決於支撐需求

CCI 的紡織保存資料說明，脆弱、針織或重裝飾衣物不適合隨意吊掛；清潔乾燥、避光與適當支撐是保存重點。本書取用這些原則，不要求家庭照搬博物館用材與環境規格。[CCI：Basic care – Textiles，Storage](https://www.canada.ca/en/conservation-institute/services/care-objects/textiles-costumes/basic-care-textiles.html)

在家裡可以先問：肩部是否承受不必要重量？摺線是否壓到硬裝飾？衣物是否太密以致難以檢查？與其先購買整套收納工具，不如先安排現有空間，讓需要支撐的衣物得到支撐。

## 潮濕季節不要只靠日曆

本書建議在連續潮濕、漏水或衣櫃出現異味後增加檢查，而不是等下個換季。先查櫃體、牆面和衣物，發現異常分開處理。開窗、除濕或改放位置，要依實際環境選擇；不把香包當成濕氣問題的證據或解方。

收納容器要與衣物狀態配合。完全乾燥才談封存；頻繁取用則保留容易檢查的安排。對霉斑、蟲害或珍貴衣物，先找專業建議，不自行把防蟲劑與除濕劑堆在衣物上。

## 一個最小可行的衣物紀錄

不必替每雙襪子建檔。先為容易忘記洗法或具有價值的衣物保留：洗標照片、品牌型號、上次成功方法、異常與修補。其餘衣物按共同路線分類即可。

| 欄位 | 範例寫法 |
|---|---|
| 衣物 | 深藍羊毛針織上衣，型號已拍照 |
| 路線 | 按本件洗標手洗、相容羊毛洗劑、平放乾燥 |
| 問題 | 右腋下毛球，尚未使用工具 |
| 下次注意 | 與包帶接觸處先檢查 |

這是紀錄範例，不是對任何深藍毛衣的洗滌處方。

## 換季時做最後一次分流

需要清潔的先清潔，需要修補的先安排修補，無法確認狀態的另放並註記。送洗者使用[交接表](appendices/stain-index.md)，取回後再檢查。確認不再使用的衣物，也應先判斷是否適合轉贈或其他用途，不把未處理問題交給下一個人。
