# 牛仔衣褲：先決定你要保留什麼

**適用情境：**日常牛仔衣褲。含彈性纖維、特殊塗層、裝飾或未預縮原色款，需要額外核對原廠要求。

牛仔衣物的使用目標可能不同：有人要維持深色，有人接受自然落色。可以接受使用痕跡，不代表要接受髒污或異味；照護頻率應反映實際穿著與髒污。

## 原廠例子如何使用

Levi’s 的照護頁建議翻面、關拉鍊、冷水溫和洗，以及優先自然乾燥；新深色款要與淺色衣物分開。這些支援其一般牛仔衣物的起始判斷，仍需核對手上款式。[Levi’s：Denim care and washing](https://help.levi.com/hc/en-us/articles/15463553339917-Denim-care-and-washing)

本書不把原廠頁面中的穿著次數當作所有人的固定期限。流汗、工作環境、污漬和個人使用情境不同，一個次數無法替你檢查衣物。

## 操作前後比什麼

洗前看腰頭、褲襠、膝部與褲腳，記錄原本磨白區域。確認洗標後分類、前處理、洗滌與乾燥。洗後檢查尺寸和接縫；如果局部擦洗形成淡斑，停止在同一位置加強摩擦。

原色或 Shrink-to-Fit 類款式需查該款的尺寸和浸洗指示，不採一般洗法猜測。含彈性纖維的褲子則需保留彈性限制，見[第 06 章](../06-synthetics-and-blends.md)。

## 顏色問題怎麼接續

本身落色與染到別件衣物是兩件事。若其他衣物被染上顏色，先分開，依[染色轉移案例](../stains/dye-transfer.md)評估；不要為了維持牛仔色澤而忽略同批衣物的結果。
