# 運動機能衣：洗乾淨，也保留原本功能

**適用情境：**一般可水洗運動上衣與彈性褲；有膜材、貼合構造、特殊防護功能者另依原廠。先看[合成纖維](../06-synthetics-and-blends.md)，再確認這件衣服的具體要求。

## 從脫下來就開始安排

本書建議不要把汗濕衣物長期擠在運動袋中。若不能立刻洗，先在合適處展開處理濕氣，再安排相容批次。這是日常流程建議，不以晾乾替代清洗。

Nike 對運動胸罩建議運動後清洗，不能即洗時先晾開；對吸濕排汗類運動衣也提醒避免柔軟精與烘衣紙。這些是其產品照護建議，不是每一件運動服的通用配方。[Nike：Sports bra care](https://www.nike.com/a/how-to-wash-sports-bra)

## 一次可執行的流程

先看衣標，檢查腋下、領口與褲頭。對允許前處理的局部髒污，使用相容衣物產品；有印花的部位不要靠刷到發白換取「洗淨」。接著按衣標選程序和用量，充分完成漂洗，再以允許方式乾燥。

洗後要同時檢查味道、油影、彈性與貼合部位。若只是香味強了但異味仍在，回到[第 15 章](../15-odor-yellowing-and-mildew.md)查流程。若彈性已鬆、接縫起翹，則看[損傷章](../17-wear-damage-and-repair.md)，清潔不保證恢復結構。

## 不把功能名當材質名

「排汗」描述一項功能，不一定對應單一纖維。兩件同樣叫機能衣的產品，可能一件是羊毛、一件是聚酯，也可能有不同整理加工。分類時仍要回到實際成分與衣標，而不是運動用途。
