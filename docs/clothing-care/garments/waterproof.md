# 防水外套：表面潑水與防水層分開看

**適用情境：**已能辨認品牌、系列與洗標的機能外套。以下以 GORE-TEX 原廠文件示範，不涵蓋所有膜材、塗層或防水衣。

## 水不成珠，不等於同一種故障

DWR 是表面耐久撥水整理；膜材與接縫則參與整件防水系統。GORE-TEX 的說明列出不同層合構造，並指出成衣還涉及接縫膠條和其他部件。[GORE-TEX：FAQ，technology integrated in a finished product](https://www.gore-tex.com/support/frequently-asked-questions)

本書因此把外表吸水、接縫滲水和膜材剝離分成不同待查問題。不靠潑水照片自行判定所有問題都能靠補撥水解決。

## 查到系列，才套用清潔指示

一般 GORE-TEX 外套指引包括相容液體洗劑、避免柔軟精、漂白及一般去污劑；清洗後再按原廠條件乾燥或活化撥水。**SHAKEDRY 等持續水珠表面的款式是重要例外：不烘乾、不熨燙、不補 DWR。**[GORE-TEX：Outerwear care，Special Care](https://www.gore-tex.com/en_uk/support/care/outerwear)

所以本頁不列一個所有外套通用的熱處理時間。先確認系列和衣標，再按原廠頁面指定的洗滌與乾燥路線進行。若成衣品牌和膜材指引看似衝突，先詢問成衣原廠，不選自己比較方便的那一邊。

## 洗後如何決定下一步

先確認衣物完整，再評估清洗後的表面狀態。只有原廠允許補撥水且判斷需要時，才用相容產品。接縫翹起、層間起泡、表面剝落或持續漏水，則尋求維修評估。

噴上更多撥水產品不會自動修好破洞或重新黏合分層。這個判斷是從不同部件的功能推導而來，不是對每一件外套故障的遠端診斷。
