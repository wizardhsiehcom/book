# 西裝與結構外套：送洗也是一種需要準備的操作

**適用情境：**有肩部、襯料、內裡或立體剪裁的外套。這一頁是選擇路線與交接指南，不是西裝家庭水洗教學。

## 成分不能回答版型問題

同樣是羊毛，可以做成柔軟毛衣，也可以做成有結構的外套。你希望保留的不只是一片布的顏色，還有前襟、領型、肩部與內裡的相對位置。因此先看成衣洗標，不用毛衣經驗代替。

專業乾洗也不是所有衣物的保證。FTC 的美國洗護規則說明，衣物標示可水洗不代表必然適合乾洗；不同方法有各自的相容條件。這裡引用的是照護觀念，不是台灣法規。[FTC：Clothes Captioning，care methods](https://www.ftc.gov/business-guidance/resources/clothes-captioning-complying-care-labeling-rule)

## 送洗前把資訊交完整

本書建議檢查口袋、記錄鬆扣與破損，拍下整件和局部，說明污漬來源、何時發現及自己用過的產品。若是一套衣物，讓清潔者知道外套與褲裙配成一組，討論色澤一致性與實際清潔需求。

不要只說「幫我洗乾淨」。可以具體說：「前襟這裡有油影，內裡這裡有汗痕，領型希望維持；尚未自行處理。」這讓對方能評估去污和整燙，而不是事後才發現期待不同。

## 取件時檢查

比較污漬、顏色、形狀、鈕扣、內裡和原本破損位置。異常先拍照並與店家確認，避免拿回家再自行加熱或刷洗，讓處理歷史變得難以釐清。

日常保存可參考[第 18 章](../18-storage-and-routines.md)。結構已起泡、內裡扭曲或接合異常時，先評估修復，不把高溫蒸氣當成通用還原方法。
