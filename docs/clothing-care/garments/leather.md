# 皮革與麂皮：先辨認表面，再決定交給誰

**本頁範圍：**辨識、日常檢查與專業送洗界線。皮革染整、補色與修復不在本書家庭操作範圍。

## 名字相似，不等於可用同一瓶產品

光面皮革、麂皮、塗層皮革與合成仿皮的表面不同。衣物還可能混有織物、內裡與裝飾。買到「皮革保養」產品，仍必須確認准用於哪一種表面與顏色。

本書建議先保留成分與型號，不用滴水或上油的結果猜材料。仿皮尤其不能只因外觀像皮，就沿用真皮滋養產品。

## 能做的日常照護

原廠允許的表面除塵可依指示進行；不確定時先不加產品。AllSaints 對其麂皮外套建議避免大雨與直射日光，以柔軟麂皮刷輕理表面；深層污漬則交專業麂皮清潔。[AllSaints：Suede jacket care](https://www.allsaints.com/men/leathers/suede-jackets)

這是限定產品類別的例子。不能把刷麂皮的方法用在已粉化、剝落的仿皮上，也不能把鞋用皮油直接當成衣物處方。

## 遇到污漬或受潮

記錄來源、範圍與已使用的產品，避免任意浸泡、加熱、酒精擦拭或上油。先詢問衣物原廠或具該類材料經驗的清潔／修復者。送件時把皮面、裡布與拼接部位一起拍照。

如果表面已剝落、發黏、掉色或異味反覆，清潔和修復需分開評估。任何專業處理也可能不能完全恢復；本書不以通用保養油承諾解決。
