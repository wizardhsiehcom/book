# 04 羊毛與羊絨：把形狀也當成要保護的東西

羊毛與羊絨都屬動物毛纖維，但來源、纖維細度、紗線與成衣結構不相同。標成羊絨的薄針織衫，不能只因同屬「毛衣」就套用厚實羊毛外套的照護方式。

這一章關注的是衣物的形狀與表面：是否可水洗、濕時如何移動、乾燥時如何支撐，以及如何區分毛球與結構改變。

## 可機洗是一件成衣的資格

Woolmark 的機洗指引以衣標允許機洗的羊毛衣物為前提，並建議相容的羊毛程序與溫和洗劑。不能反過來推論洗衣機有「羊毛」按鈕，就能洗所有毛衣。[Woolmark：How to wash wool](https://www.woolmark.com/care/how-to-wash-wool/)

| 洗標與狀態 | 你要做的判斷 |
|---|---|
| 明確允許機洗，衣物完好 | 核對設備程序與洗劑是否相容 |
| 只允許手洗 | 確認手洗與乾燥的完整安排 |
| 只能專業清潔 | 不用短時間浸泡取代送洗 |
| 洗標缺失、已變形或有特殊裝飾 | 先找原廠資料或專業評估 |

表中的最後一列也適用羊絨。本書沒有查核特定羊絨品牌的所有加工，故不提供「羊絨一律浸多久」的配方。

## 洗劑要問材質相容，不只問酸鹼

Woolmark 的洗劑指引建議中性溫和羊毛洗劑，避開強效、含漂白成分與一般生物酵素洗劑，並明確排除含氯與含氧漂白。實際產品仍須讀適用標示。[Woolmark：Best detergent when washing wool](https://www.woolmark.com/care/best-detergent-when-washing-wool/)

因此，「這瓶是中性」仍不是充分答案；你還要知道它是否適用羊毛、是否含其他不相容功能，以及手洗和機洗的用量是否不同。洗髮精是洗頭產品，不應僅因名字同樣有「洗」就代替有衣物用法的產品。

## 把乾燥安排在下水之前

先準備能支撐濕衣的平面。移動時托住整件，不以肩部承受全部重量；依洗標去除多餘水分後整理輪廓。Woolmark 對未標示可翻滾烘乾的羊毛衣物建議平放乾燥；明示可烘乾的款式才走相應路線。[Woolmark：Tumble drying wool](https://www.woolmark.com/care/tumble-drying-wool/)

本書建議洗前拍下領口與袖口，洗後按原本形狀整理，而不是大力拉到自己想要的尺寸。如果發現整片布面變得緊密、厚實、尺寸縮小，先停止；這不同於衣物還濕時的一點皺折。

## 毛球與縮絨不能用同一種修復想像

毛球是表面維護問題；縮絨涉及布料本身的變化。去毛球可以改善外觀，不能還原縮小的衣長。也不要把泡護髮乳或強力拉伸當成保證復原的方法。具體判斷看[第 17 章](17-wear-damage-and-repair.md)。

完成本章後，你應能說出這件毛衣適合哪條清潔路線、用什麼產品、如何乾燥，以及何時停止。若答案只有「輕柔洗」，還缺了可執行的細節。
