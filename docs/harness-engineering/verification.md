## 程式檢查了哪些失敗

工作迴圈區分正常完成、工具要求被拒、模擬工具執行失敗、步數用完與未驗證。檢查通過後再次修改，舊驗證會失效。固定回應只驗證流程，不測真實模型的選擇品質。

檔案編輯檢查零次、唯一、多次、重疊匹配及空原文。拒絕時逐位元組核對檔案未變；成功時保留 CRLF 換行。`aaa` 搜尋 `aa` 的重疊案例在交叉查核時補入，避免把非重疊計數誤當成唯一位置。

上下文實驗區分漏掉限制、把尚未檢查改成成功，以及保留全部指定資訊。它是固定事實比對，無法替代自由文字摘要的語意審查。

## 出版檢查的範圍

本機輔助檢查保存在 `data/harness-engineering/check_local.py`，可於儲存庫根目錄執行。它核對內容頁中的本地目標與錨點、原論文 HTML 的引用錨點，以及下載檔與共用資產是否和來源相同。建置後再執行一次，才能檢查最新輸出。

主題自動產生的 `404.html` 使用主機根路徑，沒有納入 25 個內容頁的可攜連結檢查。本書尚未設定公開網站掛載網址或自訂 404 路由；若日後公開部署，需另核對這部分。進階增補後重跑嚴格建置與連結檢查；視覺抽查仍是下述首版範圍，新增內容尚未另做瀏覽器覆核。

`check-book-palettes.cjs` 最後仍期待同步腳本含有舊版 shell `cp` 指令，但目前專案已用 Python 複製資產。這項既有格式斷言失敗，不代表本書少了配色檔。另已逐位元組核對本書輸出的共用 CSS、字型初始化及 Mermaid 初始化檔與來源一致；未為本書改動全域檢查器。

視覺抽查發現共用 Mermaid 預設主題的深色箭頭在深色頁面不夠清楚，因此本書圖表加上固定淺色底。窄螢幕保留圖中文字大小，以圖框內橫向捲動閱讀；抽查時正文沒有整頁水平溢出。這是指定頁面的抽查，尚未完成所有頁面、淺色模式與其他瀏覽器的視覺覆核。瀏覽器連線在後續抽查時中斷，未將未完成項記為通過。
