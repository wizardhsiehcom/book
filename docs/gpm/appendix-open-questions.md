# 附錄 C：待查事項總表

全書 16 章的未結問題彙整。**這一頁的存在本身就是一個結論：這本書有大量事情查不到，而查不到的地方必須看得見。**

## 怎麼用這一頁

三種用法：

1. **判斷某個結論有多硬**：如果一個結論依賴的問題出現在這裡，那個結論就還是推論。
2. **決定下一步查什麼**：優先處理下方「高優先」那五題——它們各自卡住好幾章。
3. **定期重跑**：每次均豪發布新法說或年報，回來看有哪幾題可以劃掉。

## 已知無解或可能永遠查不到的

誠實地說，以下幾題大概率查不出來，讀者不必反覆嘗試：

| 問題 | 為什麼查不到 |
|---|---|
| 各節點的缺陷密度（1-4） | 屬晶圓廠核心機密，不對外公開 |
| 客戶產線的實際站點配置與檢測頻率（4-3、11-2） | 客戶端不揭露，設備商亦受保密約束 |
| 未具名客戶的真實身分（P2、15-1） | 雙方刻意不具名，除非有一方主動改變揭露政策 |
| 單機均價與訂單金額分布（14-5 的下游） | 設備業普遍不揭露 |

**對這幾題，正確的做法不是猜，是把它們永久標為未知，並讓依賴它們的結論保持在「推論」等級。**
