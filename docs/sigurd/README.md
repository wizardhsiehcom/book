# 從測試看懂矽格

一顆晶片做好之後，要花多少代價才能確認它是好的？

這本書以**測試**為主線。矽格（Sigurd Microelectronics，TWSE 6257）是專業測試廠，但本書不是公司宣傳冊——前六章先把測試講成一門有成本結構與物理極限的工程，第七、八章才用矽格的公開證據落地，並示範怎麼讀一則擴產新聞。

## 這本書假設你已經知道什麼

你讀過本書庫任一本封裝書，知道晶圓、裸晶與封裝體的差別，但沒有做過量產測試。不需要測試工程背景。

以下概念本書直接引用既有書，不重寫：

- [Chiplet 的良率乘法與 KGD](../../cowos/html/13-test-and-kgd.html)
- [產能、稼動率與資本支出通則](../../gpm/html/14-yield-capacity-capex.html)
- [測試工程師與 DFT 工程師的職務內容](../../semi-jobs/html/16-test.html)

## 讀完之後你能做什麼

把一則矽格消息拆成五段：**測什麼 → 用什麼測 → 測多久 → 誰付這個成本 → 證據到哪一階段**，並說出哪些新資訊會推翻你的判斷。

## 怎麼讀

完整閱讀依章序。趕時間的話：[01](01-test-in-the-flow.md) → [02](02-test-cost-model.md) → [07](07-sigurd-product-evidence.md) → [08](08-reading-news.md)，遇到技術名詞再回讀 03–06。全書依賴關係見[全書地圖](00-map.md)。

## 這本書的證據規則

技術章（01–06）的原理與控制項是工程通則整理，**不對應任何特定廠商的型號規格**；02 與 05 的算例全部是可重算的教學假設，不是任何公司的實際數字。

公司章（07–08）的每一項陳述都標示證據等級：經會計師查核的財務報表、公司官方文件、媒體轉載的公告、媒體轉述，四級不混用。**互相衝突的數字一律並列，不調和。** 未具名的客戶不補名字。

查證未解決的問題列在[待查事項](appendix-open-questions.md)——那是證據缺口，不是未寫的章節。
