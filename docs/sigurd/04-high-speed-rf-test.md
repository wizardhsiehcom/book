# 04　高速與射頻訊號為什麼特別難測？

## 開場問題：治具本身就測不到那麼快，怎麼辦？

低速數位訊號的測試邏輯很單純：給一個電壓，量一個電壓，比對規格。訊號在路徑上損失一點沒關係，因為判定的門檻很寬。

換成一個每秒切換數百億次的訊號，這套邏輯就崩了。**訊號從測試機走到晶片的那段路，本身的頻寬可能還不如被測物。** 你用一把比待測物粗的尺去量它，量到的是尺的誤差，不是物件的尺寸。

這是高速與射頻測試的核心困境：**量測系統本身成為量測極限**。本章談這個限制怎麼來的、業界怎麼繞開它，以及繞開的代價是什麼。先備是 [03 測試單元](03-test-cell.md)。

## 先看結構：訊號路徑的頻寬是串聯的

```mermaid
flowchart LR
    Src["ATE 訊號源<br/>頻寬 B1"] --> LB["load board 走線<br/>頻寬 B2"]
    LB --> Con["接觸介面<br/>socket／探針 頻寬 B3"]
    Con --> DUT["待測晶片<br/>目標速率 B0"]
    DUT --> Ret["回程路徑<br/>同樣受限"]
    Ret --> Meas["量測資源"]
```

整條路徑的有效頻寬由**最窄的那一段**決定。當 B0 接近或超過 B2、B3 時，測到的失敗有兩種可能：晶片真的不行，或治具不行。**分辨這兩者，是高速測試最花時間的工作。**

Advantest 在其平行 RF 針測文件裡把這件事寫成一句話：整體 RF 效能永遠受限於訊號路徑最弱的一環。[T2](appendix-sources.md#T2)

數量級大致如下：ITRS 2009 估計超過 10 Gbps 的訊號需要治具頻寬達 20 GHz 以上；同一份文件列出 10 Gbps 下的 jitter 量測精度需求——總 jitter 3 ps、確定性 jitter 1.5 ps、隨機 jitter 0.11 ps。[T4](appendix-sources.md#T4) 探針卡本身也有頻寬分層：cantilever、vertical 與 membrane 三類各有頻寬與平行度的取捨，membrane 型可達 20 GHz 實測頻寬。[T2](appendix-sources.md#T2)

這些數字都是 2009–10 年代的，不是現行規格。引用它們只為了說明：**治具頻寬需求遠高於訊號本身的速率，而且計時精度要求已經推到 0.1 ps 等級。**


| 限制來源 | 為什麼在高速下變嚴重 | 低速時為何不明顯 |
|---|---|---|
| 走線長度 | 衰減隨頻率上升；阻抗不連續造成反射 | 判定門檻寬，小幅衰減無影響 |
| 接觸介面的電感 | 接點的寄生電感在高頻形成阻抗 | 低頻下阻抗小到可忽略 |
| 電源完整性 | 高速切換瞬間電流大，電源塌陷影響時序 | 電流變化小 |
| 串擾 | 相鄰通道耦合隨頻率增強 | 耦合量小 |
| 時基精度 | 要判定的時間窗口只有數 ps | 窗口是 ns 等級，餘裕大 |

## 輸入／操作／輸出：三種繞開治具極限的做法

既然直接量測受限於治具，業界發展出幾條路。每條路都有代價。

| 做法 | 原理 | 換到什麼 | 代價 |
|---|---|---|---|
| 內建自我測試（loopback／BIST） | 讓晶片自己產生訊號、自己收、自己判定 | 訊號不必離開晶片，繞過治具極限 | 測的是晶片對自己的判定，不是對外部世界的真實表現；且佔用晶片面積 |
| 降速測試＋設計保證 | 在較低速率下測，高速性能由設計與製程統計保證 | 治具需求降低、成本下降 | 承擔統計風險：降速通過不保證全速通過 |
| 專用高速治具 | 縮短走線、改善阻抗匹配、特製 socket | 真正量到接近規格的性能 | 治具極貴、壽命短、通道數受限、換線慢 |
| 抽測全速 | 少量樣本用高階治具全速驗證 | 兼顧成本與信心 | 只有統計保證，不是逐顆保證 |

**關鍵推導**：這四條路沒有一條能同時達成「逐顆、全速、低成本」。實務上是混合使用——大部分項目用便宜的方式，關鍵項目用貴的方式，並用相關性研究（correlation study）證明便宜的方式與貴的方式判定一致。**相關性研究本身就是測試工程的核心產出之一。**

## 失敗會長什麼樣子：最怕「治具的問題長得像晶片的問題」

| 現象 | 機制 | 需要的證據 |
|---|---|---|
| 高速項目失敗、低速全過 | 治具頻寬不足，不是晶片問題 | 用已知良品（golden unit）在同治具上測，看是否同樣失敗 |
| 換一片 load board 結果就變 | 兩片的走線或阻抗特性不同 | 治具本身的通道特性量測（不是量晶片） |
| 邊緣通道失敗率高 | 走線長度不一致，邊緣通道路徑較長 | 依通道位置分類的失敗率 |
| 同時切換多通道才失敗 | 電源塌陷或串擾，不是單通道問題 | 單通道測與全通道同時測的比對 |
| ATE 過、客戶端不過 | 真實系統的訊號環境比 ATE 髒 | SLT 或客戶端重現條件；見 [01](01-test-in-the-flow.md) |
| loopback 過、外部測不過 | 自我測試繞過了對外介面的真實負載 | 至少抽樣做外部量測驗證 loopback 的代表性 |

**第一列與最後一列是同一類錯誤的兩面**：把量測系統的限制當成待測物的性質。前者過殺（丟掉好晶片），後者漏檢（放行壞晶片）。

## 如何檢查與控制：先證明治具，再判定晶片

高速測試的第一條紀律是：**在相信任何量測結果之前，先證明量測系統本身是可信的。**

| 控制項 | 怎麼做 | 沒做的後果 |
|---|---|---|
| 治具特性量測 | 量 load board／socket 本身的頻率響應與串擾 | 分不清是治具還是晶片的問題 |
| 標準件驗證 | 已知良品在治具上應該全過 | 良率損失被誤歸因為製程 |
| 通道間一致性 | 各通道的裕度分布 | 特定通道的系統性偏差被當成隨機不良 |
| CP 與 FT 相關性研究 | 同一顆在兩個插入點的結果比對 | 無法判斷哪一站的判定可信 |
| 替代測法的相關性 | loopback 或降速測法與全速測法的一致率 | 便宜測法的代表性無人背書 |
| 治具壽命 | 接觸次數與性能退化的趨勢 | 治具老化被誤讀成產品品質下滑 |

一份能判定的高速測試方案，至少要寫出：**目標速率、治具實測頻寬、用哪種測法、替代測法的相關性數據、裕度（guard band）設多少、這個方案適用哪些產品**。缺相關性數據，替代測法就沒有工程依據。

5G 測試遇過一個具體的版本。IEEE EPS 的一篇論文指出：傳統類比 IQ 調變的頻寬限制約在 1 GHz，要支援更寬的訊號必須轉向全數位 IQ；而在晶圓針測階段，還要把 40 GHz 以上的訊號送到密集的 die pad 陣列上。[T9](appendix-sources.md#T9) **量測系統的架構被待測物的規格逼迫改寫，這就是「治具成為極限」的具體面貌。**

毫米波與射頻測試再多一層問題：訊號在空間中傳播、對治具幾何極度敏感、需要校正到參考面（reference plane）。**校正面在哪裡，決定你量到的是不是晶片的性能**——校正面若停在 socket 外側，量到的就包含 socket 的損耗。

## 理解檢查

??? question "為什麼「高速項目失敗、低速全過」不能直接判定晶片不良？"
    因為治具本身的頻寬可能就不足以支撐高速項目。最快的分辨方法是拿已知良品在同一治具上測——如果良品也失敗，問題在治具；如果良品通過，才有理由懷疑晶片。先證明量測系統，再判定待測物。

??? question "loopback 自我測試很便宜又繞過治具限制，為什麼不全部用它？"
    因為它測的是晶片對自己的判定。真實應用中，訊號要送到另一顆晶片、經過一段通道、被不同的接收端解讀。loopback 不涵蓋這段外部負載與對端差異。實務上必須用抽樣的外部量測，證明 loopback 的判定與真實情況相關，這個相關性才是它可信的依據。

??? question "什麼叫「校正面」，為什麼射頻測試特別在意它？"
    校正面是量測數據所代表的實體位置。校正只做到測試機端點，量到的就包含後面所有治具的損耗；校正推進到 socket 內側，量到的才接近晶片本身。射頻下治具損耗佔比大，校正面差一段，數字就差很多，因此規格必須連同校正面一起陳述。

??? question "為什麼「同時切換多通道才失敗」通常不是單一通道的問題？"
    多通道同時切換時瞬間電流最大，最容易引發電源塌陷；相鄰通道的串擾也在此時最強。單通道測正常代表該通道本身沒問題，失敗來自通道間的交互作用或供電能力，要查的是電源完整性與治具佈局，不是那一條通道。
