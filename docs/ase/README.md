# 從封裝測試看懂日月光

晶圓廠把晶片做好了，為什麼還要把它送到另一家公司手上，才變成能裝進機器裡的東西？

這本書以**封裝與測試**為主線。日月光投控（ASE Technology Holding，TWSE 3711／NYSE ASX）是全球最大的委外封裝測試服務商（OSAT），但本書不是公司宣傳冊——前八章先把封裝測試講成一門有結構、有失效模式、有責任歸屬的工程，後三章才用公開證據落地，並示範怎麼讀一則技術發布、一則擴產公告、一份季報。

## 這本書假設你已經知道什麼

你知道晶圓和晶片的差別，會讀半導體產業新聞，但沒有封測背景。開頭兩章補足最小先備，不需要先讀其他書。

## 讀完之後你能做什麼

把一則日月光消息拆成五段：**這是哪個主體 → 技術落在哪一階段 → 數字是什麼口徑 → 誰說的 → 什麼會讓我改判**，並說得出哪些資訊公開資料裡根本查不到。

完整閱讀依章序。趕時間的話：[01](01-osat-value-chain.md) → [02](02-group-and-business.md) → [09](09-capacity-and-economics.md) → [10](10-ase-service-evidence.md) → [11](11-reading-news.md)，遇到技術名詞再回讀 03–08。全書依賴關係與兩把證據尺規見[全書地圖](00-map.md)。

## 這本書的證據規則

技術章（01、03–08）的原理、失效模式與控制項是工程通則整理，**不對應任何特定廠商的型號規格**；書中所有算例都是可重算的教學假設，**不是任何公司的實際成本、良率或產能**。

公司章（02、09–11）的每一項陳述都標示**證據等級**（誰說的）與**證據階段**（做到哪）。經查核的財務報表、公司官方文件、媒體轉載公告、媒體轉述，四級不混用；研發、展示、客戶驗證、量產，四階段不跳階。**公司新聞稿只證明「公司這樣說過」，不是技術性能的獨立驗證。** 互相衝突的數字一律並列，不調和。未具名的客戶不補名字。

本書撰寫期間，日月光的品牌技術站與投資人關係站**皆回傳 HTTP 403**，官方技術規格表與法說會簡報原檔未能取得——這不是省略，是缺口，逐項記在[來源索引](appendix-sources.md)與[待查事項](appendix-open-questions.md)。

**本書不預測股價、不給買賣建議、不建估值模型。**
