# 04　漏檢、假警報與誤殺，分母究竟是誰？

兩套系統都說「準確率 99%」，其中一套可能把罕見的真缺陷全部放過。問題不在百分號，而在被計數的對象。先讀[四種任務](03-detection-metrology-review.md)，本章再把每個結果放進固定分母，避免檢測、分類與最終報廢混成一個成績。

## 固定單位後再畫矩陣

以下全是**教學假設**：以 10,000 個獨立受檢單位為集合，參考判定指出 100 個有缺陷、9,900 個良好；系統對每個單位都輸出「攔截」或「放行」。這裡先假設參考判定可信且沒有未知，實際驗收若有爭議樣本必須另列。

| 參考狀態 | 系統攔截 | 系統放行 | 合計 |
|---|---:|---:|---:|
| 有缺陷 | 90：真陽性 TP | 10：假陰性 FN | 100 |
| 良好 | 198：假陽性 FP | 9,702：真陰性 TN | 9,900 |
| 合計 | 288 | 9,712 | 10,000 |

召回率 recall 是找到的真缺陷占全部真缺陷：90 / 100 = 90%。漏檢率在本章定義為 FN / 全部真缺陷，即 10%。精確率 precision 是攔截結果中真正有缺陷的比例：90 / 288 = 31.25%。良品假警報率為 FP / 全部良品：198 / 9,900 = 2%。

總正確率 accuracy 為 (90 + 9,702) / 10,000 = 97.92%。若另一套系統全部放行，總正確率反而是 99%，但召回率降為零。這就是缺陷罕見時，整體 accuracy 容易遮住風險的原因。

## 假警報不一定成為誤殺

在候選階段，系統把良好單位列為異常，可以叫假警報或 false positive。若後續複判把它排除，它未必造成報廢；仍可能消耗人力、等待時間及重新取像成本。只有整個決策流程真的把良品當成不良處理，才形成相應的誤殺損失。

產業用語 overkill、escape 的分母並不總是一致。本書每次計算都寫完整分母，不假設一個英文詞即可消除歧義。例如「放行品中的不良比例」在本例是 10 / 9,712，約 0.103%；它不同於「真缺陷中的漏檢比例」10 / 100 = 10%。兩者都能有用，但不能互換。

## 閾值改變了誰的工作？

把異常閾值調低，通常會讓更多位置成為候選，可能找到更多真缺陷，也可能送出更多正常背景。這只是一般取捨方向，實際幅度要用同一批資料重算，不能假設所有演算法都有一條平滑、穩定的改善曲線。

若 288 個候選每個需複判 10 秒，總工作量是 2,880 秒，即 48 分鐘。這個算例假設不需搬送、開圖與補拍；現場還應加入那些時間。如果後端每小時只能處理 200 個候選，而前端每小時持續送入 288 個，佇列會逐漸增長。單機拍得再快，也不能消除分類端的缺口。

## 把檢出與 ADC 串起來

再用一個不同的教學集合：全部 100 個真缺陷中，上游找到 90 個；ADC 在收到的這 90 個真缺陷中保留 95%，則預期保留 85.5 個，端到端召回率為 85.5%。小數是期望值；實際單批個數必須是整數。

乘法成立的原因是第二個比例**條件化於上游已找到的缺陷**，不需要假設兩站獨立。若 ADC 的 95% 來自另一批更容易的資料，就不能直接相乘。還要處理沒有影像、傳輸失敗與未知樣本，否則兩個看似完整的成績都可能漏算同一群工件。

## 參考判定也要驗證

人工標註不是天然真相。邊界不清、影像不足或類別規則矛盾，都可能讓兩位判讀者得到不同答案。可採雙人獨立標註、爭議仲裁，以及必要時的額外量測，保存參考判定的依據與版本。

訓練與測試資料也應按可能共享資訊的群組切開。例如同一晶圓相鄰位置的近似影像若同時進入兩邊，測試可能過度容易。若要推論未來量產表現，應包含時間較晚、不同批次與合理的工況變化，並另報高風險少數類別。

驗收時，零次觀察到漏檢也不等於真實漏檢率為零。它可能只是樣本太少。應把樣本量、抽樣方式與估計的不確定性一起交付，不能把「本次未見」寫成無條件保證。

## 與倍利的連結

**已確認：** 倍利公開提供 AI 平台及相關效益敘述，來源與條件見[產品證據矩陣](14-v5-product-evidence.md)。

**推論：** 人力減少與品質指標應聯合驗收。把大量候選自動排除，可以減少複判，也可能改變漏放風險；需要同一集合的前後比較才能區分。

**待查：** 公開效益對應的候選比例、人工範圍、各類召回率與端到端結果。公司給出的節省比例不能代入本章教學矩陣。

## 理解檢查

1. 本章 2% 與約 0.103% 的分母分別是什麼？
2. 假警報很多但最終沒有報廢良品，是否完全沒有成本？
3. 兩站召回率何時可以相乘？
4. 測試零漏檢，還需要記錄什麼？

??? note "參考推理"
    1. 2% 是全部良品中的假警報；約 0.103% 是放行單位中的不良比例。
    2. 仍有複判、等待、補拍與產能成本。
    3. 第二站成績必須是對第一站已保留真缺陷的條件比例，且集合、定義與資料交接一致。
    4. 樣本數、來源、缺陷類型、工況、參考判定與統計不確定性。
