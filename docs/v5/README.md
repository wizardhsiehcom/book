# 從半導體檢測看懂倍利科技（V5）

**光學、量測、AI 與產線導入**

倍利的產品介紹同時出現晶圓檢量測、OM 升級、Inline AOI 和 AI 平台。這本書從沒有設備背景的讀者出發，先解釋缺陷如何被看見、量測和分類，再問不同方案在產線裡承擔什麼責任，最後回到可查證的公司資料。

V5 在這裡指倍利科技的品牌稱呼，並非第五版。公司主體為倍利科技股份有限公司，原始資料以 [v5.com.tw](https://www.v5.com.tw/) 為入口。

## 讀完能做什麼？

- 拆清楚檢出、量測、複判、分類與品質放行。
- 看懂倍率、像素、檢出尺寸與量測不確定度的差別。
- 用工件、品質、節拍和資料接口分析整機、改造、機內模組與軟體。
- 重算漏檢、假警報、人工工時及有效產能的教學算例。
- 將公司消息拆成公開事實、作者推論與待查證條件。

全書 16 章、四篇，每章有理解檢查與可展開的參考推理。先讀[全書地圖](00-map.md)，也可以直接從[為什麼需要檢測](01-why-inspection.md)開始。

## 怎麼讀本書的證據？

公司來源查閱日為 **2026-09-14**，採用官網及 2026 年 3 月、4 月、8 月簡報；每份來源仍保留自己的發表日期與版本。查閱日不是所有數字的統計截止日，也不表示資料會自動更新。

「已確認」指已核對公開來源的內容；公司自述與客戶共同驗證分開。作者自行建立的流程、算例與驗收問題都有標示，不能當作倍利設備架構、測試結果或客戶實績。全文採原理解說與有限的來源摘要，完整文件請循連結閱讀。

部分重要條件仍未公開，例如 100X／150X 配置關係、特定型號的共同品質與節拍、ADC 效益完整分母及 3D 商用證據。這些具體問題保留於[待查表](appendix-open-questions.md)，不妨礙先學會如何判讀。
