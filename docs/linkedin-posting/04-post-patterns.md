# 04｜六種內容模式：同一份材料，可以回答不同問題

本章承接 [C03 素材與選題](03-material-and-topics.md)：選好一個讀者問題後，再決定用哪一種論述方式。六種模式是本書整理材料的編輯分類，不是 LinkedIn 官方內容類別、演算法標籤或成效排名。它們可以混合，但一篇短貼文最好先有一個主要任務。

如果材料來自設備、視覺 AI 或軟體整合，先把已做過、公開可說、閱讀所得與假設分開。以下真實貼文只供結構觀察，作者的自述不等於獨立驗證；後面的 AOI 草稿則是明確標記的合成情境，不能改成個人工作成果。

## 六種模式各自要完成什麼

| 模式 | 主要任務 | 常見結構 | 先確認什麼 |
|---|---|---|---|
| 教學拆解 | 讓讀者能理解或嘗試一種做法 | 問題 → 步驟 → 小例子 → 限制 | 步驟是否真的有材料支撐；讀者需要哪些前提？ |
| 案例復盤 | 說明一次決策如何形成、後來看到什麼 | 情境 → 目標／限制 → 選擇 → 結果 → 教訓 | 結果是否已觀察；有沒有把推測寫成原因？ |
| 觀點論證 | 提出可檢查的專業判斷 | 主張 → 理由／證據 → 反例 → 適用邊界 | 讀者能否分辨事實與判斷？什麼情況下不成立？ |
| 經驗敘事 | 用一個具體事件呈現理解轉變 | 場景 → 摩擦／轉折 → 新理解 → 對讀者的用途 | 哪個細節是真實且必要的？有沒有為了故事效果誇大？ |
| 資料解讀 | 幫讀者讀懂一組可追溯的資料 | 來源與樣本 → 發現 → 限制 → 實務意涵 | 期間、分母、指標、帳號類型或資料範圍是否交代？ |
| 專業提問 | 把有上下文的問題交給同行共同補充 | 情境 → 自己目前的判斷 → 明確問題 | 作者有沒有先做功課？問題是否小到能具體回答？ |

選模式時可依序問三件事：我希望讀者帶走一個方法、一個決策脈絡、一個判斷，還是一個可回答的問題？我手上有什麼證據？缺少的部分能不能明說？例如只有公開報告，適合做資料解讀；尚未完成的原型可寫成設計與提問，不能包裝成案例復盤。結尾的 CTA（邀請讀者採取下一步）與媒介是另外兩項選擇，C05 會再處理開頭和編輯，C06 再處理發布格式。

## 同一份合成 AOI 材料，寫成教學或復盤

### 先固定材料與證據邊界

以下情境、人物、影像條件與事件均為**合成示例**，不是任何人的真實專案、實驗或設備資料。假設題目是：一個反光金屬零件的 AOI 檢查畫面中，高光邊緣被框成疑似刮痕。可用材料只有示意圖、檢查區域、缺陷定義、拍攝條件清單，以及尚待執行的對照測試設計；沒有量測結果、準確率或產線驗收。兩篇草稿使用相同材料，只改變要回答的問題。

### 草稿 A：教學拆解

> **合成示例｜資訊型草稿；未描述真實測試**
>
> AOI 把金屬表面的高光邊緣標成疑似刮痕時，先別急著調分類閾值。
>
> 假設檢查對象是反光金屬零件，異常框剛好落在一條亮邊。這只是線索，還不能證明反光就是誤報原因。排查可以先分四步：
>
> 1. **固定問題定義。** 把「刮痕」和「可接受的表面反光」寫成可供複判的標準，避免模型、工程師和品保各自用不同定義。
> 2. **確認取像條件。** 記下光源方向、曝光、增益、零件定位與檢查區域。若條件同時變動，就很難知道畫面差異來自哪裡。
> 3. **準備成對影像與複判。** 比較相同零件在不同取像條件下的影像，並讓熟悉判定標準的人標記真缺陷、反光與不確定案例。
> 4. **再決定改哪一層。** 根據對照結果，才評估打光、影像前處理、ROI、規則或模型門檻；每次只改一類因素，並確認真缺陷仍會被保留。
>
> 這個合成情境沒有實測答案，所以不能宣稱已找到根因或改善誤報。它示範的是先讓錯誤可檢查，再選擇修正位置。
>
> 你在 AOI 排查中，會先固定取像條件、標註規則，還是模型門檻？哪些情況會改變你的順序？

這篇的主角是「可重複的排查順序」。若真的照做，發布前需換成自己實際完成的步驟與材料，並刪除沒有做過的部分；若只有設計，請保持「計畫／示意」語氣。

### 草稿 B：案例復盤式的假想演練

> **合成示例｜假想復盤草稿；不是實驗結果或個人履歷**
>
> 一個 AOI 誤報看起來像模型問題，也可能只是我們還沒把問題描述清楚。
>
> 假想情境：反光金屬零件的高光邊緣被標成疑似刮痕。面對這個畫面，至少有三個方向：提高分類門檻、補充困難影像，或先確認取像條件與缺陷標準。
>
> 這份演練把「先查取像與標註」排在前面，因為目前只有一張示意圖，還沒有證據足以判定是模型、光源或標註造成。下一步會先建立成對影像：固定零件與檢查區域，記錄光源方向和曝光，再請複判者依同一套標準區分真刮痕、反光和不確定樣本。
>
> 這裡沒有宣稱做完測試，也沒有前後準確率。若對照影像顯示高光變化而缺陷特徵仍一致，才有理由把成像列為優先調查方向；即使如此，也要保留其他可能原因。若證據指向分類或標註，再回頭檢查模型門檻與資料定義。
>
> 這個案例演練的重點是：復盤不只是說「改了什麼」，還要說當時有哪些選項、為何先查某一層，以及什麼結果會推翻自己的猜測。
>
> 如果你看到同樣的單張誤報，會先要求哪一項證據，才決定動模型？

不能把「假想情境」剪掉後當成親身復盤。真實復盤必須補上已完成的測試、可公開的觀察、結果範圍與未解問題。沒有結果時，可以分享設計或專業提問，無須假裝已有答案。

這份草稿刻意停在**復盤前半段的決策演練**：它交代情境、可選方向和下一步，但沒有測試結果，不能當成一篇完整的真實復盤。要寫成正式復盤，還須補上實際執行的對照、觀察到的結果、哪些推測被支持或推翻，以及結果適用的範圍；如果沒有這些材料，就保留「演練／待驗證」標記。

### 同一材料換模式時，改的是任務與證據順序

| 編輯面向 | 教學拆解 | 復盤／決策演練 |
|---|---|---|
| 目標 | 讓讀者學到一套可執行的排查順序 | 讓讀者看懂為何先查某一層，以及如何判斷下一步 |
| 順序 | 問題 → 步驟 → 限制 → 可選提問 | 情境 → 選項 → 當下依據 → 結果／待驗證 → 教訓 |
| 證據 | 每個步驟的前提、影像或檢查紀錄；示例需標記 | 決策時可用的材料、實際對照與觀察；推論另標 |
| 沒有結果時 | 分享方法設計，明說尚未驗證 | 只寫成復盤前半段演練或待測計畫，不宣稱完成，也不虛構改善 |

兩種版本可以使用同一張示意圖，卻不該用相同的第一句和段落安排。若目標是教人操作，就把步驟寫清楚；若要說明工程判斷，就呈現選項與證據，並回答什麼新資料會讓自己改變主意。

## 練習：用同一材料寫出兩個版本

挑一個自己可公開的工程問題，或繼續使用上面的合成 AOI 情境：

1. 用一句話界定讀者問題，並標記材料是已完成、公開資料、閱讀所得或合成假設。
2. 先寫教學版：列出三到五個能實際執行的步驟，最後加一個適用限制。
3. 再寫復盤版：列出當時選項、選擇理由、觀察到的結果；沒有結果就明確寫「尚未測試」，不可補造。
4. 圈出每個因果字眼，例如「因此」「造成」「改善」，問自己是否有對照證據支持。
5. CTA 只問一件事；若問題只是為了求留言、與本文無關，就刪掉。

再從六種模式各挑一題，寫成一行草稿大綱：

- **教學拆解：** 用一張合成的反光誤報示意圖，寫出三步如何確認取像條件；標出尚未驗證的部分。
- **案例復盤：** 回想（或假設）一次模型輸出不穩定的情境，列出當時兩種可選修正，以及什麼結果支持其中一種。沒有真實結果就標為演練。
- **觀點論證：** 論證「調高閾值不應是每次 AOI 誤報的第一個反應」，各寫一項支持理由、反例與適用邊界。
- **經驗敘事：** 選一個真實、可公開的工程事件，寫出自己從哪個細節改變原判斷；若沒有可公開事件，改用明確標記的假設，不冒充親身故事。
- **資料解讀：** 找一份可追溯的公開 AOI／影像檢查資料，寫清來源、樣本範圍、指標與不能推出的結論；不要只摘單一數字。
- **專業提問：** 描述反光區被判疑似刮痕的情境，先列出目前假設和還缺的證據，再問同行會如何設計最小對照。

完成後進入 [C05 開頭與編輯](05-opening-and-editing.md)：把兩版都改成工程同行與跨域主管容易理解的版本，再確認承諾與證據相稱。
