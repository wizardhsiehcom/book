# 設備 AI 工程師的 LinkedIn 寫作

從半導體設備與視覺 AI 出發，把工程問題寫清楚，再用公開作品探索軟體 RD、LLM 與 Agent。

你可能已經有不少值得分享的材料：一次難以解釋的誤判、一段終於能追查的日誌、一個尚未成功的文件問答原型。困難往往是，怎麼讓不在現場的人理解問題，又能判斷你實際做了什麼。

本書以九章練習為主線，另以研究與作者案例補充如何選擇寫法。讀完會留下自己的讀者定位、題庫、兩篇草稿、四週練習安排與回顧紀錄。AOI 指自動光學檢測，RD 在本書指研發角色；LLM 指大型語言模型，Agent 指能依任務選擇工具並推進工作的 AI 系統。它適合從設備或影像 AI 延伸到軟體與 AI 應用的工程師；沒有要求你先成為某領域專家。

## 本書怎麼使用來源

初版查核日期為 **2026-09-30**，研究擴充日期為 **2026-10-03**；各案例保留自己的查核日期。來源分成官方平台文件、觀察性研究、作者公開案例，以及本書的編輯建議。引用就在相關段落旁；日期未公開的貼文不推算精確發布日。先讀[案例、讚數與作者歷程的判讀方法](research-method.md)，可以知道每種材料能支持哪些結論。

案例涵蓋半導體／設備、LLM 與 Agent。這些是用來學寫法的少量樣本，沒有以互動量排行，也不能代表整個產業。個人技術長文用來補充工程推理，與 LinkedIn 短貼文分開看。

**合成示例是寫作教材。** 其中的角色、操作與數字不代表讀者經歷或實測結果。要改成自己的成果貼文，必須換成確實完成且能公開的材料。公開原型、設備端測試與量產部署也應各自說明。

全書不需要付費排程或分析工具。先用文字檔和自己看得到的帳號紀錄即可；平台功能會變動，實際操作時以當時官方說明與介面為準。
