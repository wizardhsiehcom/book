# 記錄留言品質：看內容增加了什麼

留言品質指留言替技術理解或交流增加的內容，不等於留言數、正面語氣或貼文觸及。記錄時分開三件事：留言增加了什麼資訊、它表達何種立場，以及發言者是讀者還是作者。同一則留言可以同時是專業補充與異議，也可能附帶推廣連結。

## 簡單記錄法

每筆記下貼文 ID／網址、觀察日、頁面顯示的相對時間與「總反應／留言」標籤、可見範圍、留言短摘或準確摘要、類別，以及它補上的條件或仍待核實之處。類別可用：**專業補充**（機制、資源或實務條件）、**反例／異議**（反面證據、代價或限制）、**認同／鼓勵**、**推廣／標記同行**、**作者續篇／答覆**。可多選；讚美能記為支持性回應，但不能當成技術驗證。批評若提出可檢查的速度、成本或連接條件，可能比單純認同更有技術資訊。推廣與資訊價值分欄記，不把商業連結當成證據。

## 怎麼判斷一則留言是否有用

先問它有沒有提供可追查的來源、具體案例、失效條件或能改變工程判斷的限制，再記下它支持或挑戰了哪一項主張。設備與軟體 RD 可把供電、走線、熱、維修、吞吐或成本等條件記成待查問題；寫 LLM／Agent 時，可記錄安全、使用者回饋、澄清需求與同行資源。作者續篇要和讀者留言分開，避免把作者補充算作外部驗證。感謝與推廣仍可記錄其交流功能，但不替它們加上技術證據分。

可用的單行格式是：`貼文｜留言摘要｜類別｜新增的證據或限制｜下一步核查｜可見範圍`。只記讀到的部分，未讀留言留白。這份紀錄能幫作者修正說法、補足條件或找到下一個題目；它本身不能證明留言分類會增加流量、曝光或互動。
