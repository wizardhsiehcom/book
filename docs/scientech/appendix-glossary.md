# 附錄 B：術語表

這是全書工作用語，不取代客戶規範或標準正文。第一次閱讀可先記住「目標層、保留層、用途、驗證範圍」，不必先背設備型號。

| 用語 | 英文 | 在本書中的意思與邊界 |
|---|---|---|
| 晶圓 | wafer | 工件外形不是用途；可能是元件晶圓、監控晶圓或載具 |
| 元件晶圓 | device wafer | 帶有產品結構／元件的工件；累積的製程狀態不能任意消除 |
| 監控晶圓 | monitor wafer | 用來監控製程；再利用資格依指定用途判定，不是恢復原電路 |
| 載具晶圓 | carrier wafer | 支撐另一工件的載具；與被薄化的元件晶圓分開記錄 |
| 目標層 | target layer | 此次預定移除或改變的材料，可能只在局部區域 |
| 保留層 | retained layer | 必須維持要求的材料或結構，不一定只在目標層正下方 |
| 選擇比 | selectivity | 在指定條件下不同材料移除速率的比；不是零損傷保證 |
| 過蝕刻 | over-etch | 為確保目標層去除而增加的加工；可能消耗其他材料餘裕 |
| 光阻 | photoresist／PR | 用以定義加工位置的感光材料，不是下層線路本身 |
| 顯影 | development | 依光阻系統將曝光形成的差異轉為圖案，不等於下層已蝕刻 |
| 去膠／光阻剝離 | resist strip | 移除光阻；正常流程與候選重工皆可能出現此動作 |
| 圖案轉移 | pattern transfer | 把遮罩所定義的空間關係轉成下層加工結果，不能靠去膠自動撤銷 |
| 關鍵尺寸 | critical dimension／CD | 指定圖案的關鍵幾何尺寸；需附量測方法與位置 |
| 對位誤差 | overlay error | 不同圖案層之間的相對位置誤差；不等同一般搬送定位 |
| 殘留 | residue | 原預定移除卻仍存在的物質；不必然能被肉眼或一種儀器看到 |
| 污染 | contamination | 對目標用途不允許的外來或再分布物質；與原製程殘留可重疊但不能混作單一量測 |
| 損傷 | damage | 原需保留的結構或性質被改變；清掉污染也不等於修復損傷 |
| 凸塊下金屬層 | under-bump metallization／UBM | 凸塊與下方接點之間的金屬結構；實際堆疊及各層角色需另查 |
| 暫時接合／鍵合 | temporary bonding | 為支撐加工而設計的接合，須搭配指定分離路徑 |
| 解鍵合 | debonding | 分離接合體；物理分離不等於兩表面回到原始合格狀態 |
| 永久／混合接合 | permanent／hybrid bonding | 不同於暫時黏著的界面設計，混合接合含介電與金屬接點 |
| 總厚度變異 | total thickness variation／TTV | 指定量測範圍內的厚度差異；不能與整片翹曲混為一談 |
| Bow／warp | bow／warp | 晶圓形狀量測指標；定義、參考面與支撐狀態需附方法 |
| 重測 | retest | 再取量測證據，不等於改變工件 |
| 重工 | rework | 異常後依核准路徑重新加工以滿足要求；需指定回到哪一站 |
| 再生 | reclaim | 恢復特定用途晶圓的可用條件，不等於恢復元件晶圓原電路 |
| 再驗證 | requalification／reverification（依情境） | 確認處置後仍滿足指定用途；本書不將兩個英文用語當跨產業統一標準 |
| 可靠度 | reliability | 在指定時間、環境與應力下維持功能的證據，不是一次量測通過 |
| 瓶頸 | bottleneck | 限制本情境流率的資源；加入重工可能改變瓶頸位置 |
| 每小時產出 | units per hour／UPH | 須說清輸入／輸出、合格／全部、理想／實際及批次條件 |
| 自製／代理／服務 | manufacturing／distribution／service | 以誰研發製造、誰交付何物及官方揭露分列，不由產品名猜收入 |
