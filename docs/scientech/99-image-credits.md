# 附錄 D：圖表來源與使用邊界

本書並用兩類視覺資料：**原創教學圖表**與 **Wikimedia Commons 自由授權／公有領域圖片**。外部圖片用來辨認工件、材料移除與檢測範圍，不是辛耘的設備照片、工廠現場或客戶實績。

外部圖片參考 GPM 書的方式：正文遠端顯示圖片，點圖連到 Commons `File:` 頁，**圖檔不下載進 repo**。顯示需要網路，來源失效或限流時可能暫時無法載入；圖說與替代文字仍保留。2026-09-18 逐張讀取檔案頁原始內容及 Commons API 的作者、來源與授權欄位，不以 Commons 網站頁尾授權代替個別圖片授權。

### 外部圖的閱讀邊界

- W01／W02 是外觀對照，不提供膜系、污染、電性或製程站點證據。
- W03 只畫 CMP 接觸配置，不替處理分類為重工或再生；承載頭也不等同暫時接合載具。
- W04 固定非等向蝕刻假設比較材料選擇性；W05 以正光阻與氧化層說明正常圖案轉移，均不是操作配方。
- W06 不能證明晶圓已乾淨；W07 的缺口是晶粒已取走，不是清洗破片或本書 carrier 堆疊。
- W08 是 SU-8 接合的局部截面，不是本書暫時接合案例或可靠度證明；W09 是圖案幾何，不是電性良率圖。

## 如何避免把圖讀過頭

剖面中的厚度、寬度與顏色用於區分角色，不提供比例、材料或操作條件。決策圖中的「通過」只對應該節定義的範圍。表格將未知分列，不因版面對齊而假設不同公司、設備或材料可直接互換。
