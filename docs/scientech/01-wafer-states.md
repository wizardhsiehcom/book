# 01 同一片晶圓，做到哪一步了？

## 為什麼只說「洗一片 wafer」還不夠？

兩片外觀看似相同的圓片，一片只有矽基材，另一片已做出金屬線路。都送進清洗設備，能否使用同一種處理？不能只憑直徑與顏色回答。**晶圓是工件的形狀與載體名稱，不是完整的材料狀態，也不是用途保證。**

本書主要討論矽晶圓上的加工；其他半導體基材不可直接套用其材料相容性。晶圓可以承載產品元件，也可以用來測試製程、監控設備，或扮演支撐載具。用途決定要保留什麼、量測什麼，以及處理完成後可以去哪裡。監控片不一定做完整電路，但仍可能有嚴格的表面與污染要求。

## 從基材到有圖案的工件

[![兩片不同尺寸、表面沒有積體電路圖案的矽晶圓](https://commons.wikimedia.org/wiki/Special:FilePath/Siliziumwafer.JPG){ .wiki-image width="600" loading="lazy" }](https://commons.wikimedia.org/wiki/File:Siliziumwafer.JPG)

*圖 01-W1｜先看工件外觀：兩種尺寸的矽晶圓，原始檔案說明為尚無 IC 電路。鏡面外觀不等於沒有氧化層、污染或厚度差，不能用照片替代來料履歷。Hebbe／公有領域；[圖片出處 W01](99-image-credits.md#w01)。*

[![展示盒中的矽晶圓，表面可見重複排列的晶粒圖案](https://commons.wikimedia.org/wiki/Special:FilePath/ICC_2008_Poland_Silicon_Wafer_1_edit.png){ .wiki-image width="500" loading="lazy" }](https://commons.wikimedia.org/wiki/File:ICC_2008_Poland_Silicon_Wafer_1_edit.png)

*圖 01-W2｜再看有圖案的工件：這是 Intel 展示晶圓的照片，不是辛耘現場。重複圖案讓「圓片」與「片上的晶粒」可被分開辨認，但照片不能告訴我們完整膜系、目前站點或電性是否合格。FxJ／公有領域；[圖片出處 W02](99-image-credits.md#w02)。*

先把「一片」拆成層。基材提供主要支撐；其上可以有介電膜、金屬膜與暫時使用的光阻。介電膜通常用來絕緣或隔離，金屬用來導電；光阻則像可加工的遮罩，讓特定位置接受下一步處理。[T01](appendix-sources.md#t01)明確把光阻描述為暫時遮罩，去除時仍須保護基材及既有材料。

```text
                         加工面朝上；以下是三個獨立狀態
甲：尚未覆上本例膜層       乙：光阻已圖案化          丙：圖案轉移後
空氣                     光阻   開口   光阻         光阻   開口   光阻
                         ━━━          ━━━          ━━━          ━━━
                         待加工膜仍連續             下層膜   凹槽   下層膜
                         ━━━━━━━━━━━━━━━           ━━━          ━━━
矽基材                   矽基材                    矽基材
━━━━━━━━━━━━━━           ━━━━━━━━━━━━━━━           ━━━━━━━━━━━━━━━
```

*圖01-1｜教學假設：三種工件剖面，非按比例；省略自然氧化層、既有元件與多層結構。丙僅假設本例下層膜被開口，不代表蝕刻一定停止於矽表面。圖中空白是開口或已移除區，不是透明材料。*

乙的開口只在光阻，下面的膜尚未被挖掉；丙的下層已改變。移除兩者的光阻，會得到不同工件，不能統稱「回到裸晶圓」。此外，薄化改變的是基材厚度；去除表面薄膜不會自動補回薄化拿走的矽。

| 加工狀態 | 此刻可能要留下什麼 | 常被漏掉的問題 |
|---|---|---|
| 未覆本例膜層的基材 | 厚度、表面與幾何 | 「裸」不代表完全沒有氧化或污染 |
| 已覆膜、尚未圖案化 | 膜厚、界面與均勻度 | 膜的名稱相同，履歷未必相同 |
| 光阻已圖案化 | 下層膜、對位標記 | 錯誤是否仍只存在於暫時遮罩 |
| 圖案已轉移 | 線路、開口、側壁與電性 | 去膠不能補回被移除的材料 |
| 已薄化或有支撐結構 | 薄基材、加工面與支撐 | 化學相容之外，還有搬運承受力 |

最後一列只先建立狀態觀念；支撐與接合的機制留到[第 07 章](07-bonding-and-debonding.md)，不把所有晶圓畫成永遠堅固的圓片。

## 輸入、操作、輸出要怎麼寫？

假設正常流程要在蝕刻後移除剩餘光阻。[T02](appendix-sources.md#t02)的公開製程說明確有這種用途，但不是量產授權書。

| 流程欄位 | 本例應記錄的內容 |
|---|---|
| 輸入 | 工件識別、正背面、膜層順序、已有圖案、熱與蝕刻履歷、處理前量測 |
| 操作 | 依核准路線移除光阻；明列不能攻擊的材料與停止條件 |
| 輸出 | 去除目標的證據、保留結構的證據、異常記錄及允許的下一站 |

「已清洗」只描述做過動作，沒有說明結果。較完整的輸出應是：「光阻去除檢查已完成；下層膜厚與指定缺陷項目待判定。」它不漂亮，卻比「晶圓恢復乾淨」更能交接工作。

## 異常先定位到哪一層

若去膠後局部出現斑點，候選原因可能是光阻殘留、重新附著的粒子，也可能是下層膜受侵蝕。顏色差異也可能來自膜厚變化，不能僅依斑點外觀選藥液。[T03](appendix-sources.md#t03)分列光阻、殘留與粒子等去除對象；[T04](appendix-sources.md#t04)則提醒蝕刻速率、粗糙度及污染需要分開看。

檢查與處置先分三條路：

1. **身分或履歷不明：** 隔離並補齊站點與膜系資料，不用再次清洗代替辨識。
2. **確認有可移除物，保留層尚有餘裕：** 交工程評估已核准的候選處理，不代表立即可重做。
3. **確認保留層已缺損，或證據互相矛盾：** 停止原候選路線，另作處置判定；移除更多材料通常不能證明原結構恢復。

## 再驗證必須回到用途

產品片可能還要檢查圖案與電性；監控片可能要確認表面能否代表指定製程。兩者都不能只用「看起來亮」放行。同一片晶圓改作另一用途，也要有新用途的允收證據，而不是把原規格刪掉。

再驗證至少將處理前後的目標層、保留層、缺陷位置與量測方法相對照；有薄化或形變風險時，再列適用幾何檢查。資料只覆蓋哪些項目，結論就停在哪裡，不能從一站通過跳成可出貨。

## 推理檢查

1. 兩片晶圓直徑相同，為何不足以判斷能否共用處理？
2. 圖01-1 的乙與丙去掉光阻後，差別在哪裡？
3. 監控片沒有完整產品電路，是否表示可接受任意污染？
4. 去膠後出現斑點，為什麼不先多洗一次？

??? note "參考推理"
    1. 還缺用途、基材、膜系、圖案及加工履歷；這些共同決定相容性與驗證範圍。
    2. 乙的下層膜仍連續；丙已有移除區，去膠不會填回。
    3. 否。污染可能破壞監控結果或影響設備；仍要符合指定用途。
    4. 斑點可能是殘留，也可能是材料損傷；追加處理可能擴大損失或掩蓋證據。
