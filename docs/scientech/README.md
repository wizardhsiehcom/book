# 從晶圓清洗、去膜與重工邊界看懂辛耘

晶圓上的圖案做錯，能不能把表面洗掉再重來？答案取決於錯誤在哪一層、下面還要保留什麼，以及處理後能否被下一站接收。**能移除材料，不等於能撤銷先前的加工。** 這是讀懂清洗、蝕刻、光阻剝離與解鍵合設備的起點，也是本書理解辛耘的主線。

本書先從一片加工中的晶圓出發，建立材料帳本、機械支撐與再驗證，再回到辛耘的自製設備、代理及再生服務。不是把公司所有產品都改稱「修復設備」，也不從公開能力直接推定特定客戶訂單。

## 讀完能做什麼

- 指出要移除的目標層、必須保留的層，以及不可由去膜恢復的改變。
- 分開正常製程、失效重工與再生，不因機台名稱相同就混為一談。
- 對圖案異常、清洗殘留、薄晶圓損傷提出下一個檢查及停止條件。
- 先判斷回到流程的資格，再計算設備時間、成本與失敗支線。
- 讀公司消息時，分開自製、代理、服務，以及規劃、能力、驗證與收入。

本輪查閱日為 **2026-09-18**。發布日、文件涵蓋期間、實際讀取範圍與限制，分列於[來源索引](appendix-sources.md)。供應商對自己產品的描述不等於獨立性能驗證；技術來源也不替辛耘證明重工應用。來源不足處保留在[待查問題](appendix-open-questions.md)，不填入通用藥液、重工次數、客戶或良率。
