# 即時系統

即時系統要的不是峰值速度，而是**有界新鮮度、可正確重啟、失敗可量測**。延遲、掉幀與重連必須能對照讀者自己量到的硬體與現場負載，而不是規格表。

先讀 [影片與追蹤](../16/index.md) 與 [匯出與一致性](../20/index.md)，確認畫面與結果可對齊後，再談即時路徑。

- [串流攝入](stream-ingestion.md)：來源、時戳與緩衝如何進入可重啟的攝入路徑。
- [背壓與丟幀](backpressure.md)：下游跟不上時丟什麼、留什麼，新鮮度如何保持有界。
- [多鏡頭與故障驗收](operations.md)：多路同時失敗時如何驗收，而不是單鏡頭示範。
