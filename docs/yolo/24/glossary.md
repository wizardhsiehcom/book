# 詞彙

下列詞在全書必須同義。評估細節見 [06 評估](../06/index.md)，解碼見 [11 解碼／NMS](../11/index.md)，座標見 [03 座標](../03/index.md)。

**IoU（Intersection over Union）**\
兩框交集面積除以聯集面積，介於 0 與 1。用途有三，**閾值不可混用**：NMS 去重、TP matching、以及報表上的 IoU 掃描。說「IoU=0.5」必須補語境。

**NMS IoU**\
傳統 greedy NMS 的 IoU 閾值用來決定「重疊到什麼程度就把低分框當成同一物體而抑制」：對每個類別依分數由高到低掃描，若候選框與已保留框的 IoU 高於該閾值，該低分重疊框被刪除。此閾值不是評估時 TP matching 的 IoU，也不是 confidence。降低 NMS IoU 閾值會讓較輕微的重疊也被視為同一物體，因而抑制更多框、較易誤刪鄰近真物體；提高閾值則較寬容，較易留下重複框。

**TP matching IoU**\
評估時預測框要與某個 GT 框的 IoU 達到此閾值才算 True Positive。COCO 風格是在 IoU 0.50 到 0.95、步長 0.05 各算一次 AP 再平均；PR 曲線的積分／插值是在每個 IoU 內進行，不要把兩層混在一起。匹配失敗可能是定位差，也可能是 [漏標](../05/index.md) 讓真框根本不在 GT 裡。

**conf（confidence）**\
模型對「這裡有該類物體」的分數。它**不是** IoU。調 conf 改變你接受哪些預測；調 IoU 改變框與框如何匹配或抑制。現場「很密的誤報」先看 conf 與 NMS，不要先怪 mAP 公式。

**AP / mAP**\
AP 是單一類別在精確度–召回曲線下的面積（實作依 COCO 或 VOC 規則）。**mAP 是各類別 AP 的等權平均**；類別出現次數不直接加權。小類別 10 張圖的 AP 與大類別一萬張的 AP 在 mAP 裡權重相同。

**stride**\
特徵圖相對輸入的步長。框中心、網格與解碼位移都吃 stride。改輸入尺寸或插值方式卻沒對齊 stride，座標會整層錯位。

**letterbox**\
等比縮放後補邊，避免把物體拉扁。補邊的偏移必須在還原到原圖座標時減回去。訓練與推論 letterbox 不一致，等於評估在另一套幾何上。

**anchor-free**\
不預先放一組固定長寬比錨框，改為直接預測中心／邊界或分佈。不代表沒有網格，也不代表不需要 NMS（視版本；見 [12 演進](../12/index.md)）。

**DFL（Distribution Focal Loss）**\
DFL 是監督離散邊界距離分佈的損失；解碼是該分佈的機率加權期望。不要把 loss 與 decode 混為一談。訓練與解碼必須用同一套 bin。細節見 [10 訓練機制／DFL](../10/index.md)。

**quantization**\
把權重／活化從 FP16／FP32 降到 INT8 等。省記憶體與加速，通常掉一點 AP。掉點要在**與上線相同的前處理**下用 [19 benchmark](../19/index.md) 量，不要用訓練日誌裡的 mAP 代替。

**drift**\
上線資料相對訓練／驗證集的分佈偏移：鏡頭、季節、產品外觀。mAP 在舊驗證集仍高、現場變差，先查 drift 與切分洩漏，見 [22 維運](../22/index.md)、[04 資料切分](../04/index.md)。

**ID switch**\
追蹤裡同一物體被換成新 ID，或兩物體互搶 ID。偵測斷框、NMS 切錯、相機運動都會誘發。見 [16 追蹤](../16/index.md)。

**漏標 / 漏檢**\
漏標：GT 缺失。漏檢：prediction 缺失。前者修標註；後者查閾值、遮擋、解碼。
