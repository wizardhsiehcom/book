# 排錯

用法：對上症狀 → 做完檢查 → 回到指定章修改。先分清 **漏標（GT 缺失）** 與 **漏檢（prediction 缺失）**，再動閾值或重訓。

## 驗證 mAP 很高，現場漏很多框

**檢查**\
1. 抽 20 張現場圖：物體在畫面上但 GT 根本沒框 → **漏標**，不是模型瞎。\
2. GT 有框、模型也有框但被濾掉：看 conf 與 **NMS IoU** 是否過嚴。\
3. GT 有框、模型無框或 IoU 低於 **TP matching IoU** → **漏檢**。\
4. 驗證集是否含同一鏡頭／同一段影片的鄰近幀（洩漏會灌水 mAP）。

**回章**：[05 標註](../05/index.md)、[06 評估](../06/index.md)、[04 資料切分](../04/index.md)、[13 錯誤分析](../13/index.md)。

## 框位置整體偏移或縮放不對

**檢查** letterbox 補邊是否在還原時減掉；推論 imgsz 與 stride 是否和解碼假設一致；輸出 `xyxy` 是 letterbox 空間還是原圖空間。訓練與推論**不必同尺寸**，但前處理與座標契約必須同一套。

**回章**：[03 座標](../03/index.md)、[02 推論](../02/index.md)、[07 訓練](../07/index.md)、[11 解碼／NMS](../11/index.md)。

## 重疊框爆量，或緊鄰物體互刪

**檢查** Greedy NMS 只在兩框 IoU 大於閾值時才抑制低分框。例如 IoU=0.6：閾值 0.5 會刪低分框，閾值 0.7 則不刪。故重複框過多應嘗試降低 NMS IoU 閾值，讓更容易互刪；密集物體被互刪則應提高該閾值，讓較難互刪。兩句方向不可反。其餘條件固定，用 validation 分別驗證。confidence 只先篩低分框；評估 matching IoU 不是這個閾值。

**回章**：[11 解碼／NMS](../11/index.md)、[02 推論](../02/index.md)。

## 某一類把 mAP 拉崩，但畫面「看起來大多對」

**檢查** mAP 是**類別等權平均**，稀有類 AP 與大宗類權重相同。不要用樣本頻次當藉口忽略小類。分開看每類 AP、混淆與漏標率。

**回章**：[06 評估](../06/index.md)、[14 改善](../14/index.md)、[18 選型](../18/index.md)。

## 匯出／量化後精度掉一截

**檢查** 是否仍用訓練日誌 mAP 對比引擎輸出；校正集是否混進驗證集；NMS 是否從 Python 側移進圖內導致閾值不同；資料型別與動態 shape。

**回章**：[20 匯出](../20/index.md)、[19 benchmark](../19/index.md)；quantization 定義見 [詞彙](glossary.md)。

## 追蹤 ID 亂跳（ID switch）

**檢查** 偵測是否在遮擋時斷框（漏檢鏈）；NMS 是否在交會時切錯人；相機或物體加速是否超出關聯閘。先穩定偵測契約，再調追蹤器。

**回章**：[16 追蹤](../16/index.md)、[21 即時系統](../21/index.md)。

## 上線數週後變差，舊驗證集分數仍好

**檢查** drift：鏡頭、燈光、新品、季節。不要先重訓整個 backbone。建現場抽樣集，與舊 val 對打。

**回章**：[22 維運](../22/index.md)、[23 專案](../23/index.md)、[04 資料切分](../04/index.md)。

## 開放詞彙「能講但不能穩」

**檢查** 提示詞是否當類別 id 用；評估是否仍用封閉集 mAP 硬套。這是新任務契約，不是把 detect 的 conf 調低。

**回章**：[17 開放詞彙與新任務](../17/index.md)、[01 任務](../01/index.md)。
