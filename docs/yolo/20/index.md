# 匯出與數值一致性

檔案匯出成功不代表數值通過驗證。輸出與讀檔產物本身就是待核對的工件，必須與訓練時的推論路徑對齊後再比。

先備：[推論機制](../11/index.md) 與 [公平Benchmark](../19/index.md)。

- [ONNX FP32基準](onnx-baseline.md)：以未量化 FP32 圖作為後續精度與延遲比較的基準。
- [FP16與INT8](quantization.md)：量化改變數值與運算圖，須與基準分開量測。
- [執行時選擇](runtime-selection.md)：同一圖在不同執行時的核與捨入不同，輸出不可直接互換。
- [輸出一致性](output-consistency.md)：比對輸出與讀檔產物，確認匯出未引入不可接受的偏差。
