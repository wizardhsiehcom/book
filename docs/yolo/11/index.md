# 推論解碼、信心過濾與 NMS／NMS-free 工程

推論不是把張量直接畫框。網路輸出格式因頭而異：有的是中心點加寬高，有的是角點，有的還帶網格偏移或對數空間。**座標解碼必須對齊該頭的參數化**，不能拿一套公式套所有模型。把框還原到原圖座標，只在你要顯示、量測或交給下游（例如 [../16/index.md](../16/index.md) 追蹤）時才做；IoU 只要兩框在**同一座標系**即可，不必先 letterbox 還原。

## 操作順序：先濾再解、同系比 IoU

實務上可先用物件分數做門檻，丟掉明顯低分通道，再對存活項做完整座標解碼。這不是省精度，而是省算力：解碼與後續 IoU 都隨框數成長。信心分數**不是校準機率**；`0.9` 不代表九成真有物體。它只是排序與過濾用的分數。信心門檻、NMS 的 IoU 門檻、評估用的 IoU（見 [../06/index.md](../06/index.md)）是三條獨立旋鈕，不要混成一個「夠不夠準」的感覺。

letterbox 還原只服務「原圖座標」這條路徑。若你在網路輸入尺度上做 NMS，框已對齊同一縮放與填充，IoU 合法。等要畫到原圖或匯出給下游，再反變換一次。過早還原會把填充區的誤差放大，也讓除錯時難對齊特徵圖尺度（對照 [../08/index.md](../08/index.md) 的感受野與 [../09/index.md](../09/index.md) 的頭結構）。

## 合成例子：同一類三框

同一類、同一座標系（此處用輸入尺度的 `xyxy`，單位任意）：

- A：`(0,0,10,10)`，分數 `0.9`，面積 `100`
- B：`(1,1,11,11)`，分數 `0.8`，面積 `100`
- C：`(8,0,18,10)`，分數 `0.7`，面積 `100`

A∩B：`(1,1,10,10)`，面積 `81`。聯集 `100+100-81=119`。IoU＝`81/119≈0.681`。\
A∩C：`(8,0,10,10)`，面積 `20`。聯集 `100+100-20=180`。IoU＝`20/180≈0.111`。

標準 greedy NMS、IoU 門檻 `0.5`：依分數保留 A；B 對 A 的 IoU 高於 `0.5`，刪 B；C 對 A 低於 `0.5`，留 C。結果是 A 與 C，不是「只留最高分一個」。把 NMS 門檻**提高**（例如 `0.7`）會**更少抑制**：`81/119<0.7` 時 B 也會留下。抑制前框數永遠 ≥ 抑制後，兩者可以相等（沒有任何一對超過門檻）。這是接受條件，不是 bug。

失敗假設要分開寫：漏檢像是信心門檻過高；重框像是門檻過低或 NMS IoU 過寬；評估 mAP 掉了卻畫面看起來乾淨，常是評估 IoU 與 NMS IoU 不一致，而不是解碼寫錯。對照 [../13/index.md](../13/index.md) 的假設清單與 [../14/index.md](../14/index.md) 的旋鈕實驗，一次只改一條。

## NMS-free 是頭的選擇，不是把後處理關掉

截至 2026-09-08，Ultralytics YOLO26 文件寫明：預設是 one-to-many 頭，推論仍走 NMS；`nms=False` 是選**支援的 one-to-one 頭**，走 NMS-free 路徑。見 [YOLO26](https://docs.ultralytics.com/models/yolo26/) 與 [Predict 的 conf／iou](https://docs.ultralytics.com/modes/predict/)。不要把「關掉 NMS」套到尚未訓練成一對一的 raw 多對一輸出上：同一物體仍會爆出多框，畫面重疊不是後處理魔法能補的。那是訓練目標與頭設計問題，回到 [../10/index.md](../10/index.md)，不是推論開關。

raw 輸出與 fused／export 輸出也要分開處理。訓練或除錯時你可能讀未融合的多尺度張量；匯出（[../20/index.md](../20/index.md)）常把解碼、sigmoid、甚至部分 NMS 編進圖。同一組 `conf`／`iou` 在 Python 路徑與引擎路徑上可能作用在不同階段。即時管線（[../21/index.md](../21/index.md)）若延遲突然升高，先數「進 NMS 前的框數」而不是先怪硬體：信心門檻太低會讓 NMS 變二次瓶頸。基準（[../19/index.md](../19/index.md)）要固定：同一座標系、同一門檻、同一是否還原 letterbox。

沒有「所有模型通用」的解碼表。換頭、換錨、換一對一／多對一，就重寫對應步驟並用合成框驗 IoU 算術。推論頁（[../11/index.md](../11/index.md)）只負責這條流水線是否可重複，不負責宣稱機率校準。
