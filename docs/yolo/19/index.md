# 公平Benchmark

同一契約下比速度與準確度：固定輸入、輸出與計分，才看得出誰快、誰準。本頁給你可複現的比較骨架，不報現場數字。

先備：[評估指標](../06/index.md)、[當代選型](../18/index.md)。

- [比較契約](comparison-contract.md)：鎖定模型、提示、資料與計分，避免各跑各的。
- [計時協定](timing-protocol.md)：何時開表、何時停表、暖機與重複次數寫死。
- [延遲與吞吐](latency-vs-throughput.md)：單筆等待與批次流量分開報，勿混成一句「比較快」。
