# YOLO 資料流：單尺度原點與後續分解

YOLO 家族的共同點是**單階段**：一張圖走完網路後直接出框，不必先跑獨立 region proposal。這不等於「永遠只有一個特徵尺度」。2015 年原作把偵測寫成單一網路、單一輸出張量上的迴歸與分類（Redmon et al., 2015-06-08, [arXiv:1506.02640](https://arxiv.org/abs/1506.02640) 摘要）。2024 年的 YOLOv10 則另開一條線：一致雙重指派、可免 NMS（Wang et al., 2024-05-23, [arXiv:2405.14458](https://arxiv.org/abs/2405.14458) 摘要）。兩者相隔九年，不可把 v1 的單尺度網格當成全家族不變量，也不可把 v10 的雙指派倒讀回 2015。

現代實作常用 **backbone / neck / head** 當工程切面：backbone 抽特徵；neck 做尺度融合或金字塔；head 把每個空間位置解成框與類別。這是模組邊界，不是論文裡對所有版本的法定分層。下列張量形狀是**合成教學例**，不是任一公開權重的精確規格。

設輸入 \(H=W=416\)，單尺度步幅 \(s=32\)，則特徵圖 \(13\times13\)。若每個格子預測 \(B=2\) 個框、每框 \(5\) 個幾何／物件度、外加 \(C=20\) 類，合成輸出可寫成

\[
T\in\mathbb{R}^{13\times13\times(2\cdot5+20)}=\mathbb{R}^{13\times13\times30}.
\]

多尺度頸部（後續版本常見，非 v1 不變式）可能再掛 \(26\times26\)、\(52\times52\) 頭；那是金字塔，不是「單階段」的同義詞。訓練與指派見 [指派與損失](../10/index.md)；推論後處理見 [推論](../11/index.md)；評測協議見 [評測](../06/index.md)。

## 座標正確性：把已知 raw 灌進指定解碼器

工程驗收不是「在合成矩形上訓練完，框剛好平移一個 stride、類別一定對」。權重、指派、增強都會讓那個期望失敗。正確做法是：**凍結解碼器與公式，注入已知 raw，檢查像素框是否與手算一致。**

以下解碼是**錨點式示意慣例**，不是現行所有 YOLO 的解碼器。令格子 \((i,j)=(4,3)\)、\(s=32\)，該格錨寬高 \(p_w=p_h=64\)。已知 raw（已假設為解碼前的 logit／偏移）：

\[
t_x=0,\quad t_y=0,\quad t_w=0,\quad t_h=0.
\]

示意公式：

\[
b_x = s\cdot(j+\sigma(t_x)),\quad
b_y = s\cdot(i+\sigma(t_y)),\quad
b_w = p_w e^{t_w},\quad
b_h = p_h e^{t_h}.
\]

\(\sigma(0)=0.5\)，故 \(b_x=32\cdot(3+0.5)=112\)，\(b_y=32\cdot(4+0.5)=144\)，\(b_w=b_h=64\)。中心—寬高轉角點：

\[
x_1=b_x-b_w/2=80,\quad y_1=b_y-b_h/2=112,\quad x_2=144,\quad y_2=176.
\]

驗收：同一 raw、同一公式、同一格子與錨，解碼器輸出必須與上式逐元素相符（浮點容差例如 \(10^{-5}\)）。改 \(t_x=\ln 3\) 不在此慣例的中心公式裡；若你的實作把 \(t_x\) 用在寬而非中心，那是**另一個解碼器**，必須先寫方程式再灌數，不可混用。

失敗假說與處置：

| 假說 | 觀察 | 處置 |
|------|------|------|
| 格子原點或 \(i,j\) 對調 | 中心差一整格 stride | 對照特徵圖索引與輸入座標約定 |
| \(\sigma\) 漏做或做兩次 | 中心卡在格角或格心以外 | 對 raw=0 必得 0.5 格內偏移 |
| 錨與 stride 張冠李戴 | 寬高差一倍或差尺度 | 鎖定該頭的 \(p_w,p_h,s\) |
| 把訓練網路當解碼測試 | 合成矩形上框「不該」準 | 停訓，改灌已知 raw |
| 把 v1 單張量當全家族 | 多頭輸出對不齊 | 分頭解碼，再合併 |

匯出與數值位寬見 [匯出](../20/index.md)；基線對照見 [基線訓練](../07/index.md) 與 [基準](../19/index.md)。錯誤分析時先分「解碼錯」與「學錯」，見 [錯誤分析](../13/index.md)、[改進](../14/index.md)。卷積尺度堆疊見 [卷積與尺度](../08/index.md)；模組切面見 [架構](../09/index.md)。

一句話：單階段描述的是提案是否獨立；尺度、頸部、指派與解碼器都是版本契約。先鎖契約與公式，再用已知 raw 驗座標，訓練準度另案處理。
