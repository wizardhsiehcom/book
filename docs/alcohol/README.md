# 理解酒：從發酵、風味到文化與身體

尾牙桌上，同事說這瓶「很順」，長輩說米酒「是拿來煮菜的」，朋友說紅酒「對心臟好」，另一位朋友一杯就臉紅，被笑說「代謝好」。這幾句話談的其實是四件不同的事：製程、用途、健康宣稱、身體反應。它們常被混在同一句「這酒不錯」裡。

這本書想把它們拆開。

## 這本書回答四個問題

1. **一杯酒怎麼形成？** 糖從哪裡來、微生物做了什麼、蒸餾和木桶又改變了什麼。
2. **我們怎麼感覺、怎麼描述它？** 哪些感受來自酒液，哪些來自價格、酒標和當下的心情。
3. **酒在人群中扮演過什麼角色？** 勞動、祭儀、稅收與殖民，而不只是品味故事。
4. **酒精對身體做了什麼？** 研究怎麼讀，哪些說法有證據、哪些沒有。

## 這本書不做什麼

- 不推薦品牌、不排行、不談收藏投資，也沒有購買連結。
- 不教自己釀酒，只講原理。
- 不勸人喝酒，也不評價喝酒的人。拒酒、少喝與不喝，都是完整的生活選擇。
- 不要求你喝酒才讀得懂。每章都有一個用茶、果皮、香料或其他無酒精材料完成的觀察練習。

## 書中怎麼區分四種說法

同一段文字裡，本書盡量讓你看得出一句話屬於哪一種：

| 類型 | 意思 | 例子 |
|---|---|---|
| 事實 | 可由法規、測量或教材確認 | 美國 NIAAA 的標準杯約含 14 克純酒精 |
| 研究結果 | 某個研究在某種條件下的發現，附上研究設計與限制 | 一項 20 人的實驗中，同一支酒標上較高價格時，受試者的評分較高 |
| 文化詮釋 | 某個群體、某個時期對酒的理解 | 具體族群文獻如何描述酒在祭儀與分享中的角色 |
| 偏好 | 個人喜歡或不喜歡 | 有些人喜歡冰涼的啤酒，有些人偏好接近室溫 |

「好喝」「高級」「值得」屬於偏好或評價；「甜」「酸」「苦」「澀」是可以描述、也部分可以測量的感官特徵。本書把兩者分開寫。
