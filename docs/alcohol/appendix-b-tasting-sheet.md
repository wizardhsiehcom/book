# 附錄 B：風味觀察單

這張表用來留下自己的觀察，不計總分、不做品牌排名，也不是健康檢查。茶、果皮、麵包、水果或單純聞香都能使用；不需要飲酒才能填寫。方法說明見[第 09 章](09-describing-flavour.md)，溫度與餐桌比較見[第 11 章](11-storage-temperature-pairing.md)。

## 使用方式

先決定這次只比較哪一件事，例如同一份茶的兩種溫度，或兩種熟悉水果的香氣。盡量保持其他條件相近，先各自填寫，再交換說法。如果只是日常隨手記錄，不做比較也可以，請直接註明。

「未觀察」「沒有察覺」「有感覺但無法命名」是三種不同結果，都可以寫。欄位留白不代表能力不足；不要為了把表填滿而勉強入口，也不要用試喝確認材料是否安全。只選用本來就能安全接觸、沒有過敏疑慮的食品。

## 一份填寫示例

以下是虛構的無酒精教學紀錄，不是實驗結果，也不預告你應該有相同感覺。

| 項目 | 示例 |
|---|---|
| 問題 | 同一份茶放涼後，我會怎麼描述？ |
| 條件 | 相同玻璃杯；先溫熱、後常溫；沒有測量溫度；已知茶名 |
| 入口前香氣 | 先像烤穀物，放涼後想到果皮；果皮是哪一種不確定 |
| 味道 | 苦味有察覺，酸、鹹、鮮未能辨認；沒有做甜味比較 |
| 口腔感受 | 入口後稍晚出現乾澀；不把它寫成酸味 |
| 喜好 | 今天較喜歡前一次的溫熱口感 |
| 限制 | 時間和溫度同時變了，沒有盲測，只有我一個人 |
| 能說的結論 | 這次我記錄到不同描述；不能推出所有茶的最佳溫度 |

## 多人一起用時

讓每個人先寫再說，不公布「老師答案」。交換的是具體參照物，例如「橘皮」或「烤吐司邊」，而不是誰比較懂。兩人描述相同但喜好不同，不需要改到一致；兩人描述不同，也可以先保留。

若加入重複樣本，只是觀察紀錄是否穩定，不能以一次結果判定能力。可以隨時停止，也可以只負責觀察外觀或聞香。不要為了完成表格而增加飲酒量，或要求不飲酒的人參與含酒精樣本。

本表由本書編製，供個人閱讀與教學使用；不是經驗證的感官量表。感官生理與研究來源見[第 09 章來源](09-describing-flavour.md#來源)。
