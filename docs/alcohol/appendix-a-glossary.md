# A 術語表

這份詞表用來協助閱讀與查資料。中文同一個字有時對應不同外語概念；外語同一個字，也可能因法律地區而改變範圍。遇到酒標時，先確認上下文與適用地區，再查所在章節的來源。

## 原料與製程

| 繁體中文 | 英文／必要日文 | 本書用法與容易混淆的地方 | 延伸章節 |
|---|---|---|---|
| 乙醇、酒精 | ethanol / ethyl alcohol；エタノール | 酒類中的主要酒精成分；化學上的 alcohol 是更大的物質家族，不能把其他醇當作可飲用乙醇 | [02](02-fermentation.md)、[13](13-body-health.md) |
| 糖化 | saccharification；糖化 | 用酵素將澱粉分解成較小的糖；與酵母產生乙醇的步驟不同 | [02](02-fermentation.md) |
| 酒精發酵 | alcoholic fermentation；アルコール発酵 | 微生物把可利用的糖轉成乙醇等產物；不等於所有發酵食品都含相同酒精量 | [02](02-fermentation.md) |
| 酵母 | yeast；酵母 | 單細胞真菌的通稱；不同物種與菌株的釀造表現不一樣 | [02](02-fermentation.md) |
| 麥芽 | malt；麦芽 | 經發芽與乾燥等處理的穀物；提供糖化酵素及風味，不是麥芽糖的同義詞 | [04](04-beer.md) |
| 麴 | koji；麹 | 日本釀造語境常指培養麴菌的穀物等材料，提供酵素；不是酵母的另一個名稱 | [02](02-fermentation.md)、[06](06-rice-koji-taiwan.md) |
| 酒麴 | jiuqu / qu | 中文麴種多樣，可能含混合微生物；不能直接把所有酒麴等同日本清酒用麴 | [06](06-rice-koji-taiwan.md) |
| 麥汁 | wort | 麥芽等原料糖化後得到的液體；不是成品啤酒 | [04](04-beer.md) |
| 醪 | mash / moromi；もろみ | 依製程可指含固體的糖化物料或發酵中的物料；英文 mash 與日文 moromi 不在所有場合完全相同 | [02](02-fermentation.md) |
| 蒸餾 | distillation；蒸留 | 蒸發與冷凝形成的分離操作；乙醇通常先由發酵產生 | [03](03-distill-age-blend.md) |
| 餾分 | fraction / cut | 蒸餾時分段取得的部分；頭、心、尾不是各自只含一種物質 | [03](03-distill-age-blend.md) |
| 熟成 | maturation / ageing；熟成 | 在特定條件下隨時間產生變化；不是品質必然增加的承諾 | [03](03-distill-age-blend.md) |
| 調和、調配 | blending；ブレンド | 組合不同酒液；合法定義和一般操作需看上下文 | [03](03-distill-age-blend.md) |
| 加烈 | fortification | 加入酒精或烈酒提高酒精含量；加入時機及成品甜度另有關係 | [05](05-wine-fruit.md) |
| 蘋果酸乳酸發酵 | malolactic fermentation, MLF | 乳酸菌將蘋果酸轉成乳酸與二氧化碳；不是把糖變成乙醇的同一過程 | [02](02-fermentation.md) |
| 殘糖 | residual sugar | 依分析方法測得的殘留糖；與感受到的甜味有關，但不能完全互換 | [05](05-wine-fruit.md)、[09](09-describing-flavour.md) |

## 酒類名稱與標示

| 繁體中文 | 英文／必要日文 | 本書用法與限制 | 延伸章節 |
|---|---|---|---|
| 釀造酒 | fermented alcoholic beverage | 製程入門分類；具體法律稅目仍需查當地定義 | [01](01-what-is-alcohol.md) |
| 蒸餾酒、烈酒 | distilled spirit / spirit drink | 蒸餾酒描述製程；烈酒在不同法規下有特定條件，不用單一濃度替全球分類 | [07](07-spirits.md) |
| 再製酒、調製酒 | compounded beverage / mixed drink 等 | 中文日常與法定用法不同，沒有一個英文詞可涵蓋所有情形 | [01](01-what-is-alcohol.md)、[08](08-mixed-nonalcoholic.md) |
| 艾爾、拉格 | ale / lager | 主要從酵母及發酵傳統區分，不是深色與淡色的同義詞 | [04](04-beer.md) |
| 葡萄酒、白葡萄酒 | wine / white wine | 英文 wine 在具體法律中可能範圍不同；本書不用「白酒」簡稱白葡萄酒，以免與蒸餾白酒混淆 | [05](05-wine-fruit.md) |
| 白酒 | baijiu | 本書指相關穀物蒸餾酒文化與品類；不是白葡萄酒 | [07](07-spirits.md) |
| 清酒 | sake / seishu；清酒 | 日語 sake 也可泛指酒；法律上的清酒與日常日本酒稱呼需分開看 | [06](06-rice-koji-taiwan.md) |
| 精米步合 | rice polishing ratio；精米歩合 | 精米後留下的白米重量相對於原糙米的比例，不是磨掉的比例 | [06](06-rice-koji-taiwan.md) |
| 本釀造、純米 | honjozo / junmai；本醸造／純米 | 日本清酒特定名稱；代表原料與製法要求，不是本書的品質分數 | [06](06-rice-koji-taiwan.md) |
| 單一麥芽 | single malt | 在蘇格蘭威士忌語境有特定原料及單一蒸餾廠條件；不是單桶的同義詞 | [07](07-spirits.md) |
| 利口酒 | liqueur | 通常涉及加糖與增香，但法定含糖量及分類要依地區和品類查證 | [08](08-mixed-nonalcoholic.md) |
| 無酒精、低酒精 | alcohol-free / non-alcoholic / low-alcohol | 不同字詞與地區的條件可能不同；不憑翻譯判定完全不含乙醇 | [08](08-mixed-nonalcoholic.md) |
| 酒精濃度 | alcohol by volume, ABV / % vol | 以體積表示的酒精百分比；濃度與整杯含多少克乙醇是兩個數值 | [附錄 C](appendix-c-labels-units.md) |
| 年份、年齡 | vintage / age statement | 前者常涉及採收年，後者可能涉及熟成；不能只見數字就作相同解讀 | [03](03-distill-age-blend.md) |

## 感官與研究

| 繁體中文 | 英文 | 本書用法與限制 | 延伸章節 |
|---|---|---|---|
| 風味 | flavour / flavor | 嗅覺、味覺與其他口腔感受整合後的經驗 | [09](09-describing-flavour.md) |
| 鼻前嗅覺、鼻後嗅覺 | orthonasal / retronasal olfaction | 氣味分子從鼻孔或口腔經鼻咽抵達嗅覺區域的不同路徑 | [09](09-describing-flavour.md) |
| 澀感 | astringency | 口腔的乾澀、收斂等感受；與苦味分開描述 | [09](09-describing-flavour.md) |
| 酒體 | body | 整體厚薄等感受的描述詞；沒有由單一分子決定的通用分數 | [09](09-describing-flavour.md) |
| 盲測 | blind tasting / blinded test | 隱藏指定資訊來比較；仍須控制順序、容量、溫度等條件 | [10](10-price-labels-expectation.md)、[附錄 B](appendix-b-tasting-sheet.md) |
| 期待效應 | expectation effect | 先前資訊可能改變感受或報告方式；不能因此說所有差異都只是想像 | [10](10-price-labels-expectation.md) |
| 相對風險 | relative risk, RR | 某組事件風險相對另一組的比值；須交代比較組與時間 | [13](13-body-health.md) |
| 勝算比 | odds ratio, OR | 兩組事件勝算的比值；不直接等於風險比或個人罹病機率 | [13](13-body-health.md) |
| 混雜因素 | confounding factor | 可能同時與暴露及結果相關，影響觀察到的關係 | [13](13-body-health.md) |
| 系統性回顧、統合分析 | systematic review / meta-analysis | 按方法整理研究；統計合併仍受原研究品質及模型限制 | [附錄 D](appendix-d-evidence.md) |
| 標準杯、酒精單位 | standard drink / alcohol unit | 計量工具，國別定義不一；不是安全額度 | [附錄 C](appendix-c-labels-units.md) |
| ALDH2 | aldehyde dehydrogenase 2 | 乙醛代謝相關酵素；低活性變異與飲酒反應及風險有關 | [13](13-body-health.md) |

## 查詞時保留原文

讀到不熟悉的酒名時，可記下「原文名稱、語言、出現地區、是標示還是文章描述」。例如 *dry* 在風味語境常指不甜，不能直接翻成沒有水；*spirit* 在酒類語境指烈酒，和日常說的精神無關。查字典得到的第一個中文詞，未必適合當前的法規或製程。
