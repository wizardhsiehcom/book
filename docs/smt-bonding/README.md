# 熱風・熱壓・熱板　電子接合完整指南

## 本書目標

這本書幫助剛接觸電子組裝的讀者，分清三種加熱接合方式，並看懂製程、設備與品質人員各要檢查什麼。讀完後，你應能說明：熱從哪裡進入接合區、哪些條件影響結果，以及異常應交給誰確認。

全書以三種工藝為主軸：

| 工藝 | 加熱方式 | 典型應用 |
|------|---------|---------|
| 熱風回流 | 強制對流 | SMT 量產主線 |
| 熱壓接合 | 傳導（刀頭接觸） | FPC、ACF、顯示器模組 |
| 熱板傳導 | 傳導（板面接觸） | 打樣、維修 |

SMT 是把元件裝到電路板表面的製程；FPC 是軟性電路板；ACF 是靠厚度方向導通的異向性導電膜。初次閱讀不必記住所有縮寫，可隨時查[名詞表](00-glossary.md)。

## 依目前問題找章節

| 你要解決的問題 | 先讀 | 讀完要能做什麼 |
|---|---|---|
| 三種加熱方式差在哪裡？ | [工藝比較](07-comparison.md) | 說明熱如何傳入工件，以及是否需要施壓 |
| 換產品後，哪些設定要一起確認？ | [量產控制](02b-production-control.md) | 核對物料、程式、實測曲線與放行紀錄 |
| 熱壓機的設定要看什麼？ | [熱壓接合](03-hot-bar.md) | 分清刀頭設定與接合結果，列出待確認條件 |
| 檢測報不良後，先查哪裡？ | [缺陷分析](08-defect-analysis.md)、[量產控制](02b-production-control.md) | 選擇觀察工具，界定受影響批次與最近變更 |

本書用來理解原理與準備檢查項目。實際調機前，仍須確認產品、材料規格與已核准的製程條件；書中不同材料的示例不能直接合成一份機台設定。
